# 攒股收息：合并版完整分析框架 v3.0

> 框架定位：为"以股息收入为核心目标"的长期投资者提供从避坑、门槛、质量、估值到资金规划的全流程决策系统。
> 适用范围：A 股高分红标的（银行、消费、公用事业、电信、交通基建、制造周期等板块）。
> 使用方式：L0 → L1 → L2 → L3 → L4 → L5 → L6 → L7 逐层过滤，每层有明确"通过 / 不通过 / 降级"判定。

---

## L0 避坑筛查（一票否决层）

T1-T7 七类陷阱逐一排查，命中任意一条直接淘汰：

| 编号 | 陷阱 | 判定标准 |
|---|---|---|
| T1 | 扣非连亏 | 连续两年扣非净利润为负 |
| T2 | 负分红 | 近三年累计现金分红为负（分红再融资倒挂） |
| T3 | 债务雷 | 资产负债率 > 80% 且带息负债/EBITDA > 5 |
| T4 | 低回报 | 近三年 ROE 均值 < 5% |
| T5 | 商誉雷 | 商誉占净资产比 > 30% |
| T6 | 质押雷 | 控股股东质押率 > 80% |
| T7 | 审计雷 | 审计意见非标准无保留 |

**输出**：命中项列表 + 全部通过则进入 L1。

---

## L1 硬门槛（量化准入层）

| 编号 | 指标 | 标准 |
|---|---|---|
| H1 | 近 3 年平均股息率 | > 3% |
| H2 | 近 3 年分红比例 | > 30% |
| H3 | 近 3 年营收复合增速 | > 5% |
| H4 | 近 3 年毛利率标准差 | < 5%（稳定性） |

**豁免规则**（H1 或 H2 不达标时检查，命中任一则放行）：
1. L4 七维打分 A 级（≥ 30 分）；
2. 央企/国企有明确分红承诺（如三年股东回报规划）；
3. 低 PB + 高 ROE（PB < 0.8 且 ROE > 10%）；
4. 高 DPS 复合增速（近 3 年 DPS CAGR > 15%）。

**输出**：达标 / 不达标 / 不达标但触发豁免。不达标且无豁免 → 直接降级出池。

---

## L2 质量评估（定性 + 定量）

1. **通用质量指标**：ROE 趋势、净利润增速、营收增速、毛利率、净利率、资产负债率。
2. **股权结构**：实控人类型、前十大股东集中度、分红意愿评级。
3. **DPS 增长分类**：真成长型 / 周期性 / 吃老本型 / 倒退型。
4. **行业专属指标**：银行（不良率、核心一级资本充足率）、消费（提价能力、渠道库存）、公用事业（电价机制、利用小时数）、电信（ARPU、资本开支周期）、交通基建（车流量、费率）、制造周期（产能利用率、库存周期）。
5. **护城河定性评分**：品牌、转换成本、网络效应、成本优势、牌照/特许经营。

**输出**：质量评级（优/中/差）+ 核心矛盾清单。

---

## L3 估值定位（多锚交叉验证）

1. **估值绝对值**：PE、PB、股息率及各自近 5 年分位数。
2. **DDM 合理买价**：必须输出 Bear / Base / Bull 三档；股息增速 g 的取值必须与 L2 盈利趋势一致（禁止用不可持续的高增速）。
   - V = D₁ / (r − g)，r 为要求回报率（一般 8.5%–10%）。
3. **估值交叉验证矩阵**：PE 法 / PB-ROE 法 / 股息率定价法 / DDM 法互相印证，给出合理区间与安全边际。

**输出**：合理买价区间 + 当前价格所处位置（低估 / 合理 / 高估）。

---

## L4 七维打分卡（35 分制）

| 维度 | 满分 |
|---|---|
| 分红质量 | 5 |
| 盈利能力 | 5 |
| 分红波动率 | 5 |
| 护城河 | 5 |
| 行业地位 | 5 |
| 股息增速 | 5 |
| 估值分位 | 5 |

**等级**：A 级 ≥ 30；B 级 26–29；C 级 20–25；D 级 < 20。

**输出**：总分 + 等级 + 与已分析标的池的排名对比。

---

## L5 资金规划

1. **目标分红测算**：目标年分红额 ÷ 预期 DPS = 所需股数 × 股价 = 所需资金。
2. **多情景敏感性**：基准 / 悲观两情景下的收益差距。
3. **建仓建议**：分批节奏、仓位上限、执行注意（流动性、红利税）。

---

## L6 组合构建（组合层面）

单只标的分析可略。组合层面关注：行业分散、股息到账月份错配、单一标的仓位上限（一般 ≤ 15%）。

---

## L7 宏观压力测试

| 情景 | 内容 | 判定 |
|---|---|---|
| A | 通缩 / 消费疲软 | 分红维持 / 削减 / 归零 |
| B | 利率长期下行 | 分红维持 / 削减 / 归零 |
| C | 能源价格战（或行业特有冲击） | 分红维持 / 削减 / 归零 |

**输出**：三情景判定 + 组合抗压结论。

---

## 全流程总结模板

- 层级总览表（L0–L7 各层结论一览）；
- 最终结论（等级 + 是否入池 + 建仓区间）；
- 核心矛盾（最重要的 1–3 条多空分歧）；
- 对标对比（与已分析标的横向排名）；
- 何时重新评估（触发重估的事件清单）。
