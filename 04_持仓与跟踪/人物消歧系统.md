## 一、核心问题

在金融新闻中，一个人名可以指向完全不同的个体。把张三（歌手）误认为张三（上市公司高管），轻则浪费时间，重则做出错误投资判断。

**本系统解决两个问题**：

1. **消歧判定**：新闻中出现的"张杰"是歌手还是运动员？匹配上下文标签 → 输出置信度。
2. **标签发现**：对于高频常见名，如何系统性地整理出"独有标签"——即那些只属于某一个张杰、绝对不会出现在另一个张杰身上的信号。

本系统与 Vault 现有人物档案互补：人物档案描述**这个人做了什么**，消歧标签告诉你**如何在新闻中认出这个人**。

## 二、标签五层分类体系 (L1-L5)

### 概述

| 层级 | 名称 | 判定规则 | 信息量 | 示例 |
|------|------|----------|--------|------|
| L1 | 锚定标签 | 1 条命中 = 确定识别 | 极高，唯一映射 | 小米创始人 → 雷军 |
| L2 | 强组合标签 | ≥2 条命中 = 高置信 | 高，组合后唯一 | [芯片 + 兆易创新 + 百亿持仓] → 葛卫东 |
| L3 | 弱组合标签 | 单条仅提升概率，不独立判定 | 中，多人物共享 | 浙江籍 → 提升概率但不唯一 |
| L4 | 排除标签 | 1 条命中 = 淘汰该候选 | 极高（反向） | 奥运会金牌 → NOT 张杰(歌手) |
| L5 | 领域标签 | 缩小候选池，不加分 | 方向性 | 娱乐版 → 候选池 = 歌手/演员 |

### L1 — 锚定标签

**定义**：与目标人物形成 **1:1 唯一映射**的信号。在整个人名空间中，这个标签只可能指向一个人。

**判定**：1 条 L1 命中 → 置信度"确定"，无需再看其他标签。

**来源**：
- 唯一性头衔："小米科技创始人"（只有一位雷军创办小米）
- 唯一性外号："章盟主"（A 股游资圈公认指向章建平）
- 唯一性事件："2025 年入主经纬天地（HK 02477）"（只有钱峰雷做了这件事）
- 唯一性作品/成就："《逆战》原唱"（只有一位歌手张杰唱了这首歌）

**注意事项**：
- 锚定标签有时效性。"茅台董事长"在 2021 年前指向高卫东，2021 年后指向丁雄军——需要加时间限定。
- 并非每个人都能找到 L1 标签。对于高频常见名（如"王伟"），可能不存在任何 L1 标签，此时依赖 L2+L4 组合。

### L2 — 强组合标签

**定义**：单条不唯一，但 ≥2 条组合后形成高区分度的信号。

**判定**：≥2 条 L2 同时命中 → 置信度"高置信"（总分 ≥80）。1 条 L2 命中 + 无 L4 冲突 → 置信度"低置信"。

**来源**：
- 行业 × 公司 × 角色的交叉组合
- 地理 × 机构 × 事件的交叉组合
- 关联人物 × 场景的交叉组合

**示例**：

| 组合 | 指向 | 为什么组合后唯一 |
|------|------|------------------|
| [期货大佬 + 棉花 + 铜] | 葛卫东 | 同时在这两个品种上有百亿级别操作的只有他 |
| [游资 + 龙虎榜常客 + 家族一致行动人] | 章建平 | 游资中带配偶/岳父一起上榜的是标志性特征 |
| [港股 + 入通即崩 + 叠码仔背景] | 钱峰雷 | 同时具备这三条的港股操盘手极少 |

### L3 — 弱组合标签

**定义**：单条信息量低，多人物共享，不能独立判定，但可**累积提升概率**。

**判定**：每条 L3 命中 +15 分，需要在有 L2 或 L5 支撑的情况下才有意义。

**来源**：
- 地域："浙江人""深圳"
- 年龄段："80 后""60 后"
- 教育背景："清华毕业"（太多人共享）
- 通用角色："CEO""投资人""教授"

**注意事项**：L3 标签的价值在于**数量累积**。单独一条"浙江人"无意义，但"浙江人 + 宁波 + 从事投资 + 参与过蚂蚁"就开始有区分度了。

### L4 — 排除标签

**定义**：只要出现，就可以**确定性地排除**某个候选人的信号。

**判定**：任意 L4 命中 → 该候选得分清零（直接从候选池移除）。**L4 的优先级高于 L1-L3** —— 即使其他标签匹配，L4 命中也要排除。

**来源**：
- 领域互斥："奥运会""金牌""国家队" → 排除娱乐人物
- 机构互斥："中国科学院""SCI 论文" → 排除企业家（除非该企业家确为学术出身）
- 时间互斥："2025 年去世" → 排除 2026 年的新闻报道（除非是追忆文章）
- 地域互斥："常驻纽约" → 排除以国内为主要活动范围的人物

**示例**：

| 排除标签 | 排除候选 | 原因 |
|----------|----------|------|
| 奥运会 / 金牌 / 全运会 | 张杰(歌手) | 歌手不可能出现在体育竞技语境 |
| 演唱会 / 专辑 / 巡回 | 张杰(运动员) | 运动员不可能出现在音乐演出语境 |
| A 股 / 龙虎榜 / 证监会 | 张杰(学者) | 学术人物不会出现在股市监管语境 |
| SCI / 论文 / 导师 | 张杰(企业家) | 企业人物不会以学术身份出现 |

### L5 — 领域标签

**定义**：不直接打分，而是**缩小候选池的搜索范围**。

**判定**：先根据领域标签确定候选子集，再在子集内用 L1-L4 进行精细打分。

**来源**：
- 文章板块：财经版 → 企业家/分析师；娱乐版 → 歌手/演员；体育版 → 运动员
- 文章来源：证监会公告 → 上市公司高管；学术期刊 → 学者
- 关键词聚类：出现"股价""市值""营收" → 商业人物

## 三、匹配算法与置信度判定

### 加权评分模型

```
对每个候选人物 C：
  Score(C) = (L1命中数 × 100) + (L2命中数 × 40) + (L3命中数 × 15)
  IF L4命中 > 0 → Score(C) = -∞（淘汰）
  IF L5领域匹配 → 候选池权重 + 方向调整（不加分）
```

### 置信度等级

| 等级 | 条件 | 含义 | 行动 |
|------|------|------|------|
| **确定** | L1 ≥ 1，且无 L4 冲突 | 可以确认就是这个人 | 直接引用该人物信息，无需标注 |
| **高置信** | 总分 ≥ 80，且最高分与次高分差 ≥ 30 | 基本可以确认 | 可引用，报告中标注"高置信识别" |
| **低置信** | 总分 40–79，或分差 < 30 但最高分 > 0 | 有方向但不够确定 | 仅做参考标记，报告中标注"待核实" |
| **无法判断** | 总分 < 40，或所有候选被 L4 淘汰，或无候选 | 无法判断 | 标记"同名歧义"，手动查证原文语境 |

### 决策流程

```
文本中出现人名 N
    │
    ▼
Step 1: 提取上下文窗口（±200 字或同段落）
    ├── 提取共现命名实体（人名/公司/产品/地点/机构）
    ├── 提取关键词（行业/事件/角色）
    └── 提取领域信号（文章板块/来源/关键词聚类）
    │
    ▼
Step 2: 检索候选池
    ├── 查询 Vault 中所有姓名 = N 的人物档案
    └── 若无档案 → 临时搜索（百度百科消歧义页）→ 构建临时候选列表
    │
    ▼
Step 3: 对每个候选打分
    ├── L5 领域筛选 → 缩小候选集
    ├── L4 排除检查 → 淘汰命中候选
    ├── L1 锚定检查 → 直接判定
    └── L2 + L3 累积计分
    │
    ▼
Step 4: 排序 + 判定置信度
    ├── 排序候选按 Score
    ├── 检查分差（最高分 - 次高分）
    └── 输出：最佳匹配 + 置信度
```

## 四、四种标签发现方法

### 方法 1：对比挖掘法（解决高频常见名的核心方法）

**适用场景**：人名高频出现（如张杰、王伟、刘洋），存在 ≥2 个需要区分的候选。

**步骤**：

1. **收集语料**：对每个候选搜索 10–20 篇相关新闻，确保覆盖不同语境
2. **提取伴随词**：从每篇文章中提取该人名 ±100 字内的命名实体和关键词
3. **构建频率表**：统计每个词在各候选语料中的出现频率
4. **计算排他性**：词 W 对候选 C 的排他性 = 在 C 语料中的频率 / 在所有候选语料中的总频率
5. **筛选标签**：
   - 排他性 = 100%（只出现在一个候选）→ L1 或 L2 候选标签
   - 排他性 ≥ 80% → L3 候选标签
   - 排他性 ≤ 30% → 废弃（无区分度）

**示例**（张杰 — 歌手 vs 运动员）：

| 伴随词 | 歌手语料频率 | 运动员语料频率 | 排他性 | 归类 |
|--------|------------|-------------|--------|------|
| 谢娜 | 85% | 0% | 100% | L1 锚定（歌手） |
| 演唱会 | 90% | 0% | 100% | L2 强组合（歌手） |
| 全运会 | 0% | 70% | 100% | L2 强组合（运动员） |
| 金牌 | 0% | 65% | 100% | L4 排除（歌手） |
| 北京 | 30% | 40% | ~50% | 废弃 |

### 方法 2：知识图谱种子法

**适用场景**：人物有百度百科/维基百科词条，快速获取结构化种子标签。

**种子来源与映射**：

| 百科字段 | 映射到的标签层级 | 说明 |
|----------|-----------------|------|
| 配偶 | L1–L2 | 谢娜 → 张杰(歌手)，高度唯一 |
| 儿女 | L2 | 组合使用更有效 |
| 毕业院校 | L3 | 多人物共享，需组合 |
| 职业 | L5 | 用于领域分类 |
| 代表作 | L1–L2 | 《逆战》→ 张杰(歌手)，高度唯一 |
| 任职机构 | L2 | 需注意时效性和唯一性 |
| 出生年月 | L3 | 辅助区分，尤其同名同龄时有用 |
| 籍贯 | L3 | 弱信号 |

**操作步骤**：
1. 打开百度百科"XXX (消歧义)"页面 → 获得完整同名人物列表
2. 逐个打开各人物的百科页面 → 提取 infobox 字段
3. 填入维度矩阵（见方法 3）
4. 标注每个字段的排他性 → 归类到 L1-L5

### 方法 3：维度矩阵法

**适用场景**：初次建消歧档案、系统性排查所有可选标签维度。

**10 维度标准对比表**：

| # | 维度 | 说明 | 典型标签层级 |
|---|------|------|-------------|
| 1 | 全名/别名 | 中文名 + 英文名 + 绰号 + 曾用名 | L1（若唯一） |
| 2 | 出生年/年龄段 | 具体年份或年代 | L3 |
| 3 | 籍贯/常驻地 | 省/市/区域 | L3 |
| 4 | 教育背景 | 学校 + 专业 + 学位 | L3（可升级为 L2 组合） |
| 5 | 职业/角色 | 企业家/基金经理/分析师/官员/学者/艺人/运动员 | L5 |
| 6 | 所属机构 | 现职公司/组织 + 历任 | L2 |
| 7 | 核心作品/成就 | 代表产品/交易/案件/奖项/成绩 | L1–L2 |
| 8 | 关联人物 | 配偶/合伙人/同事/竞争对手/密友 | L1–L2 |
| 9 | 公开事件/争议 | 被处罚/被调查/获奖/重大交易 | L2 |
| 10 | 社交媒体/公众形象 | 微博/抖音 ID/公开言论风格/外号 | L2–L3 |

**操作**：为每个同名候选填写一行，交叉比对找出每个维度上的排他性值 → 归类 L1-L5。

### 方法 4：迭代精炼法

**适用场景**：标签初版完成后，持续优化准确性。

**流程**：

```
初版标签
    │
    ▼
测试（10-20 篇新文章）
    ├── 记录 FP（误报）：标签匹配了，但实际不是这个人
    │   └── 分析原因 → 标签不够排他 → 降级或添加限定条件
    ├── 记录 FN（漏报）：是这个人，但标签没匹配上
    │   └── 分析原因 → 缺少关键标签 → 从漏报文章中提取新标签
    └── 调整标签 → 复测
```

**测试记录模板**：

| 轮次 | 测试文章数 | FP 数 | FN 数 | 调整动作 |
|------|-----------|-------|-------|----------|
| R1 | 10 | 2 | 1 | FP 原因：L3"深圳"标签误命中（另一候选也在深圳）→ 降级该标签 |
| R2 | 10 | 0 | 1 | FN 原因：人物使用英文名 David → 增加英文名 alias |
| R3 | 10 | 0 | 0 | 初步可用 |

## 五、使用流程

### 场景 A：日常新闻阅读中遇到模糊人名

```
新闻中出现"张杰" → 搜索 Vault 中是否有消歧档案
    ├── 有档案 → 提取上下文标签 → 快速人工对照 L1-L4 → 判定置信度
    └── 无档案 → 脑中做最小消歧：这篇文章是财经/娱乐/体育？→ 常识判定
```

### 场景 B：为新人建消歧档案（完整流程）

```
1. 确定目的：此人名在 Vault 中出现的频率是否值得建档案？
   └── 若仅偶尔出现 → 不做完整档案，仅做临时标注
2. 搜索同名人物：百度百科"XXX (消歧义)" → 列出所有候选
3. 填写维度矩阵：10 维度 × N 候选
4. 提取种子标签：百科 infobox → L1-L5 初版
5. 对比挖掘：搜索各候选 10 篇新闻 → 提取排他性伴随词
6. 合并标签：方法 2 + 方法 1 的结果 → 去重 + 分层
7. 迭代测试：10 篇新文章 → FP/FN → 调整 → 复测
8. 发布档案：写入 `operators/` 或独立消歧档案文件
```

### 场景 C：研究报告中引用人物

```
在报告中第一次提到某个人名时：
1. 若该人名有常见同名歧义 → 加注置信度
   示例："张杰（歌手，高置信识别）在 2024 年..."  
2. 若该人名无歧义（如"葛卫东"在 A 股语境）→ 可直接引用
3. 在报告的"引用源"或"方法论说明"中链接 [[person-disambiguation-system]]
```

## 六、常见人名场景

### 场景 1：高频常见名 — 张杰

**候选人物**：

| 候选 | 出生年 | 领域 | 核心区分 |
|------|--------|------|----------|
| 张杰 (C1) | 1982 | 歌手 | 《逆战》《这就是爱》、谢娜丈夫、四川音乐学院 |
| 张杰 (C2) | ~1990 | 田径运动员 | 全运会参赛、国家田径队 |

**标签分层**：

| 层级 | C1（歌手） | C2（运动员） |
|------|-----------|-------------|
| L1 | 谢娜丈夫、《逆战》原唱 | —（暂无唯一锚定） |
| L2 | [演唱会 + 专辑]、[快乐男声 + 天娱] | [全运会 + 田径]、[国家队 + 田径] |
| L4（排除） | 金牌、全运会、锦标赛 | 演唱会、专辑、乐坛 |
| L5 | 娱乐/音乐 | 体育/田径 |

**消歧逻辑**：大部分情况下 L5（领域）即可区分。边缘情况（综艺节目同时请歌手和运动员）→ L2 组合判定。

### 场景 2：同行业同名 — 王伟

多个企业家/高管都叫王伟，如何处理？
- 行业细分：互联网王伟 vs 房地产王伟 vs 金融王伟
- 公司锚定：即使没有唯一外号，"XX 公司 CEO 王伟"中公司名本身就是 L1
- 关联人物组合：与马云同框的王伟 vs 与王石同框的王伟

### 场景 3：角色转换 — 同一人，不同时期

某分析师后来成为基金经理——同一人但不同时期的标签不同：
- **标签时效性标注**：L1[某券商首席分析师, 2018-2022]；L1[某基金基金经理, 2022-至今]
- **时间轴标签**：在消歧档案中增加时间维度

## 七、已知局限与应对

| 局限 | 场景 | 应对 |
|------|------|------|
| **信息不足** | 短新闻仅有姓名 + 模糊描述 | 返回"无法判断"，不做强行判定 |
| **百科不准确** | 百科信息过时或有误 | 标注标签来源 + 数据截止日期；优先用一手来源（公司公告、监管文件） |
| **同人异名** | 同一人有中文名/英文名/绰号 | 在 alias 字段中记录所有已知名称 |
| **跨时空同人** | 同一人不同时期标签完全不同 | 标签加时间限定（起始年–终止年） |
| **自我引用** | 新闻 A 引用新闻 B，信息被稀释 | 追溯原始来源，优先用一手报道 |
| **新人物无档案** | 新闻中新出现的人物无 Vault 档案 | 不需立即建完整档案——做临时标注，待积累 ≥3 次引用后再建 |
| **极端高频名** | "张伟""王芳"等级别的常见名 | 可能永远无法满意消歧——依赖 L4 排除法 + 领域判断，不追求 100% 自动判定 |

---

## 八、与 Vault 现有模式的集成

### 模式映射

| 现有模式 | 消歧系统对应 | 关系 |
|----------|------------|------|
| 【事实】 | 标签的来源标注 | 标签中的"来源"列可引用【事实】条目 |
| 【推断】 | 标签权重的判断依据 | L2 组合逻辑可引用【推断】推理链 |
| 【信号】 | 操作/风险信号（独立维度） | 与消歧标签并列，但目的不同——消歧看"是谁"，信号看"危险吗" |
| 复合识别信号总表 | 消歧标签评分表 | 同构模式：独立信号 + 阈值判定 + 双栏格式 |
| 报告头尾模板 | 消歧档案模板 | 各自的独立模板，共享免责声明 + 双链格式 |
| [[...]] 双链 | 消歧档案双向链接 | 人物档案 → 消歧框架；消歧框架 → 各人物档案 |

### 标签标注约定

在人物档案中新增消歧标签时，放在**分析章节之后、引用源之前**，以独立章节呈现：

```markdown
## 九、人名消歧标签

### L1 锚定标签
| 标签 | 来源 | 有效期 |
|------|------|--------|
| ... | ... | ... |

### L2 强组合标签
...

### L4 排除标签
...
```

这样消歧标签与【事实】/【推断】/【信号】分析章节**物理分离但逻辑互补**——消歧标签告诉你在新闻中"怎么认出这个人"，三层标注告诉你"这个人做了什么、意味着什么"。
