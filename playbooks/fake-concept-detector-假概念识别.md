# 假概念识别三步法

> **触发使用**：当一只股票有多个热门概念标签（AI/航天/半导体/液冷等），但你对它的实际业务一无所知时，用这个清单。

---

## 第一步：查分部报告

```
直接查年报的"分部财务"披露。

Alice 问法：
"XX公司各业务分部的营收、毛利率、利润贡献"
"XX公司分产品和分地区的收入拆解"

判断标准：
✅ 在分部报告里能查到独立营收的 = 真业务
❌ 只有市场概念标签，年报里查不到独立业务线的 = 假概念
⚠️ 营收占比<0.1% = 目前基本还是概念
```

### 利欧案例

| 概念 | 市场炒作 | 分部报告实况 | 判定 |
|------|----------|-------------|------|
| 商业航天 | 航天概念股 | 年报查无此项 | ❌ 纯概念 |
| 半导体 | 芯片概念 | 年报查无此项 | ❌ 纯概念 |
| 液冷 | AI液冷龙头 | 营收<0.2亿（<0.1%） | ⚠️ 有样品，没收入 |
| AI/AIGC | AI营销平台 | 只是营销业务的"工具" | ⚠️ 降本增效不改变本质 |
| 水泵 | 没人提 | 41亿营收，毛利率25% | ✅ 真本业 |

---

## 第二步：看扣非 vs 归母

```
归母净利润 = 主业利润 + 卖资产 + 持股盈亏 + 补贴 + 一次性收益
扣非净利润 = 真正的经营能力

Alice 问法：
"XX公司近五年归母净利润和扣非净利润的差异及原因"

判断标准：
✅ 两者差距持续<20% = 利润质量好
⚠️ 某一年差距巨大 = 有一次性事件
❌ 每年扣非都远低于归母 = 归母利润靠非经常性损益"化妆"

利欧案例：
2023 归母 19.66亿 → 扣非 0.55亿（靠卖理想汽车股票赚了19亿）
→ 看归母以为它是印钞机，看扣非才知道主业微利
```

---

## 第三步：算应收/营收比

```
如果公司"赚钱"但应收账款一直在涨 → 钱挂在纸上，没进到兜里。

Alice 问法：
"XX公司应收账款/营业收入比值、应收账款账龄、坏账计提比例"

判断标准：
✅ 应收/营收 <15% = 回款正常
⚠️ 15-25% = 需要关注
❌ >25% = 利润质量存疑
❌ 应收/归母净利润 >10倍 = 利润大部分是纸上数字

利欧案例：
营收200亿，应收58亿 = 29%
→ 每卖100块，29块还没收到钱
```

---

## 综合判断表

| 指标 | ✅ 真成长 | ⚠️ 需验证 | ❌ 假概念 |
|------|----------|-----------|----------|
| **分部独立营收** | 能查到且有规模 | 有但体量极小 | 查不到或<0.1% |
| **扣非 vs 归母差异** | <20% | 偶尔偏大 | 年年偏大 |
| **应收/营收** | <15% | 15-25% | >25% |
| **毛利率** | 稳定或改善 | 小幅波动 | 持续下降 |

## 典型"假概念"案例：利欧股份

```
市场标签：液冷龙头 + 商业航天 + 半导体 + AI营销
实际情况：水泵年赚10亿毛利，其余全是概念标签

半年30个涨停的逻辑：
→ 每个概念爆发时，游资把同一家水泵公司贴上不同标签反复收割
→ 航天行情 → 涨停（贴航天标签）
→ 液冷行情 → 涨停（贴液冷标签）
→ AI行情 → 涨停（贴AI标签）
→ 但商业航天=零营收、半导体=零营收、液冷<0.1%

研报推波助澜：
标题全是"AIGC赋能增长""AI助力升级""估值双升"
没有一份敢写"这些概念不赚钱"
```

## 四、为什么研报会"猛吹"垃圾股

这不是不专业——恰恰是**专业的"合规话术"**。背后是利益结构：

```
卖方分析师的真实商业模式：

❌ 不是"帮投资者找到好公司"
✅ 是"帮投行部拉到项目" + "帮经纪业务维持交易量" + "维护管理层关系"

利欧股份：
→ 200亿营收 → 每年给券商贡献可观佣金
→ 每次定增/发债 → 投行部赚承销费
→ 得罪利欧管理层 = 这家公司以后不跟你合作
→ 发一份"业绩承压、概念无实质"的报告 = 自断财路

研报措辞解码：
"AI赋能增长" ← 没说赋能了多少（<0.1%营收）
"AIGC落地在即" ← 没说落地是什么（降本增效）
"业绩拐点已至" ← 没说拐点来自哪（后来扣非变亏了）

每句话单独看都是"对"的，组合起来就是误导。
没有一句假话，但通篇都是假象。
```

## 五、资本做局的经典剧本

```
利欧半年30个涨停的背后：

1. 提前埋伏（游资在低位建仓）
2. 制造催化剂（研报吹风 + 短视频灌水 + 蹭概念）
3. 拉涨停吸引关注（散户看到"AI/航天/液冷"冲进来）
4. 高位出货（大股东质押46% → 质押款流向不明）

### 这套局为什么专杀散户

```
散户的行为弱点 = 做局者的入场时机：

1. 舆论造势 → 散户"听说AI/航天/液冷很火"
   → 研报+短视频+财经号同时推 → "应该靠谱"

2. 涨停吸引眼球 → 散户"再不买就晚了"
   → 利欧30次涨停 = 30次FOMO触发器
   → 每次涨停都在喊"你看，真的有资金在做"

3. 概念多 = 安全垫幻觉 → 散户"这个不行还有那个"
   → "航天跌了没事，它还有液冷；液冷不行了，还有AI"
   → 实际上三个概念加起来的营收≈零

4. 股价腰斩后 → 散户"已经跌这么多了，还能跌到哪去"
   → 利欧从高点跌50%到4.8元，看似"便宜了"
   → 但按主业算合理估值才2.9元 → 还有40%下行空间
   → 腰斩之后的反弹 = 做局者最后的出货窗口
```

**利欧的30次涨停，本质上是一台精心设计的"散户注意力收割机"——每一个概念都是一根鱼竿，每次涨停都是一次拉杆，被钓上来的永远是最后相信故事的人。**

关键疑点：
├── 30个涨停完美踩中AI/航天/液冷行情 → 太巧合
├── 研报发布时间和股价拉升高度吻合 → 推波助澜
└── 涨完后 → 业绩"变脸" + 深交所谴责 → 暴雷

研报在这个局里的角色：
它不是策划者，不是执行者——但它是"弹药"。
游资需要"有机构覆盖"给散户"应该靠谱"的错觉。
券商也乐于参与——流量来了、佣金来了。各取所需。
```
