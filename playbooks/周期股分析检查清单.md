# 周期股分析检查清单

> 适用范围：猪周期、鸡周期、水泥、钢铁、煤炭、化工、航运等强周期行业个股分析
> 创建日期：2026-07-21
> 来源：基于牧原/双汇/新希望三家公司分析经验总结

---

## 一、行业周期定位

- [ ] 当前处于周期的哪个阶段？（底部/左侧/右侧/顶部）
- [ ] 本轮周期与历史周期有何不同？（规模化程度提升、政策调控、需求结构变化等）
- [ ] 行业产能利用率当前水平？
- [ ] 供给侧去化进度？（产能/存栏/开工率的环比变化）
- [ ] 需求侧是否出现结构性变化？（如猪肉消费下降、替代品增加等）
- [ ] 政策因素对周期的影响？（储备肉投放/收储、环保政策、产业政策等）

## 二、公司竞争壁垒

- [ ] 成本优势：公司成本 vs 行业平均 vs 领先者，差异多少？
- [ ] 成本优势来源：是什么导致了成本差异？（技术/规模/产业链/资源）
- [ ] 成本优势可持续性：同行能否追赶？需要多长时间？
- [ ] 市场份额：公司市占率及变化趋势
- [ ] 规模效应：产能利用率与固定成本摊薄
- [ ] 产业链一体化程度：是否覆盖上下游？协同效应如何？
- [ ] 技术/专利壁垒：是否有难以复制的技术优势？
- [ ] 品牌壁垒：终端品牌认知度和溢价能力
- [ ] 渠道壁垒：销售网络的深度和广度

## 三、财务健康度

### 3.1 盈利能力

- [ ] 当前盈利/亏损情况？单季利润趋势？
- [ ] 头均/单吨/单件利润？（量化每单位产品的盈利能力）
- [ ] 各业务板块拆分：哪个板块亏？哪个赚？
- [ ] 毛利率、净利率、ROE、ROIC 水平及趋势？

### 3.2 资产负债

- [ ] 资产负债率及趋势（是升是降？）
- [ ] 有息负债 vs 货币资金（偿债压力？）
- [ ] 短期借款 vs 货币资金（短期偿债缺口？）
- [ ] 经营性现金流 vs 净利润（盈利质量？）
- [ ] 筹资现金流（融资能力如何？）
- [ ] 资产减值损失（存货跌价、固定资产减值等）

### 3.3 股东结构

- [ ] 大股东质押率（>50%高风险，<10%安全）
- [ ] 北向/外资持仓比例及变化趋势
- [ ] 高管增减持动作（底部增持=看好后市）
- [ ] AH/ADR折价情况（折价大=国际投资者不认可）
- [ ] 分红政策（高分红=现金充裕+管理层信心）
- [ ] 机构持仓集中度及近期变动

## 四、周期敏感度分析

- [ ] 核心产品价格每变动1单位，对公司利润的影响？（弹性测算）
- [ ] 上行弹性 vs 下行弹性是否对称？
- [ ] 不同价格情景下的利润模拟（至少3个情景）
- [ ] 公司是否有"对冲"业务？（如牧原的屠宰业务）
- [ ] 原材料成本与产品价格的相关性？（猪价↓→肉制品成本↓但屠宰收入↓）

## 五、估值分析

### 5.1 估值方法选择

| 公司类型 | 推荐估值方法 | 原因 |
|----------|------------|------|
| 成熟周期股 | PB + EV/EBITDA | PE在周期底部/顶部会严重失真 |
| 成长型周期股 | PE（远期） + PB | 用远期盈利估值，避免当期PE失真 |
| 消费属性周期股 | PE + 股息率 | 如双汇，盈利稳定，PE有意义 |

### 5.2 估值检查项

- [ ] 当前 PE（TTM）及历史分位数（注意周期底部PE可能虚高）
- [ ] 当前 PB 及历史分位数（周期股看PB更可靠）
- [ ] EV/EBITDA 及历史分位数（适合重资产行业）
- [ ] 一致预期 PE（2026E/2027E）
- [ ] 与可比公司估值对比（同行业横向）
- [ ] 股息率及分红可持续性
- [ ] 头均市值/单吨市值（行业特定指标）

### 5.3 估值陷阱识别

- [ ] **低PE陷阱**：周期高点利润最大时PE最低，此时反而该卖出
- [ ] **高PE陷阱**：周期底部亏损或微利时PE极高，此时反而可能是买入机会
- [ ] **成本口径差异**：不同机构的成本数据可能因口径不同而差异巨大，必须注明来源
- [ ] **AH折价陷阱**：A股看似便宜，但H股折价说明国际投资者不认可

## 六、催化剂与跟踪指标

### 6.1 上行催化剂

- [ ] 行业供给去化加速信号？（产能/存栏连续下降）
- [ ] 产品价格企稳/回升信号？
- [ ] 公司成本持续下降？
- [ ] 新业务突破？（如牧原屠宰盈利、海外扩张）
- [ ] 管理层增减持/回购动作？
- [ ] 政策利好？（收储、补贴、进口限制等）

### 6.2 下行风险

- [ ] 去产能速度不及预期？
- [ ] 产品价格进一步下跌？
- [ ] 成本上升？（原材料涨价、疫病等）
- [ ] 融资环境恶化？（债务到期、信用评级下调）
- [ ] 行业竞争格局恶化？（产能过剩加剧）
- [ ] 黑天鹅事件？（食品安全、疫病、政策突变）

### 6.3 关键跟踪指标清单

| 频率 | 指标 | 数据来源 |
|------|------|---------|
| 月度 | 行业产能/存栏数据 | 农业农村部/协会 |
| 月度 | 产品价格走势 | 交易日/现货市场 |
| 月度 | 公司出栏量/销量 | 公司公告 |
| 季度 | 公司完全成本 | 公司财报/交流纪要 |
| 季度 | 各业务板块利润拆分 | 公司财报 |
| 季度 | 机构持仓变化 | 基金季报/龙虎榜 |
| 不定期 | 高管增减持 | 交易所公告 |
| 不定期 | 行业政策/突发事件 | 新闻/政府公告 |

### 6.4 拐点确认信号

> 建议设定至少3个可验证的拐点确认信号，集齐2个以上可初步确认反转。

示例（猪周期）：
1. 能繁母猪存栏连续3个月环比下降
2. 产品价格（猪价）稳在盈亏平衡线以上
3. 公司季度扭亏为盈

## 补充：价值陷阱鉴别清单（2026-07-21 追加）

> 适用范围：所有低估值（破净/低PE/高股息）但可能暗藏陷阱的标的
> 来源：基于招商银行案例分析提炼

### 一、三层诊断法

只看"便宜"就买入是价值陷阱的根源。必须通过三层诊断来判断：

```
第一层：估值本身（看起来便宜）
    ↓
第二层：基本面趋势（为什么便宜）
    ↓
第三层：未来催化剂（什么时候变贵）
```

| 层次 | 检查内容 | 工具/指标 |
|------|---------|---------|
| **第一层：估值** | PB/PE/股息率处于什么水平？ | 历史分位数、可比公司对比 |
| **第二层：趋势** | 为什么这么便宜？ROE趋势？营收增速？核心指标变化方向？ | 连续3年ROE变化、营收增速、净息差、不良率等 |
| **第三层：催化剂** | 有没有明确的拐点信号？需要什么条件才能变贵？ | 关键指标企稳、新增长点出现、行业政策变化 |

### 二、机构背离信号（核心预警）

| 信号 | 表现 | 含义 | 危险程度 |
|------|------|------|---------|
| **评级高但配置低** | 机构评级买入/增持，但主动型基金配置比例极低 | 嘴上说好，手上没买，说明不认为现在是好时机 | 🔴 高 |
| **举牌但非战略** | 大资金举牌，但定性为"财务投资" | 看中分红，不代表看好股价上涨 | 🟡 中 |
| **目标价高但持续跌** | 机构目标价远高于现价，但股价持续下行 | 目标价可能基于过于乐观的假设 | 🟡 中 |
| **高管减持/回购缺位** | 公司喊低估但管理层不买、不回购 | 管理层自己都不信 | 🔴 高 |

### 三、不同类型"低估值"的鉴别

| 类型 | 特征 | 典型标的 | 投资策略 |
|------|------|---------|---------|
| **周期底部型** | 行业性亏损，但公司成本优势/市场份额仍在 | 牧原股份（周期底部） | 左侧布局，等待周期反转，适合高风险偏好 |
| **价值陷阱型** | 基本面持续恶化，低估值是对恶化的合理定价 | 民生银行（PB 0.29） | 避免抄底，除非有明确拐点信号 |
| **优质资产承压型** | 公司优秀，但行业系统性承压，估值被拖累 | 招商银行（PB 0.89） | 可收息，但不要期待估值扩张，适合低风险偏好 |
| **成长放缓型** | 高增长→增速放缓，市场重新定价 | 伊利、海天等消费龙头 | 等待估值消化+新增长点 |

### 四、银行股五维分析模型

| 维度 | 关键指标 | 行业参考值 | 优秀值 | 警报值 |
|------|---------|-----------|--------|--------|
| 资产质量 | 不良率+拨备覆盖率 | 不良率1.3-1.6% | 不良率<1.0% | 拨备覆盖率<150% |
| 盈利能力 | ROE+净息差 | ROE 8-12% | ROE>13% | 净息差<1.4% |
| 增长动力 | 营收增速+利润增速 | 0-3% | 营收增速>5% | 连续负增长 |
| 股东回报 | 股息率+分红率 | 股息率4-6% | 分红率>30% | 分红率下降 |
| 估值安全 | PB+PE历史分位 | PB<1 | PB处于历史10%以下 | PE持续失真 |

### 五、关键问题清单

在分析任何低估值标的时，先回答以下问题：

1. 这家公司为什么便宜？（必须给出具体原因，不能只说"市场错杀"）
2. 这个原因会持续恶化还是即将改善？
3. 机构评级和实际配置是否一致？（嘴上说好 vs 手上买没买）
4. 管理层是否在用自己的钱买入？（回购/增持）
5. 有没有明确的"变贵"催化剂？（需要什么条件才能修复估值）
6. 如果持有3年不涨，能不能接受？（股息率是否提供足够的安全垫）
7. 如果基本面继续恶化，下行空间有多大？
8. 同行业对比：它是行业里相对最好的，还是绝对意义上的好公司？
