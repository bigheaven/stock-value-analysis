# 行业估值差异指南：不同行业用什么指标判断贵不贵

> **定位**：价值投资的"通用语言"。不同行业适用完全不同的估值锚——用 PE 判断银行、用 PB 判断消费、用 PS 判断 SaaS，都是致命的错误。本指南提供系统性的行业估值对照表。
>
> **触发使用**：每次分析新标的，先确定行业，再用本指南选择正确的估值指标。

---

## 一、核心原则

```
"估值指标不是通用的——你必须用行业通用的语言来估值。"

PE（市盈率）是最常用的，但不是万能的：
├── 对周期性行业用 PE → 在顶部会误判为"便宜"
├── 对高负债行业用 PE → 忽略了杠杆风险
├── 对亏损公司用 PE → 毫无意义
└── 对轻资产公司用 PB → 毫无意义
```

## 二、行业估值对照表（主表）

| 行业 | 首选指标 | 次选指标 | 不可用/慎用 | 合理范围 | 估值逻辑 |
|------|---------|---------|------------|---------|---------|
| **银行** | PB + ROE | 股息率 | PE | PB 0.5-1.2（ROE 越高越贵） | 资产质量决定 PB，ROE 决定 PB 溢价 |
| **保险** | P/EV | PB | PE | P/EV 0.5-1.5 | 内含价值是保险的真实净资产 |
| **消费（品牌）** | PE + PEG | EV/EBITDA | PB（轻资产无意义） | PE 15-30 | 品牌溢价 → 稳定盈利 → PE 估值 |
| **消费（渠道）** | PE + 同店增速 | PS | PB | PE 10-20 | 同店增长是核心驱动力 |
| **科技（成熟）** | PE + PEG | FCF Yield | PS | PE 15-30 | 有利润后用 PE，高增速给 PEG |
| **科技（SaaS）** | PS + EV/Revenue | 续约率 + LTV/CAC | PE | PS 5-15x | 利润被订阅成本前置，PS 更合理 |
| **科技（早期/亏损）** | PS | P/MAU（用户） | PE/PB | PS 2-10x | 靠收入增速和用户增长定价 |
| **医药（大药企）** | PE + 管线折现 | 股息率 | PB | PE 12-20 | 仿制药专利悬崖影响 PE |
| **医药（Biotech）** | DCF（管线层） | 现金/市值 | PE/PS | 现金跑道 + 管线价值 | 没有收入，全靠管线折现 |
| **矿业/能源** | EV/EBITDA | P/NAV | PE（周期顶部误导） | EV/EBITDA 4-8x | 周期底部用 PE 会误判为"贵" |
| **公用事业** | 股息率 + P/B | EV/EBITDA | PEG | 股息率 3-6% | 稳定现金流 = 股息 + 监管 ROE |
| **房地产** | P/NAV（折价率） | 股息率 | PE | 折价 0-50% | 资产重估 vs 市场价 |
| **REITs** | P/FFO | 股息率 | PE | P/FFO 10-20x | FFO 是 REITs 的"利润" |
| **基础设施** | EV/EBITDA + 股息率 | DCF | PE | EV/EBITDA 6-12x | 长期稳定现金流折现 |
| **券商** | PB + ROE | PE | 股息率 | PB 0.8-2.0 | 牛市 PB 扩张，熊市 PB 收缩 |
| **航空** | EV/EBITDAR | P/B | PE | EV/EBITDAR 3-6x | 租赁负债影响，EBITDAR 更可比 |
| **零售** | PE + 同店增速 | PS | PB | PE 10-20 | 同店增速 + 坪效是关键 |
| **电信** | EV/EBITDA + 股息率 | FCF Yield | PE | EV/EBITDA 4-7x | 高 CAPEX，EBITDA 更可比 |

## 三、估值指标选择决策树

```
拿到一只股票，按以下顺序选择估值方法：

1. 它盈利吗？
   ├── 是 → 继续
   └── 否 → 用 PS、P/用户、或管线 DCF（Biotech）

2. 它是重资产还是轻资产？
   ├── 重资产（银行、矿业、地产）→ 用 PB 或 P/NAV
   └── 轻资产（消费、科技、服务）→ 用 PE 或 PS

3. 它是周期型还是稳定型？
   ├── 周期型 → 用 EV/EBITDA 或 PB（取周期均值）
   └── 稳定型 → 用 PE、PEG 或 DCF

4. 它有高负债吗？
   ├── 是 → 用 EV/EBITDA（企业价值/息税折旧摊销前利润）
   └── 否 → 用 PE 即可

5. 它大量分红吗？
   ├── 是 → 加看股息率 + 派息率
   └── 否 → 看 FCF Yield
```

## 四、常用估值指标详解

### PE（市盈率）
```
适用：盈利稳定、非周期性、轻资产
陷阱：被一次性收益扭曲、周期顶部 PE 最低
修正：用扣非净利润、用 3-5 年平均利润（席勒 PE）
```

### PB（市净率）
```
适用：银行、保险、券商、矿业、地产
陷阱：无形资产重的公司 PB 无意义、商誉虚高、清算价值 ≠ 账面价值
修正：用有形净资产（剔除商誉和无形资产）
```

### EV/EBITDA（企业价值倍数）
```
适用：高负债、重资产、并购比较
陷阱：EBITDA 不是现金流（忽略 CAPEX）
修正：配合 FCF 和 CAPEX 使用
```

### PS（市销率）
```
适用：亏损公司、SaaS、高增长但利润被前置
陷阱：毛利率低的公司 PS 再低也贵
修正：PS × 毛利率 = 调整后 PS（毛利率越高，PS 可以更贵）
```

### PEG（市盈率/增长率）
```
适用：稳健增长型、快速增长型
陷阱：增长率不可持续、用过去暴增而非未来增速
修正：用未来 3-5 年可持续增长率
```

### FCF Yield（自由现金流收益率）
```
适用：所有行业（最通用的质量指标）
公式：FCF Yield = 自由现金流 / 市值
标准：> 5% = 合理，> 8% = 便宜，< 3% = 偏贵
```

## 五、跨行业可比框架

当你需要在不同行业之间比较时（比如"银行股 vs 消费股，谁更便宜？"），用统一框架：

```
统一估值框架：FCF Yield + ROIC 矩阵

纵轴：ROIC（越高越好，反映生意质量）
横轴：FCF Yield（越高越好，反映估值便宜）

        高 ROIC
          │
  ★ 便宜好生意  │  贵但好生意
  （买入）      │  （持有/等待）
          │
  ───────────────┼──────────────→ FCF Yield
          │
  便宜差生意    │  贵且差生意
  （价值陷阱）  │  （回避）
          │
        低 ROIC

理想标的：右上角（高 ROIC + 高 FCF Yield）= 便宜好生意
```
