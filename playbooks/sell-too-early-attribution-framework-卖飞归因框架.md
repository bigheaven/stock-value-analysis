# 卖飞归因框架：四型分类 + 判别公式

> **免责声明**：本框架为行为分析工具，不构成投资建议。
>
> **使用场景**：建仓前反向验证、持仓中定期审视、面临卖出冲动时的决策前自检。
>
> **配套产物**：[[sell-too-early-pre-sale-checklist]]（卖出前的 12 条自我拷问）、[[legendary-sell-too-early]]（五案全景复盘）

## 一、四型速查

| 类型 | 一句话判别 | 典型触发信号 | 历史案例 | 最容易犯的错 |
|---|---|---|---|---|
| **被迫卖家** | "我想拿但拿不住" | 缺现金/保证金追缴/杠杆断裂/基金赎回 | 孙正义 2019 清仓英伟达、李泽楷 2001 卖腾讯（副型） | 把投资决策当成流动性决策来做——事后后悔说"我当时是看好的" |
| **纪律卖家** | "我看好但仓位/估值不允许" | 仓位 >X%/PE 超历史区间/集中度风控 | 巴菲特 2024—25 减持苹果 | 高估了纪律的"精确度"——17x PE 和 22x PE 谁规定哪个是上限？ |
| **从未信仰者** | "我本来就没想长拿" | 投资逻辑一开始就不清晰/跟风/别人推荐的 | 李泽楷 2001 卖腾讯（主型） | 用"我是做短线的"来合理化任何卖出——问题不在短长，在逻辑是否自洽 |
| **止盈换仓者** | "赚够了，换更好的" | 大幅浮盈 + 新机会出现 + 觉得旧标的高估 | 章建平 2026 Q1 清仓寒武纪 | 把"这个贵了"和"那个更好"混为一谈——两者都需要独立验证 |

### 主型 / 副型

现实中的卖出决策很少是单一类型的。一个典型的例子：

- **巴菲特减持苹果**：主型 = 纪律卖家（仓位 50% 上限 + PE 27x），副型 = 被迫卖家（95 岁 + 交接——隐含的"被迫"不在现金层面，在时间层面）
- **李泽楷卖腾讯**：主型 = 从未信仰者，副型 = 被迫卖家（180 亿美元并购债）

**判别规则**：先看主型——"如果没有这个约束条件，我还会卖吗？"如果答案仍然为"会"，主型正确。如果答案变成"不会"，则主型应该被重新归类。

## 二、逐型展开

### 2.1 被迫卖家——"我想拿但拿不住"

**行为模式**：因为流动性需求（还债、追加保证金、基金赎回、生活开支）被迫出售。大多数情况下，卖出者内心是看好持仓的，但外部约束不允许继续持有。

**心理机制**：流动性危机下的决策不是投资决策，是生存决策。当房子着火时，你不会去挑哪个灭火器颜色最好看——你会抓起最近的灭火器。在资产组合里，"最近的灭火器"通常是流动性最好的资产——恰好也可能是最有潜力的资产。

**最容易犯的错**：事后用"我当时其实是看好的"来合理化懊悔——但当时的卖掉是注定的，因为流动性问题不解决，你根本没有"看好"的资格。

**应对策略**：
1. **永远不要让仓位规模超过流动性承受能力**——如果持仓中任何一笔的最大回撤会导致被迫卖出，仓位就太大了。
2. **区分"紧急储备金"和"投资组合"**——绝不用投资组合里的钱解决流动性问题。
3. **如果有流动性风险的苗头，先卖最不看好、流动性最好的**——而不是卖最赚钱的那个。

### 2.2 纪律卖家——"我看好但原则不允许"

**行为模式**：因为仓位上限、估值纪律、风险预算等内部规则而主动减仓。卖出者对标的可能仍然看好，但自己给自己划了一条线。

**心理机制**：纪律是在用"规则"替代"运气"。巴菲特之所以卖出苹果不是因为不喜欢苹果，而是因为**没有纪律的长期持有是赌博**。他知道苹果可能继续涨，但他也知道如果他的框架不成立（50% 仓位集中在一只科技股），他的长期存活概率会下降。

**最容易犯的错**：把主观偏好伪装成纪律。"我觉得贵了"不等于"我的框架说贵了"——前者是直觉，后者需要可量化的标准。没有量化标准的纪律不是纪律，是借口。

**应对策略**：
1. **建仓时就把卖出纪律写好**——PE 超过 X、仓位超过 Y%、逻辑变化后 Z 周内必须重新评估——不给自己留"我到时候再判断"的空间。
2. **纪律卖出的仓位必须有替代方案**——巴菲特的方案是国债（4% 安全收益），你的方案是什么？
3. **区分"估值纪律"和"择时冲动"**——如果你在 15x PE 时说"等它跌到 10x 再买回来"，你真的会买回来吗？历史表明多数人不会。

### 2.3 从未信仰者——"我本来就没想长拿"

**行为模式**：买入时的逻辑就不支撑长期持有——可能是跟风、别人推荐、或者只是一笔战术性博弈。卖出的时机可能看起来是"卖飞"，但实际上不存在"拿住"的前提条件。

**心理机制**："从未信仰"不是贬义——它恰恰是一种诚实。问题是很多人在买入时没有诚实地面对自己：明明只是想做个短线反弹，结果套住了就自称"价值投资"；明明只是因为别人推荐就买了，回头涨了就说是"自己研究过"。

**最容易犯的错**：**买入和卖出使用不同的逻辑框架。** "我买是因为它跌得多"→"我卖是因为它涨回来了"——这个逻辑链条里的每一步都不涉及对这家公司本身的任何判断。如果你买一只股票的理由在任何一本投资教科书上都不成立，你就不可能指望按那本教科书的逻辑"拿住"。

**应对策略**：
1. **每笔买入都写下"我持有多久"和"我在等什么"**——不用精确，但要有边界。
2. **如果买的时候是"试一下"，卖的时候就不要说"差一点就成功了"**——逻辑要自洽。
3. **区分"不看好"和"不了解"**——不了解的可以研究，不看好的是真的不看好。两者不要混淆。

### 2.4 止盈换仓者——"赚够了，换更好的"

**行为模式**：持仓已经产生了大幅盈利，认为当前价格已充分定价或即将见顶，将资金调仓到另一个（自认为）更有潜力的机会。

**心理机制**：这是最"聪明"的卖飞类型——因为它不是在减仓，是在**换仓**。但"这个贵了"和"那个更好"是两个独立命题：你需要分别验证"旧的真的高估了"和"新的真的更好"。很多人用"那个更好"作为"这个卖飞了也不心疼"的情感缓冲——这是一种自我安慰的叙事。

**最容易犯的错**：**"更好"的验证标准太松。** 因为已经大赚了，所以对新的机会放宽标准——"反正都是赚来的钱"。这是"赌场利润幻觉"：赢了钱之后下注更大、更随意。

**应对策略**：
1. **换仓前，对新的标的做** [[deep-value-vs-trap-checklist-深度价值vs价值陷阱]] **的全套验证**——不要因为有了浮盈就降低新买入的标准。
2. **部分止盈比全部清仓更健康**——留 20—30% 的仓位作为"我不确定"的仓位，比"一刀切"更能保护你不受卖飞的情感冲击。
3. **换仓后给自己设 3 个月冷静期**——如果 3 个月后新旧标的的走势让你后悔，重新审视判断。如果走势让你庆幸，不要急着加仓。

## 三、使用场景

### 场景 1：建仓前——反向验证

在买入之前，用四型框架问自己："如果未来我需要卖这只股票，最可能的原因会是什么？"
- 如果答案是"缺钱" → 仓位太大或流动性太紧，调整。
- 如果答案是"涨到我设定的目标" → 设定好纪律，写下来。
- 如果答案是"我也不知道" → 回到 [[deep-value-vs-trap-checklist-深度价值vs价值陷阱]]，先把买入逻辑理清。

### 场景 2：持仓中——定期自检

每季度翻出四型速查表，对照自己的持仓状态：
- 有没有出现"被迫卖家"的触发信号（现金紧张了？杠杆加了？）
- 有没有踩中"纪律卖家"的边界（仓位占比超了吗？PE 到哪了？）
- 有没有从"信仰者"悄悄变成"从未信仰者"（当初看好的理由还在不在？）

### 场景 3：卖出冲动时——强制自检

卖出之前，用四型归类自己的动机 → 然后用 [[sell-too-early-pre-sale-checklist]] 做三级拷问 → 对照每型的"最容易犯的错"看自己有没有踩坑 → 再做决策。
