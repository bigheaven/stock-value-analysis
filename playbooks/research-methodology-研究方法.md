# 研究方法：从"叙事搜索"到"数据挖矿"

> **定位**：每次分析新公司时提醒自己——不要只找故事，要找数字。
>
> **触发使用**：拿到一只新标的，三工具启动前先过这篇。

---

## 一、核心原则：数字 > 叙事

```
❌ 叙事搜索（我之前的习惯）：
"XX公司 周期属性 竞争格局 财务健康" → 出来一堆泛泛而谈的文章

✅ 数据挖矿（短视频创作者的思路）：
"XX公司 自产矿毛利率拆解" → 出一堆具体数字
"XX公司 境内外利润率对比" → 出一个反直觉的发现
"XX公司 金价下跌10%利润敏感性" → 出一个量化的风险测算
```

**一个反直觉的数据发现，价值远超十段宏观叙事。**

---

## 二、Alice 该怎么用：直接要数字，不是要观点

### 正确的问法（数据优先）

```
✅ "列出XX公司2025年报中：
  - 各业务分部的毛利率、收入占比、利润贡献
  - 境内外业务的利润率对比
  - 核心产品的单吨成本、售价、产能规划
  - 前五大客户的收入占比
  - 在建工程/固定资产/产能利用率
  - 应收账款账龄分布和坏账计提比例
  - 大股东质押比例和近期增减持情况"

✅ "XX公司的存货结构、跌价准备计提比例、周转天数"

✅ "对比XX公司和同行A、B、C的：
  - PE、PB、PS、PEG
  - 毛利率、净利率、ROE
  - 资产负债率、经营现金流/净利润比
  - 分红率、股息率、分红增长记录"
```

### 错误的问法（叙事优先）

```
❌ "分析XX公司的竞争优势和风险因素"
❌ "XX公司值不值得投资"
❌ "XX公司的发展前景"
```

### Alice 的独特价值

Alice 能做的事，Tavily 做不到：
- **分部财务数据**：Tavily 搜到的是研报摘要，Alice 能直接查 Wind 数据库里年报的分部披露
- **实时行情**：股价、期货价格的精确数值
- **可比公司筛选**：按财务指标一键筛选同行
- **敏感性分析**：原材料价格变动对利润的影响测算

## 三、Tavily 该怎么搜：搜索词要"数据化"

### 正确的搜索词

```
✅ 找毛利拆解：
"XX公司 毛利率 拆解 矿山自产 冶炼 2025 2026"

✅ 找成本结构：
"XX公司 单吨成本 产能 万吨 规划 在建工程"

✅ 找估值对比：
"XX公司 PE PB PEG 同行 对比 估值水位 历史分位"

✅ 找筹码面：
"XX公司 北向资金 持股比例 大股东 质押 增减持"

✅ 找卖方数据：
"XX公司 目标价 盈利预测 EPS 2026 2027 券商 研报"
```

### 错误的搜索词

```
❌ "XX公司 深度分析"（太泛）
❌ "XX公司 怎么样"（没用）
❌ "XX公司 发展趋势"（全是废话）
```

---

## 四、IMA 该怎么搜：关键词要"行业化"

IMA 订阅知识库搜的是研报**标题**，所以关键词必须是报告中可能出现的术语：

```
✅ 行业术语：
"钴 供需 缺口" → 出行业深度报告
"镍 印尼 配额" → 出政策分析报告
"华友 毛利率 拆解" → 出个股深度研报

❌ 避免口语化：
"华友钴业 好不好 值得买" → 搜不到
"钴价 现在 怎么样 会跌吗" → 搜不到
```

## 五、标准流程（每次分析新公司必过）

```
第1步：Alice — 直接要数字
  → 分部毛利率、境内外利润率、单吨成本、产能路线图
  → 可比公司财务对比表
  → 大股东质押/增减持

第2步：Tavily — 搜缺失的数据
  → 用"数据化"关键词搜公开研报
  → 优先搜卖方研报PDF（目标价、盈利预测、敏感性分析）

第3步：IMA — 搜行业背景
  → 用行业术语搜研报标题
  → 只取标题作"线索"，不指望读原文

第4步：Alice — 验证和补充
  → 如果前面的数据有缺口，用具体问题再问一次
  → 做敏感性测算（"如果X跌20%，利润跌多少"）

第5步：落地文档
  → 优先保留数字和量化结论
  → 叙事部分放后面
  → 标注每个关键数字的来源（Alice/Tavily/IMA）
```

## 六、容易被忽略的"金矿数据"

这些数据Alice和Tavily都能拿到，但经常被遗漏：

```
1. 合同负债变化（环比涨30%+ = 下游订单在爆发）
2. 预付款项暴增（说明公司在抢上游产能，需求前景极好）
3. 大股东质押率（>40% = 股价暴跌可能触发补质押甚至强平）
4. 北向资金持仓变化（一个季度砍仓30%+ = 外资在逃）
5. 境外vs境内利润率对比（境外更高 = 出海是加分项非减分项）
6. 在建工程/固定资产比（>30% = 产能即将爆发，<10% = 增长接近停滞）
7. 存货中原材料vs产成品的比例（产成品积压 = 滞销预警）
8. 对联营企业投资收益的变动（关联公司的利润质量）
```
