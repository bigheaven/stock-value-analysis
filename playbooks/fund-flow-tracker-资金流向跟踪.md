# 资金流向跟踪指南：如何提前发现公募调仓方向

> **目的**：不用等到季报出来才看到资金流向，用日常数据源实时推断机构资金的迁徙方向。
>
> **适用范围**：港股通标的（腾讯/阿里/小米/美团等）、A 股主题/行业轮动

---

## 一、核心原则：用高频数据推断低频信号

公募基金季报每季度一次（1/4/7/10 月出），等你看到的时候股价已经反应了。但公募调仓不是一天完成的——**它是一个持续数周至数月的过程**，每天都会留下痕迹。

| 数据源 | 频率 | 滞后性 | 看什么 |
|--------|------|--------|--------|
| 港股通十大活跃股 | **每日** | T+1 | 机构在买/卖哪些港股 |
| 行业主力资金流向 | **每日** | 实时 | 钱往哪个行业板块流 |
| ETF 份额变化 | **每日** | T+1 | 资金通过 ETF 在布局什么 |
| 龙虎榜 | 事件驱动 | T+1 | 机构席位的具体买卖操作 |
| 融资融券余额 | **每日** | T+1 | 杠杆资金的方向 |
| 公募净值估算 | **每日** | 实时 | 公募整体仓位变化趋势 |
| 公募季报 | 每季度 | 1-2 月 | 唯一准确的持仓数据 |

**正确节奏**：每天看前三项 → 每周做一次方向判断 → 每季度用季报来验证和校准。

---

## 二、最核心的跟踪工具（每天看）

### 2.1 港股通十大成交活跃股（T+1，每日更新）

这是**最有用的实时工具**。港股通（南向资金）= 大陆机构资金（含公募、保险、私募）买港股的数据。

**去哪里看：**
- 东方财富网 → 数据中心 → 资金流向 → 港股通资金流向
- 或直接搜索「港股通十大成交活跃股」
- 港交所官网：https://www.hkexnews.hk 的「沪深港通」专区

**怎么看：**

| 信号 | 含义 |
|------|------|
| 腾讯连续 3+ 天出现在净卖出前十 | 大陆机构在系统性减仓腾讯 |
| 腾讯连续 3+ 天出现在净买入前十 | 大陆机构在回补腾讯 |
| 中际旭创/寒武纪等持续在净买入前十 | 大陆机构在加仓 AI 硬件 |
| 南向资金整体单日净买入 > 50 亿 | 大陆资金在系统性抄底港股 |
| 南向资金整体持续净流出 | 大陆资金在系统性撤出港股 |

**Q2 的真实信号**（复盘参考）：
- 6 月中旬起：腾讯开始频繁出现在港股通净卖出前十
- 7 月初：恒生科技 ETF 份额持续缩水，AI 硬件 ETF 份额扩大
- 7 月 21 日：季报披露证实——如果你每天跟踪这些数据，**提前 1-2 周就能感觉到方向**

### 2.2 行业/板块主力资金流向（每日实时）

**去哪里看：**
- 东方财富 → 数据中心 → 资金流向 → 行业资金流向
- 同花顺 → 资金流向 → 行业板块排行
- 通联数据（DataYes）

**怎么看：**

| 信号 | 含义 |
|------|------|
| 光模块/半导体/AI 芯片持续净流入 | AI 硬件是当前主线 |
| 互联网/平台经济持续净流出 | 资金在撤出平台经济 |
| 银行/红利板块逆势净流入 | 资金在转向防御 |
| 某板块单日净流入占成交额 > 5% | 机构在建仓该板块 |

关键不是看一天，而是看**连续 5 天以上的趋势**。单日数据噪音大，但连续一周的方向就很说明问题。

### 2.3 ETF 份额变化（T+1，每日更新）

ETF 份额变化能反映**被动资金+部分机构资金**的流入流出。比个股资金流向更干净（剔除游资噪音）。

**去哪里看：**
- 东方财富 → ETF 频道 → 资金流向
- 天天基金 → ETF 板块 → 份额变化排行

**怎么看：**

| 信号 | 含义 |
|------|------|
| 恒生科技 ETF（513XXX）份额持续减少 | 资金撤出港股科技 |
| 通信 ETF（515XXX）份额大幅增长 | 资金涌入 AI 算力基建 |
| 半导体 ETF（512XXX）份额快速膨胀 | 资金涌入半导体 |
| 宽基 ETF（沪深 300/中证 500）份额增长 | 机构通过宽基 ETF 建仓 |

## 三、进阶工具（每周看）

### 3.1 Wind Alice（你已配好）

能直接获取结构化数据：

```bash
cd ~/.claude/skills/alice-financial-copilot && node scripts/cli.mjs \
  --prompt "最近一个月港股通南向资金各行业净买入净卖出排名，以及腾讯阿里小米的南向资金净买入额变化" \
  --no-wait --session-scope claude-code
```

典型查询：
- 公募基金行业配置周度估算
- 港股通个股资金流向明细（分日度数据）
- 北向资金（陆股通）行业配置变化
- ETF 份额变化排行

### 3.2 龙虎榜（事件驱动）

当个股出现**日涨跌幅偏离值 > 7%** 等异常时，交易所披露龙虎榜。

**去哪里看：**
- 东方财富 → 数据中心 → 龙虎榜

**看什么：**

| 席位 | 含义 |
|------|------|
| **机构专用**（买入前列）| 公募/保险在建仓 |
| **机构专用**（卖出前列）| 公募/保险在减仓 |
| **深股通/沪股通专用** | 外资在买卖 |
| 多家机构同步买入 | 板块级建仓信号 |

## 四、信号组合：当多个数据源指向同一方向

单一数据源可能误判，但**当三个数据源指向同一方向时，结论高度可靠。**

### 做多信号组合（资金在回流）

| 信号 | 数据源 | 确认度 |
|------|--------|--------|
| 港股通连续净买入腾讯 | 港股通十大活跃股 | ★★★ |
| 恒生科技 ETF 份额企稳回升 | ETF 份额 | ★★★ |
| 互联网板块主力资金由净流出转净流入 | 行业资金流向 | ★★★ |
| 腾讯融资余额回升 | 融资融券 | ★★ |
| **三个以上同时触发** | — | **高确定性** |

### 做空信号组合（资金在撤离）

| 信号 | 数据源 | 确认度 |
|------|--------|--------|
| 港股通连续净卖出腾讯/阿里/小米 | 港股通十大活跃股 | ★★★ |
| AI 硬件 ETF 份额持续增长、恒生科技 ETF 缩水 | ETF 份额 | ★★★ |
| 光模块/半导体板块持续净流入、互联网净流出 | 行业资金流向 | ★★★ |
| 龙虎榜机构席位卖出腾讯/阿里 | 龙虎榜 | ★★ |
| **三个以上同时触发** | — | **高确定性** |

## 六、关键局限

1. **港股通数据只看得到大陆资金**，看不到外资（国际投行/长线基金）的动作
2. **机构专用席位不一定是公募**，也可能是保险/社保/私募
3. **南向资金净买入 ≠ 公募基金行为**，里面包含散户通过港股通买港股的部分
4. **ETF 份额变化包含大量套利资金**，不完全反映真实投资需求
5. **唯一准确的数据仍然是公募季报**——以上都是推断和信号，不是确凿证据
