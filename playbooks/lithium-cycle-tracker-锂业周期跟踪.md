## 一、行业全景：锂产业链地图

```
上游资源开采                中游锂盐加工              下游应用
═══════════════════════════════════════════════════════════════

锂辉石矿 (澳洲/非洲/中国)  ─→  碳酸锂 (LFP电池)  ─→  动力电池 (电动车 ~53%)
盐湖卤水 (南美/中国)       ─→  氢氧化锂 (三元/NCM) ─→  储能电池 (ESS ~17% ↗)
锂云母 (江西宜春)          ─→  金属锂/其他        ─→  消费电子/传统工业

核心上市公司：
┌─────────────────────────────────────────────────────────────┐
│ 上游资源端                    中游加工端                    │
│ ★ 天齐锂业 (Greenbushes 51%)  ★ 赣锋锂业 (全球最大锂盐商) │
│   盐湖股份 (察尔汗)              雅化集团                   │
│   紫金矿业 (3Q/Manono/拉果错)   盛新锂能                   │
│   中矿资源                      天华新能                   │
│   藏格矿业 (麻米错)                                        │
└─────────────────────────────────────────────────────────────┘

天齐 vs 赣锋 核心差异：
─────────────────────────────────────────────────────────────
              天齐锂业                  赣锋锂业
定位          上游资源型                 全产业链型(资源+加工+电池)
核心资产      澳洲Greenbushes锂辉石      全球多矿源+锂盐产能+固态电池
              + 智利SQM 21.9%股权
锂矿自给率    ~100%                      ~50%(提升中)
毛利率        更高(~70%+)                较低(~40-50%)
锂价弹性      更大(矿端利润直接放大)     大但需扣外购矿成本
周期波动      更大                       相对平滑(电池业务对冲)
概念溢价      纯资源周期                  固态电池+储能+一体化
主要风险      海外地缘(澳洲FIRB/智利)    外购矿成本 vs 锂盐售价剪刀差
```

## 二、周期定位：用光谱框架给锂行业打分

基于 [[cycle-growth-spectrum-framework-周期光谱框架]] 三指标：

```
锂行业 2026.7 光谱定位

渗透率：电动车国内 >50% 🔴 周期化
        储能全球 5-30% 🟢 成长
        → 新旧动力交替，灰色地带 ⚡

CAPEX：  重资产(CAPEX/营收 >15%)，在建工程飙升 🔴
        → 周期见顶信号

壁垒：   上游资源 = 资本壁垒（钱可以复制）
        盐湖提锂技术壁垒在收窄
        → 周期股本质

综合判定：周期偏成长（储能增量）→ 纯周期（储能成熟后）
择时 > 择股，高PE买低PE卖
核心盯：供给拐点、库存周期、CAPEX方向
```

## 三、三层跟踪指标体系

### 第一层：领先指标（6-12个月前瞻）

#### 1.1 CAPEX / 在建工程趋势 ⭐⭐⭐

| 看什么 | 数据源 | 频率 |
|--------|--------|------|
| 澳洲矿商季报产能指引 (PLS/IGO/MIN/ALB) | 公司公告、SMM | 季度 |
| 宁德枧下窝复产进度、月度产量 | SMM、百川盈孚 | 月度 |
| 非洲新矿投产时间表 (赣锋Goulamina/紫金Manono/海南Bougouni) | 公司公告 | 季度 |
| 南美盐湖产能爬坡 (SQM/ALB/力拓Rincon/赣锋Mariana) | 公司季报 | 季度 |
| 全行业在建工程同比增速 | 公司年报 | 半年 |

**判断信号**：
- 在建工程同比下降 → 供给收缩中，周期见底征兆 ✅
- 在建工程飙升、全行业新高 → 周期见顶 🔴（**当前状态**）

#### 1.2 澳洲锂精矿拍卖价 (Pilbara BMX) ⭐⭐

- **领先碳酸锂价 2-4 周**
- 拍卖溢价 → 矿端紧张；折价 → 矿端宽松
- 2026年关注：Cattlin枯竭后，Finniss/Bald Hill/Ngungaju 三座停产矿是否因锂价回暖而复产

#### 1.3 津巴布韦 / 非洲政策 ⭐⭐

| 事件 | 影响 |
|------|------|
| 津巴布韦 2027年起禁止锂精矿出口 | 全球供给减少约 4万吨 LCE/年 |
| 尼日利亚打击非法采矿、暂停采矿6个月 | 影响 3-4万吨 LCE/年进口 |
| 马里布谷尼大区列为高风险地区 | 赣锋 Goulamina 项目地缘风险 |

**数据源**：SMM（上海有色网）、百川盈孚、安泰科、广期所期货

#### 2.2 碳酸锂库存（供需缺口的即时反映）⭐⭐⭐

| 库存类型 | 看什么 | 当前状态 (7月) |
|----------|--------|----------------|
| 冶炼厂库存 | 上游累库/去库方向 | 约 27,480吨（低于历史均值）→ 上游去库 |
| 下游电池厂库存 | 补库意愿信号 | 刚需采购、低库存运行 → 缺乏主动补库 |
| 期货仓单量 | 隐性库存显性化 | 5.6万吨以上 → 显性抛压 ⚠️ |
| 锂精矿港口库存 | 矿端宽松/紧张 | 25.5万吨 → 矿端供给充裕 |
| 全产业链库存/产量比 | 整体松紧度 | <1个月产量 → 偏紧 |

**关键信号**：下游库存极低 + 价格企稳 = 补库行情前兆 ✅

**数据源**：SMM周度库存、百川盈孚、广期所仓单日报、各港口周报

#### 2.3 月度排产与终端需求 ⭐⭐⭐

| 指标 | 看什么 | 当前趋势 | 数据源 |
|------|--------|----------|--------|
| 磷酸铁锂正极排产 | 需求直接验证 | 每月10日左右公布 | SMM |
| 三元正极排产 | 高端需求 | 同上 | SMM |
| 新能源汽车月销量 | 动力电池需求基数 | 7-8月夏季淡季 | 乘联会/中汽协 |
| 储能电池出货量 | 最大边际变量！ | 2026H1同比+75-85% 🔥 | 高工锂电/ICC鑫椤 |
| 储能招标量 | 未来3-6月需求前瞻 | 持续超预期 | 各电力央企招标公告 |

**2026年需求增速基准**（综合瑞银/华泰/五矿）：
- 动力电池锂需求：同比 +12-24%
- 储能电池锂需求：同比 +60-75%（**最大变量**）
- 全球锂总需求：约 197-207 万吨 LCE，同比 +16-25%

#### 2.4 全球供给增量跟踪 ⭐⭐

```
2026年全球锂供给增量拆解（中性假设 ~34万吨LCE新增）

澳洲 (~15%增速)：
├── Greenbushes CGP3 投产 → +6.5万吨 LCE
├── Kathleen Valley / Holland 产能爬坡 → 小幅增量
└── 停产矿复产（Finniss/Bald Hill/Ngungaju）→ 潜在弹性

├── 赣锋 Goulamina → 一期50.6万吨精矿爬坡
├── 紫金 Manono → 2026年中投产，年产能50万吨精矿
├── 海南矿业 Bougouni → 新投产
└── 津巴布韦出口禁令 → -4万吨 LCE（扣减）

南美 (~15%增速)：
├── 阿根廷：力拓Rincon + 紫金3Q + 赣锋Mariana 持续爬坡
├── 智利：SQM/ALB 增产有限
└── 2027年后新增项目明显减少

中国 (~43%增速)：
├── 宁德枧下窝复产 → 年产能10万吨 LCE，2026年先释放3-5万吨
├── 青海盐湖：察尔汗+汇信+扎布耶二期 产能爬坡
├── 西藏盐湖：拉果错一期+麻米错一期 新投产

全球加权增速：约 20-25%
```

### 第三层：估值/情绪指标（股价触发）

#### 3.1 动态PE与隐含锂价 ⭐⭐

| 指标 | 天齐锂业 (A股) | 赣锋锂业 (A股) | 信号含义 |
|------|---------------|---------------|----------|
| 当前动态PE | ~10-11x | ~14-16x | 历史低位 |
| 股价隐含锂价 | ~15万/吨 | ~17万/吨 | 已反映一定悲观预期 |
| 机构目标价 | 瑞银 93元 / 东吴 83.9亿利润 | 瑞银 110元 / 中原买入 | 与现价差距大 |

**周期股PE法则**：利润暴增 → PE极低 → 周期高点附近 → 谨慎
**当前判断**：PE低位 ≠ 便宜，可能是"利润见顶 → PE被动压缩"的陷阱

#### 3.2 机构评级方向 ⭐

| 机构 | 评级 | 核心逻辑 |
|------|------|----------|
| 瑞银 | 买入 (锂价看20万) | 储能爆发 + 供需缺口 |
| 东吴/中邮/中原 | 买入 | 锂价中枢上移 + 资源价值 |
| 高盛 | 卖出 (锂价看6.5-9.5万) | 2026H2供给集中释放 |
| 大和 | 沽售 | 对明年锂价上行空间保守 |

**跟踪信号**：评级下调扩散 → 悲观情绪定价中；"买入"开始增多 → 底部信号积累

#### 3.3 龙虎榜 / 主力资金

- 机构席位集体卖出（如 7/8 天齐3家机构卖1.29亿）→ 机构出清进行中
- 融资余额连续下降 → 杠杆资金撤退
- 关注：何时出现机构净买入 + 融资余额企稳

## 四、全球锂成本曲线

```
2026年全球锂现金成本曲线（完全成本，万元/吨 LCE）
═══════════════════════════════════════════════════════

 5-7万  ████████████████  南美盐湖 (SQM Atacama/ALB)
                          ← 成本最低、永续产能
 7-10万 ████████████████  澳洲优质锂辉石 (Greenbushes)
                          + 中国盐湖 (察尔汗/扎布耶)
                          ← 天齐的核心利润区 ★
10-13万 ████████████████  其他澳洲矿 + 非洲矿 + 中国盐湖
13-16万 ████████████████  江西锂云母 (宁德枧下窝等)
                          ← 当前价格区间 ★
16-20万 ████████████████  非洲高成本矿 + 高成本锂云母
20万+   ██████████        极端边际产能
═══════════════════════════════════════════════════════

关键推论：
• 锂价 15万 → 约85%产能盈利，供给释放动力强
• 锂价跌至 10万 → 锂云母全线亏损，非洲矿承压，澳洲小矿停产
• 锂价跌至 7万以下 → 仅剩南美盐湖+Greenbushes 能盈利
• 天齐(Greenbushes成本约5-6万)在行业最差时也能活 — 核心护城河

关注变化：成本曲线不是固定的
→ 澳矿从露天转地下开采 → 成本上升（Greenbushes远期也面临）
→ 南美人工+电费上涨 → 盐湖成本已从$4000升至$8000/吨
→ 新矿品位下降 → 全行业成本中枢长期上移
```

## 五、机构分歧地图

```
                    2026年锂价中枢预测
                          
    高盛                    华泰        五矿/野村       瑞银
    6.5-9.5万               8-9万        10-15万        20万
    ├───────────────────────┼───────────┼──────────────┤
    极度看空                 中性偏空     中性偏多       强烈看多
    "高位回落"              "小幅过剩"   "紧平衡"       "供需缺口"
                          
分歧根源：
─────────────────────────────────────────────────────────
1. 宁德枧下窝复产速度 → 决定国内新增供给斜率
2. 储能需求增速假设 → 50% vs 75% vs 100%，区间宽度近20万吨
3. 海外矿山复产弹性 → 高锂价是否触发 Finniss/Bald Hill 快速复产
4. 非洲政策执行力 → 津巴布韦禁令是否严格执行
5. 产业链补库意愿 → 下游低库存状态下，是否开启主动补库

最值得跟踪的单一变量：储能月度出货量
→ 若持续 +75%以上 → 倾向瑞银/野村情景
→ 若增速回落至 +50%以下 → 倾向华泰/高盛情景
```

## 六、你可能忽略的三个信号

### 6.1 锂盐加工价差（碳酸锂 - 锂辉石精矿）

- 2025年12月起价差持续扩大，2026年1月已超 4万元/吨 LCE
- 加工端利润率改善 → 刺激锂盐厂提升开工率 → 增加碳酸锂供给
- 天齐自给率~100%不受影响；赣锋外购矿部分受益

### 6.2 磷酸铁锂正极备货系数

- 华泰研究发现：备货系数与磷酸铁锂产量增速高度正相关
- 2026年产量增速预计低于2025年 → 备货系数可能下降 → 实际锂需求可能低于表观
- 这是需求端最容易被高估的环节

### 6.3 回收锂的增量

- 伍德麦肯兹预测回收供应年增13-16%
- 2040年代随电动车电池退役潮出现可观回收量
- 短期影响不大，但长期压低原生锂需求天花板
