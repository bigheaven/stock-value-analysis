# 快刀斩股十刀法：来自公众号"快刀Pro"的分析框架

> **来源**：快刀Pro 公众号「快刀斩股」系列（21篇）+《快刀斩股》后记
>
> **核心理念**：见路不走、回到起点直奔终点、破除权威主义/教条主义/经验主义三大障碍。
>
> **与格雷厄姆的关系**：格雷厄姆提供了安全边际和内在价值的基础理论，快刀做的是把理论翻译成A股散户可执行的十刀清单。

---

## 一、十刀框架：逐刀砍，砍不死才是好公司

```
第一刀：砍营收和净利润
→ 看10年以上趋势，不是只看一年
→ "一路向上画出一条完美曲线"= 第一刀不掉血

第二刀：砍ROE
→ 过去五年稳定 >15% = 优秀
→ 10%左右 = 及格（重资产行业可接受）
→ 持续下降 = 扣分

第三刀：砍资产负债表
→ 货币资金 vs 短期/长期借款（净现金越多越好）
→ 应收账款/营收比（>30% = 警惕）
→ 应付账款 + 预收款项 + 合同负债（越多说明产业链地位越强）
→ 商誉/净资产比（>20% = 警惕；移动61亿/1.37万亿 = 无足轻重）

第四刀：砍现金流量表
→ 经营现金流/净利润（净现比）>1 = 健康，>2 = 优秀
→ 自由现金流 = 经营现金流 − 资本开支
→ 自由现金流 < 净利润 = 利润质量存疑

第五刀：砍股东回报
→ 股息率、股利支付率、分红稳定性
→ 10年连续分红 = 可信赖
→ 支付率 >20% 且稳定 = 好

第六刀：砍赛道/行业
→ 市场空间是否足够大
→ 行业是否具有护城河（垄断/牌照/品牌）
→ 公司在产业链中是否有议价权（能赊账供应商 + 客户提前付款）

第七刀：砍同行对比
→ 毛利率、净利率、ROE 三率对比
→ 在所有关键指标上都要拿第一
→ 三率全优 = 龙头

第八刀：砍股权变动
→ 大股东/高管增持还是减持？
→ 增持 + 没有减持记录 = 加分
→ 大股东频繁减持 = 重大扣分

第九刀：砍人均持股
→ 股东人数变化趋势
→ 股东人数减少 = 筹码集中 = 资金在收集
→ 股东人数暴增 = 筹码分散 = 资金在出货

第十刀：砍估值
→ PE处于历史什么位置
→ 和同行比贵了还是便宜
→ 结合股息率判断安全边际
```

## 二、方法论哲学：见路不走

快刀后记中阐述的核心思想：

```
创新的定义：从起点到终点的更优方案

起点 = 你的条件（资金规模、认知水平、时间投入）
终点 = 你的目标（收息、博弹性、保本）

条件变了，策略就要变：
→ 巴菲特管万亿 vs 管百万 → 策略完全不同
→ A股散户 vs 美股机构 → 不可能照搬同一套方法
→ 这就是"见路不走"——别人的路，你条件不同就不该走

三大障碍：
1. 权威主义 → "巴菲特/格雷厄姆说的就一定对吗？"（对，但在A股要翻译）
2. 教条主义 → "PE > 15x 就一定不能买吗？"（不一定，看行业和成长性）
3. 经验主义 → "上次这个方法赚钱了，这次也能"（条件可能变了）

对治方法：回到起点，直奔终点
→ 跳过所有中间环节和既有路径
→ 直接从你的目标出发，倒退最佳方案
```

## 四、快刀体系的独特价值

格雷厄姆告诉你"买便宜货"，快刀告诉你"怎么确认这不是假便宜"。

```
格雷厄姆没有直接给你的：
→ 十刀砍完只掉了三滴血 → 大概率是好公司
→ 砍到第五刀就撑不住 → 趁早放弃

快刀没有给你的（你的系统已补充）：
→ 泡沫位置判断（索罗斯反身性 + 泡沫解剖）
→ 概念真实性验证（分部报告法）
→ 宏观风险推演（三大全球衰退剧本）
```

## 五、使用建议

```
分析新股的标准流程（合并快刀 + 你的系统）：

1. 快刀第1-5刀（财务面）→ 10分钟过一遍
2. 假概念识别 → 分部报告真实性
3. 快刀第6-7刀（赛道+同行）→ 行业位置
4. 格雷厄姆安全边际 → 估值是否足够低
5. 索罗斯反身性 → 当前是泡沫还是恐慌
6. 快刀第8-10刀（股权+人均+估值）→ 最终验证
7. 决策

如果十刀中砍到3刀以上掉血 → 放弃或只做投机
如果十刀全过 → 进入格雷厄姆安全边际计算
```
