## 二、原始数据清单

| 字段 | 说明 | 优先级 |
|---|---|---|

| 字段 | 说明 |

| PE(TTM) | 或自行用公式算 |
| PB（当期/MRQ） | 每股净资产口径 |
| 每股净资产 BPS | 或直接取「归母净资产」 |

### 2.3 财务类（按年）

| 字段 | 说明 | 用途 |
|---|---|---|
| 归母净利润（2021、2022 年报） | 必取 | 算 PE、ROE |

| 加权 ROE（可直接取最好） | 否则由净资产算 | 判质地 |
| 营业收入 | — | 区分「杀估值」vs「杀业绩」 |

## 三、公式

```
EPS = 归母净利润 / 总股本
PE  = 价格 / EPS = 总市值 / 归母净利润
BPS = 归母净资产 / 总股本
PB  = 价格 / BPS = 总市值 / 归母净资产

加权 ROE = 归母净利润 / (期初净资产 + 期末净资产) / 2   ← 权威口径
近似 ROE ≈ PB / PE                                        ← TTM 速算（PE、PB 同期时成立）

回撤     = (最低价 / 顶部价 - 1) × 100%      ← 用前复权价
区间涨跌  = (期末价 / 期初价 - 1) × 100%

泡沫判据 PB/ROE = PB ÷ ROE
   > 0.7        泡沫区（2022 宁德 = 23/25.4 ≈ 0.91）
   0.15–0.35    合理区（2026 宁德 = 5.6/22.6 ≈ 0.25）
```

> `PB/PE = ROE` 的推导：`(市值/净资产) ÷ (市值/净利) = 净利/净资产 = ROE`。这是快算利器，但须标注「TTM 近似、未年化」。

## 五、口径陷阱（算错的高发点）

1. **复权**：算回撤必须用前复权；宁德 2022「10 转 8」会让不复权最高价偏差约 44%。
2. **2022 顶部不在 2022 年内**：是 2021-11~12，别在 2022 行情里找最高价。
3. **PE 失真**：孚能（亏损）、国轩/欣旺达（利润趋零，PE 110x/213x 是假贵）——这三只用 PB 轴，不用 PE 轴。
4. **ROE 基准期**：2022 顶部对应 2021 年 ROE，不是 2022 年。
5. **同源**：PE、PB、ROE 必须同一时点、同一净利/净资产口径，否则 `PB/PE=ROE` 不成立。
