## 目录用途

| 文件夹 | 用途 | 节奏 |
|---|--|--|
| `01_泡沫风险识别框架/` | 核心框架文档（HTML 操作规范）；后续版本/指标全览放此 | 版本迭代 |

| `06_全球股息文化/` | 股息文化专题 | 按需 |

- 第一层全市场粗筛：候选池清单（非分数）
