**版本基准日：** 2026-08-26
**修订链：** v1.0 → v1.1 → **v1.2（本次）**
**修订来源：** 宇树科技（688836）案例交叉验证——外部专家报告（Manus AI，2026-08-26）与本框架 v1.1 卡片逐项比对后暴露的规则缺口

## 修订总览：v1.1 → v1.2

| 优先级 | 变更 | 解决的问题 | 暴露来源 |
|:---:|---|---|---|
| P0 | Q模块新增**利润三分离**强制检查（归母/扣非/经营现金流同表对照） | 归母净利大增掩盖扣非下滑，Q分数被高估 | 宇树案例：归母+2.74亿(转正) 但扣非2.44亿同比-19.34% |

| P0 | Q模块新增**现金流方向强制披露**：OCF必须报同比方向 | 只报绝对值或比率会掩盖"利润增+现金流降"剪刀差 | 宇树案例：OCF同比-32.53%被误写为"健康" |
| P1 | 次新专用行扩充**新股微观结构检查清单**（首日涨幅vs新股平均、价格发现完成度等） | 次新股的交易拥挤判断缺乏相对基准 | 宇树案例：首日+460% vs 近三年新股平均+226%，无此对比则"极热"缺锚 |

**设计三原则不变**：不让同一轮泡沫定义自己的合理估值；不让V和E重复给价格打分；不让不可信的数据产出伪精确总分。

## 一、Q模块：利润三分离强制检查（P0）

**插入位置：** 第五章评分卡 Q 模块行后，作为强制执行细则。

**规则文本：**

每份标准/深度报告的 Q 模块必须提交**利润质量三分离表**：

| 指标 | 本期 | 上年同期 | 同比方向 | 说明 |
|---|---|---|---|---|
| 归母净利润 | | | | 含一次性损益 |
| 扣非归母净利润 | | | | 核心经营利润 |
| 经营活动现金流净额 | | | | 现金含量 |
| 营业收入 | | | | 方向基准 |

**强制红旗（触发即 Q 分数上调至少 15 分并在证据列标注）：**

1. **利润质量背离**：归母与扣非同比方向相反（一升一降），或归母同比增速与扣非同比增速之差 >30 个百分点；
2. **利润-现金流剪刀差**：利润同比上升但 OCF 同比下降，或 OCF 降幅超过利润降幅的 2 倍；
3. **OCF 连续两期同比为负**且方向与收入背离。

**禁止做法：** 仅以"OCF/净利≈0.85"这类当期比率替代同比方向判断；仅以归母口径外推盈利能力。

> **案例注记（宇树 688836，2026H1）**：归母 2.74 亿（上年同期 -0.32 亿，转正），扣非 2.44 亿（同比 -19.34%），OCF 2.32 亿（同比 -32.53%），收入 +48.54%。三项红旗中第 1、2 项同时触发，Q 分数应由 28 修正至 50 左右。v1.1 卡片漏检，属于规则强制力不足，非数据缺失——iFinD 返回中已含"EPS-扣除/基本 0.67 vs 基本 0.75"，数据在手未被展开。

## 二、同比失真规则：低基数与一次性损益拆解（P0）

**插入位置：** 第三章数据规则末尾，作为新增小节。

**规则文本：**

当基期（上年同期）存在下列大额一次性项目时，**禁止直接引用归母净利同比增速**作为 Q 或 E 的证据，必须执行拆解：

- 股份支付费用（Pre-IPO 轮次集中确认）
- 金融工具公允价值变动（优先股、可转债）
- 大额资产处置/减值
- 会计政策变更追溯调整

**拆解格式（强制）：** "归母同比改善 X 亿元中，约 Y 亿元来自基期一次性项目消失，Z 亿元来自本期经营性改善（以扣非口径绝对额对比为准）。"

**适用扩展：** 增速基数低于绝对额门槛（如基期利润 <1 亿或为负）时，所有百分比增速自动标注"低基数，参考绝对额"。

## 三、次新专用行扩充：新股微观结构检查清单（P1）

**插入位置：** 第九章"新股/次新"行展开为独立小节。

**规则文本：**

上市 <2 年标的除既有规则（相对锚历史维度降级、换手按上市时长调整）外，T 与 C 模块必须完成以下检查清单：

| 检查项 | 数据 | 判断基准 |
|---|---|---|
| 首日/上市初期涨幅 | 首日收盘涨幅 | **vs 近三年新股平均首日涨幅**（相对热度，非绝对值） |
| 价格发现完成度 | 上市交易日数 | 科创板前 5 日无涨跌幅限制期内，分数置信度额外降档 |
| 高点回撤结构 | 上市以来最高价→现价 | 区分"回撤已深"与"仍远高于发行价"两个独立事实，两者须同时报告 |
| 解禁时间表 | 网下配售/战略配售/控股股东各批次 | 与流通盘占比同表，标注每批次占总股本比例 |
| 战略配售浮盈 | 配售价 vs 现价 | 浮盈越大，远期解禁时的减持激励越强 |

**新增规则：次新股置信度降档**

- 上市 <30 个交易日：置信度封顶为"中"，无论数据覆盖率；
- 报告须标注"价格发现未完成，分数对快照时点高度敏感"；
- **快照敏感性双检**：当同日不同时点快照的价格差 >3% 时，报告必须列双时点数据并说明分数区间而非单点分数。

> **案例注记（宇树 688836，2026-08-26）**：外部报告 12:59 快照价 611 元/市值 2471 亿；本框架 15:26 快照价 591.53 元/市值 2392 亿。同日差 3.3%，PE 读数 451x（动态）vs 410x（TTM）——单点分数的伪精确由此直观可见。

## 四、E/G 新增：海外与供应链敞口检查（P1）

**插入位置：** 第五章 E 模块与第六章 G 模块各增一行检查项。

**规则文本：**

- **E 模块**：海外收入占比 >10% 时，隐含增长路径必须评估地缘政治、关税、市场准入与关键零部件供应链约束，作为"可验证能力"的扣减项；
- **G 模块**：披露"前三大海外市场收入占比"，占比 >25% 时在"待核验风险事项"中列示准入变化跟踪点。

> **案例注记（宇树 688836）**：美国收入占 2025 年收入 13.3%（据外部报告引 CNBC/招股材料），v1.1 卡片未覆盖。对人形机器人这类出口敏感品，该敞口直接影响 E 模块的可实现性判断。

## 五、G 模块：区分"已检查未发现"与"未检查"（P1）

**插入位置：** 第六章分账规则表后。

**规则文本：**

每份报告的 G 模块结论必须区分三种状态，禁止合并表述：

| 状态 | 表述规范 |
|---|---|
| 已检查未发现 | "已核验审计意见/问询函/质押/减持公告，未发现异常" |
| 未检查 | "本卡未核验：[逐项列示]"（如：审计报告原文、质押明细、龙虎榜、招股书全文） |
| 检查中存疑 | "待核验风险事项"（沿用 v1.1） |

**"无重大红旗"仅对"已检查"清单有效。** 报告末尾必须附"本卡未核验事项"清单。

## 六、报告模板新增字段（P2）

**插入位置：** 第十三章模板第 8 节扩充。

1. **参考资料**：关键数字（价格、财务、事件、行业容量）逐条附来源（URL 或数据库+查询时点），无来源数字标"待核验"；
2. **本卡未核验事项**：清单式列示；
3. **修订记录**（如为重算/修正版）：注明与前一版本的分数差异及原因。

## 七、保留不采纳的提议（记录决策依据）

| 外部报告做法 | 本框架决策 | 理由 |
|---|---|---|
| 放弃 BRS 总分，只用风险等级 | **不采纳**，保留总分+档位 | 总分支持跨股排序（宇树 vs 优必选对比即依赖此能力）；样本不足问题已由"先验档位/研究优先级语义 + 次新置信度降档"处理，不必弃总数 |
| 新股微观结构独立成模块 | **不采纳独立模块**，扩充次新专用行 | 避免模块数膨胀导致权重重排；其内容天然分属 T（交易）与 C（供给），扩充专用行可达同一效果且不动权重 |
| 以 Reuters"首日收涨460% vs 新股平均226%"作为情绪过热证据 | **采纳为 T 模块相对基准** | 绝对涨幅无锚，相对新股总体分布才有意义——已写入第三节检查清单 |
