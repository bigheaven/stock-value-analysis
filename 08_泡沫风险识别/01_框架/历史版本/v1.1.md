# A股单股泡沫风险识别框架 v1.1（草案）

**形态：** 对话式单股研究工具
**启用方式：** 直接发送股票名称或代码
**版本基准日：** 2026年8月26日
**分数版本标记：** BRS@w2.1（结构版本2 / 权重集2.1，回测前先验权重）
**修订链：** v1.0 → 专家评议 → 审阅回应 → 边界规则修订（A/E边界、G分账、分数版本化、行为维度）→ v1.1

> **金融风险提示：** 本框架用于识别估值—基本面错配与回撤脆弱性，不构成任何证券的买卖建议，不指控违法或欺诈，不预测确定的下跌时间。"泡沫风险"指市场定价、隐含预期、经营兑现与交易结构之间的错配风险，不等同于必然下跌。研究与交易决策分离，投资风险由使用者自行承担。

## 修订总览：v1.0 → v1.1

| 优先级 | 变更 | 解决的问题 | 来源 |
|:---:|---|---|---|
| P0 | 新增三锚体系（相对锚+绝对锚+容量锚），新增A模块（容量锚，权重10%） | 相对估值在板块整体泡沫中失明 | 评议结构修订1 |
| P0 | E重定义为"可实现性缺口"；V/E分工：V=价格位置，E=能力缺口 | V/E双重计分 | 评议结构修订2 |
| P0 | G拆为"常规治理分 + 数据有效性闸门"两层 | 5%权重与严重红旗门槛的定位冲突 | 评议结构修订3 |
| P0 | A/E边界规则：份额检验只放A，E只留增长/利润率/资金缺口 | 新增A后可能复刻V/E的双重计分 | 边界修订1 |
| P1 | 三维读数（BRS水平/ΔBRS/高分持续期）+ 市场情境标签 | 静态分数被误读为顶部预测 | 评议结构修订4 |
| P1 | 分数版本化（BRS@wX.Y）与轨迹可比规则 | 权重变更污染ΔBRS | 边界修订4 |
| P1 | G分账规则（进分数/进覆盖率/进闸门三分） | 同一问题重复扣分 | 边界修订3 |
| P1 | 回测五层检验 + 数据窗口声明 + V/E/A相关性矩阵 | 权重与分档未经校准；价格族占50% | 评议校准章 + 边界修订2 |
| P2 | 模式定义表：简版/标准/深度/对比/点时各自字段最小集 | 模式边界未定义 | 评议P2 |
| P2 | 轻量粗筛层规范 | 九步流程无法覆盖全A | 评议P2 |
| P2 | 第三层新增行为/叙事检查表 | 阶段研究只有量化读数，测不出"为什么没人喊顶" | 边界修订6 |
| P2 | 行业表补"新股/次新/极端小流通盘"专用行 | 特殊类型缺规则 | 评议P2 |

**设计三原则（一切结构性修订的判据）**

1. **不让同一轮泡沫定义自己的合理估值** → 三锚体系
2. **不让V和E用不同名字重复给价格打分** → V=位置，E=能力缺口，A=容量
3. **不让不可信的数据产出伪精确总分** → 数据有效性闸门

## 一、输入协议与模式定义

最简输入只有一项：**股票名称或证券代码**。例如 `贵州茅台`、`600519`、`宁德时代` 或 `300750.SZ`。开始时先返回"主体确认卡"，确认证券代码、交易所、证券简称、上市板块、主营业务和行业归属；名称歧义、简称变更或同名主体不唯一时，先确认再分析，不自行猜测。

| 模式 | 输入示例 | 模块范围 | 字段最小集 | 适用场景 |
|---|---|---|---|---|
| 简版 | `宁德时代｜简版` | V、Q、T 三模块 + 数据覆盖率 | 估值分位、盈利质量红旗、涨幅/换手分位、覆盖率 | 快速判断是否值得进入标准模式 |
| 标准（默认） | `贵州茅台` | 全七模块 + 预期账本 + 三维读数 | 九步流程完整数据集 | 单股研究默认 |
| 深度 | `300750｜深度` | 标准 + 同业比较 + 历史估值位置 + 事件时间轴 + 行为检查表 | 标准集 + 同业组 + 5年估值史 | 候选确认、重仓决策前 |
| 对比 | `中际旭创｜对比 新易盛` | 两标的标准模式，共用同一可比组 | 两份标准集 + 同一可比组 | 二选一 / 相对强弱 |
| 点时 | `某某｜截至2025年年报` | 任意模式 + 指定历史日期 | 该时点前可得信息 | 历史复盘、回测抽查 |

> **对比模式强制附加A模块聚合检验结论。** 两只热门股互比仍发现不了板块整体泡沫，对比报告必须同时给出两股所在赛道的容量锚结果。

> 默认输出是"泡沫风险研究结论"（回测前为研究优先级分数），不是买入、卖出或做空指令。组合应用时，研究评分与交易约束、风险承受能力、持仓背景分开说明。

## 二、九步流程（v1.1）

| 步骤 | 固定动作 | 交付内容 | 不通过时如何处理 |
|---|---|---|---|
| **1. 主体确认** | 识别代码、交易所、简称、板块、主营业务、证券状态 | 主体确认卡 | 名称含混时暂停评分请求确认 |
| **2. 时间锚定与有效性预检** | 记录分析日期、价格时点、最近财报期与公告日；预检关键数据源完整性 | "截至何时"标签 + 数据源清单 | 数据无法核验→标缺失；关键科目可信度存疑→挂"待核验"并进入闸门观察 |
| **3. 可比组建立** | 监管行业为底座，按商业模式、盈利阶段、市值、产业链定位选5–15家 | 可比组名单及纳入理由 | 样本不足→缩小结论强度，提高人工复核权重 |
| **4. 三锚估值压力（V）** | 相对锚（可比组+自身历史分位）；绝对锚（跨周期利润/FCF压力测试） | V子分数 + 三锚各自读数 | 亏损/金融/强周期切换适用指标；绝对锚对早期成长只做压力测试 |
| **5. 可实现性缺口（E）** | 反推所需增长、利润率、资金，对照可验证能力（历史、指引、订单、产能、融资能力） | E子分数 + 能力缺口清单 | 份额检验不在此步（已移至A）；关键假设不可得→保留公式、降低置信度 |
| **6. 基本面兑现（Q）** | 收入、利润、经营现金流、应收、存货、毛利率、资本开支、ROIC趋势 | Q子分数及正/负证据 | 财报滞后或口径变动→单独标注，不与新数据混算 |
| **7. 交易与拥挤（T）** | 超额涨幅、换手、量价、波动、自由流通市值、融资暴露、流动性 | T子分数与脆弱性说明 | 无可靠数据→仅定性提示；次新股换手信号按上市时长调整 |
| **8. 信息、资本与事件（C+G）** | 审计意见、问询/更正、减持、解禁、再融资、质押、业绩预告、经营里程碑 | 红旗清单、催化剂、时间窗口 | G按第六章两层机制处理；严重红旗→人工复核；媒体信息不作定论 |
| **9. 综合结论** | 计算BRS@wX.Y、三维读数、先验档位、置信度、反方证据、去泡沫条件 | 标准化单股报告 | 覆盖不足→"待验证"；闸门触发→冻结报告 |

> **闸门可在任一步触发。** 触发后流程立即转入"冻结报告"：只列已核验事实与数据缺口，不输出总分，不给出档位。

## 三、数据规则：先证据，后结论

以证监会行业分类为稳定底座，交易所行业统计作横向参照。[1] [2] 财务、事件与文本证据优先使用年报、季报、业绩预告、临时公告和法定披露平台原文；创业板指定披露网站的原文优先级高于二手转述。[3]

| 数据类别 | 优先来源 | 使用方式 | 禁止做法 |
|---|---|---|---|
| 证券主体、行业与板块 | 交易所信息、证监会分类、公司公告 | 确定主体与可比组边界 | 用市场概念或媒体标签替代监管行业 |
| 价格、市值、成交与换手 | 交易所或可追溯市场数据 | 估值、相对收益、流动性、拥挤信号 | 混用复权口径；把滞后收盘价称为实时价格 |
| 财务报表与业绩预告 | 定期报告、业绩预告、审计报告 | 收入、利润、现金流、营运资本与质量 | 用披露日之后才得知的事实回填历史结论 |
| 资本与治理事件 | 原始公告、交易所问询与回复 | 解禁、减持、再融资、质押、信息质量风险 | 未经原始材料证实即指控违法或造假 |
| 行业趋势与叙事 | 公司公告、行业协会、权威研究、主流媒体 | 解释预期，不替代公司数据 | 把行业愿景等同于公司可实现利润 |

**点时原则（强化）**：所有历史结论只能使用该时点已披露信息；财务数据以**披露日**而非报告期起算可得性；禁止后见之明回填。回测与ΔBRS均以此为准。

**数据覆盖率**：每个最终结论附覆盖率标签，数值带"截至日期、最近财报期、数据来源、口径"四要素。核心模块（V/E/Q/A/T）任一关键数据缺失，不得给出高置信度结论。

## 四、三锚体系（新增）

| 锚 | 回答的问题 | 数据基础 | 使用边界 |
|---|---|---|---|
| **相对锚** | 相对同业、自身历史、商业模式，贵不贵？ | 可比组估值分位、自身历史区间 | 不单独判定全行业泡沫 |
| **绝对锚** | 在正常回报要求下，当前价格需要多大的成熟期现金流或资本回报？ | 跨周期正常化盈利、FCF收益率 vs 无风险利率+股权风险溢价、EPV | 对早期成长股只作压力测试，不机械淘汰 |
| **容量锚** | 市场已定价的收入、份额、利润率、产能是否超出行业可容纳总量？ | 赛道聚合隐含收入 vs 行业容量；单股隐含份额 vs 可信份额上限 | TAM/份额/利润率须拆保守/基准/乐观三情景 |

**A/E边界规则（防新的双重计分）**

- **E只回答"这家公司能不能做到"**：所需增长 − 可验证增长能力、所需利润率 − 可验证利润率、资金需求 − 融资/现金流能力。
- **A只回答"市场装不装得下"**：① 赛道聚合检验——同赛道全部公司市值隐含收入加总 vs 行业容量，聚合缺口 >1 即"所有公司不能同时兑现"；② 单股份额上限检验——隐含份额 vs 可信上限（历史份额、竞争格局、物理产能）。
- **份额类检验一律放A，E中不得出现份额项。**

**绝对锚适用域**：FCF收益率与"无风险利率+风险溢价"不作为早期成长公司的机械淘汰器，仅在产业化进度、单位经济与竞争优势判断之外提供压力测试证据。亚马逊2005、特斯拉2019式的路径不应被该锚杀死。

**赛道界定（操作定义，待回测校准）**：以监管行业为底座，按主营占比 >50% 的题材归属映射赛道；多元业务公司按最大收入块归属，并在报告中披露归属敏感性。

## 五、评分卡：BRS@w2.1

### 1. 总分公式

$$
\mathrm{BRS}=0.20V+0.20E+0.20Q+0.15T+0.10C+0.10A+0.05G
$$

各模块先在行业、商业模式、规模、生命周期可比组内映射到 0–100 分；分数越高，估值—兑现错配与回撤脆弱性越高。权重为**可解释的先验权重**（w2.1），须由滚动样本外回测校准后方可用于跨股排序结论。

| 代码 | 模块及权重 | 评分问题 | 典型高风险特征 | 必须保留的反方证据 |
|---|---|---|---|---|
| **V** | 估值压力，20% | 相对锚与绝对锚下，价格位置是否显著昂贵？ | 多个适用指标处于可比组高分位；绝对锚显示回报要求被压至不合理低位 | ROIC持续改善、现金流加速、真实的盈利上修 |
| **E** | 可实现性缺口，20% | 实现当前价格隐含的经营目标，难度是否超出可验证能力？（不含份额） | 所需增长/利润率明显超过公司历史、指引与融资能力 | 已签订单、产能投产、市占提升等可逐项验证的证据 |
| **Q** | 基本面兑现，20% | 已披露经营事实是否支撑市场故事？ | 利润跑赢收入但现金流变弱；应收/存货快于收入；非经常性收益依赖 | 现金回款、周转改善、更高质量的利润来源与审计支持 |
| **T** | 交易拥挤，15% | 价格是否由短期资金和叙事驱动、具快速反转脆弱性？ | 超额涨幅、换手、波动与题材热度同处高位；流通盘小或流动性脆弱 | 业绩持续超预期；高成交由长期资金再配置驱动 |
| **C** | 资本与供给压力，10% | 股权供给或资本结构会否放大估值回归？ | 解禁、减持、再融资、股本扩张或高质押集中于短期窗口 | 清晰资金用途、稳定大股东行为、足够流动性承接 |
| **A** | 容量锚，10% | 赛道聚合隐含收入是否超行业容量？单股隐含份额是否超可信上限？ | 聚合缺口 >1（所有公司不能同时兑现）；隐含份额超上限 | 行业总量本身高增长；份额有可验证的历史与竞争支撑 |
| **G** | 常规治理，5% | 一般信息质量（更正频率、承诺兑现、常规问询） | 反复更正、承诺与进展长期错配 | 公司的完整解释与后续审计/经营证据 |

### 2. 价格族披露（新增）

V/E/A 合计 50% 权重均由市值派生（三个不同问题：位置 / 可达性 / 容量）。回测阶段必须输出三模块**相关性矩阵**；若任两模块相关性 >0.7，合并或降权。在矩阵结果出来前，报告中须明确披露"价格族合计权重50%"。

### 3. 评级解释（先验档位，回测前仅作研究优先级排序）

| BRS区间 | 先验档位 | 研究含义 | 不是指什么 |
|---:|---|---|---|
| 0–29 | 低 | 当前可得资料未显示明显估值—兑现错配 | 不代表低估，也不代表可忽视基本面风险 |
| 30–49 | 中等 | 至少一个模块存在压力，需持续追踪 | 不代表短期会下跌 |
| 50–64 | 高 | 估值、预期、基本面或拥挤模块多项共振 | 不构成卖出或做空指令 |
| 65–79 | 很高 | 预期透支与脆弱性较强，强化反方核验与事件观察 | 不代表企业没有长期价值 |
| 80–100 | 极高 | 多维证据同向，且现严重信息/资本/交易红旗或极端预期缺口 | 不指控违法，不预测确定的下跌时间 |

> **校准前语义**：分数称为**研究优先级分数**，档位标注"先验"。跨股排序优先报告**全样本分位**（如"处于可比全市场样本的前10%"）而非绝对区间。回测后按经验风险分位重划档位，不预先写死"50–64=高风险"。

### 4. 置信度等级

| 等级 | 条件 | 使用限制 |
|---|---|---|
| 高 | 核心模块完整、数据覆盖率 ≥85% | 可用于排序与对比 |
| 中 | 覆盖率 ≥65% 且至少三个核心模块可核验 | 结论限于方向性判断 |
| 低 | 覆盖率 <65% 或关键数据缺口 | 只能作为"待验证清单"，不得解读为强结论 |

## 六、G模块：两层机制与分账规则

### 1. 两层机制

| 情形 | v1.1处理 | 对总分/置信度的影响 |
|---|---|---|
| 一般治理或披露质量问题 | 保留G连续分数（更正频率、承诺兑现、审计/问询异常） | 有限加分项；按分账规则处理覆盖率 |
| 关键财务数据可信度已受重大影响 | 触发**数据有效性闸门** | 输出"无法可靠评级，需人工复核"；冻结BRS，不输出总分 |
| 原始披露尚不足以证明问题 | 只写"待核验风险事项" | 不把媒体猜测转为红旗或公司事实 |

### 2. 分账规则（防重复扣分）

| 情形类型 | 进G分数 | 进数据覆盖率 | 进闸门 |
|---|:---:|:---:|:---:|
| 一般披露质量（更正频率、承诺延期、常规经营问询） | ✓ | — | — |
| 数据源缺口/口径缺失（非公司原因） | — | ✓ | — |
| 严重可信度破坏（审计非标、重大更正待查、关键科目矛盾、涉收入确认/资金占用的问询） | 暂缓 | — | ✓ |
| 已由其他模块计分的事项（如解禁已计入C） | — | — | — |

**原则：同一事实最多进一处；闸门优先级最高。** 目标是既不低估一般信息质量问题，也避免"报表可能无效、模型却给出精确62分"的伪精确。

## 七、三维读数与市场情境标签

| 读数 | 含义 | 解决的问题 |
|---|---|---|
| **BRS水平** | 当前估值—兑现错配与脆弱性的截面程度 | 现在风险有多高？ |
| **ΔBRS** | 最近一季、两季、一年分数变化 | 风险在加速还是缓解？ |
| **高分持续期** | BRS高于某门槛的连续时长 | 刚出现的透支，还是已被时间与业绩消化/证伪的长期高估？ |
| **市场情境标签** | 所在主题/市场的估值分位、成交拥挤、风险偏好、融资活动、板块扩散度 | 同样的高分出现在什么市场状态？ |

**ΔBRS三条前置规则**

1. **点时回填依赖**：轨迹需历史分数，靠点时回测回填；P1完成前，ΔBRS仅对已有评分历史的标的输出。
2. **同权重集原则**：轨迹比较必须在同一权重集内进行。
3. **版本化与重算**：每个发布权重集获得编号（如w2.1、回测后的w3.0）；权重变更后，用新权重对历史点时数据重算，报告标注重算口径。

**情境不改分数**：市场情境标签只影响解释、跟踪频率与风险预算，不乘进BRS——否则不同市场阶段的分数无法纵向比较。

## 八、预期账本（升级）

"估值高"不是足够的判断。每份标准报告必须展示市场要求公司做到什么，并列出验证条件。对盈利公司：

$$
\text{所需净利润}_{n}=\frac{\text{当前股权市值}}{\text{目标PE}_{n}}
\qquad
\text{所需收入}_{n}=\frac{\text{所需净利润}_{n}}{\text{目标净利率}_{n}}
\qquad
\text{所需收入CAGR}=\left(\frac{\text{所需收入}_{n}}{\text{LTM收入}}\right)^{\frac{1}{n}}-1
$$

**情景规则**：`目标PE` 与 `目标净利率` 由三情景构成——保守情景用可比组较低分位或自身历史中枢；基准情景用经营质量匹配的可比组中位数；乐观情景仅在公司具备可验证竞争优势时使用较高分位。亏损成长公司改用 PS 或 EV/S 情景，再反推正利润与成熟利润率所需收入；金融公司改用 PB–ROE 与资产质量框架；周期行业优先跨周期利润、产能与现金成本。

**v1.1 升级——目标倍数同时受三锚约束**：

- 相对锚给**区间**（可比组分位）
- 绝对锚给**回报要求下限**（隐含FCF收益率不得低于无风险利率+风险溢价）
- 容量锚给**收入上限**（所需收入不得超过行业容量允许的天花板）

预期账本必须新增"容量天花板"一行：行业容量允许的最大收入，以及聚合检验下该股的"公平份额"。份额类验证统一在A模块，不在E的字段中出现。

| 预期账本字段 | 必须回答的内容 | 结论的证伪/验证条件 |
|---|---|---|
| 当前市值与估值倍数 | 市场为每单位利润、收入或净资产支付多少？ | 盈利、现金流或ROE改善能否解释倍数 |
| 未来收入路径（受容量锚上限约束） | 回到基准情景所需的收入规模与CAGR | 订单、产能、产品、客户或市占是否支持 |
| 未来利润率 | 利润率需提升多少？来自价格、规模、结构还是费用率？ | 毛利率、费用率、现金流、竞争格局是否同步支持 |
| 资本回报与资本开支 | 所需ROIC是否覆盖扩张资金与再投资？ | 资本开支、周转、负债与自由现金流是否匹配 |
| **容量天花板（新增）** | 行业容量允许的最大收入；聚合检验下的公平份额 | 行业总量数据、竞争格局变化、产能投放 |
| 关键里程碑 | 哪些公告/财报项目使假设成立或失效？ | 逐季记录"超预期 / 符合 / 低于预期" |

## 九、行业与公司类型专用规则

| 公司类型 | 首选判断框架 | 不应机械使用的指标 | 额外关键核验 |
|---|---|---|---|
| 稳定消费、医药、软件服务 | PE、PS、FCF、ROIC、收入质量 | 只看静态PE | 品牌/产品周期、续费或渠道、价格与份额 |
| 高成长制造、硬科技 | PS/EV-S、毛利率、产能利用率、订单、单位经济 | 亏损期PE | 研发投入、良率、客户验证、资本开支、竞争加剧 |
| 强周期品、资源、化工 | 跨周期利润、PB、EV/EBITDA、现金成本、产能周期 | 景气高点PE | 商品价格、供需、库存、资本开支、项目投产 |
| 银行、保险、券商 | PB–ROE、资产质量、资本充足率、利差/负债成本 | 制造业PE | 不良率、拨备、久期、资本约束、监管政策 |
| 地产、建筑、重资产 | PB、EV、杠杆、现金回款、合同负债、资产减值 | 单一收入增速 | 债务期限、经营现金流、项目质量、融资能力 |
| 小市值题材股 | 流通市值、换手、量价、盈利兑现、公告与股权供给 | 只凭题材和涨幅 | 主营占比、实际订单、解禁减持、持续经营能力 |
| **新股/次新（上市<2年）** | 可比组 + 绝对锚 + 容量锚为主；相对锚历史维度降级；换手/涨幅信号按上市时长调整 | 自身历史分位（无意义） | 主营占比、发行定价 vs 现价、解禁时间表、募投进度 |
| **极端小流通盘** | 流动性调整后的量价信号；主营占比与持续经营能力 | 单纯涨幅/换手（天然高换手） | 解禁减持节奏、壳价值叙事、审计意见、股权质押 |

## 十、三层工作流与漏斗定位

| 层级 | 目标 | 工具/输出 | 覆盖范围 | 节奏 |
|---|---|---|---|---|
| **第一层：全市场粗筛** | 快速发现估值、质量、拥挤、事件异常的候选池 | 轻量指标清单（第十一章）；与《14_泡沫识别与预警》共用指标口径 | 全部A股 | 周/月 |
| **第二层：单股BRS确认** | 判断候选股是否存在真正的"价格—可实现性"错配 | 本框架九步流程、三锚、预期账本、反方证据 | 粗筛后重点公司 | 事件驱动 |
| **第三层：阶段与事件研究** | 识别题材从扩散、拥挤到验证/破裂的阶段与验证窗口 | BRS轨迹、板块扩散度、市场情境标签 **+ 行为/叙事检查表** | 高分主题与重点个股 | 逐季/逐事件 |

### 第三层双输入：量化轨迹 + 行为检查表

量化读数（BRS轨迹、扩散度、成交拥挤）之外，行为检查表回答"量价测不出的问题——为什么没人喊顶"：

| 检查项 | 观察信号 |
|---|---|
| 激励结构 | 基金经理/卖方/媒体的持仓与激励是否已完全同向（唱空对职业无好处） |
| 叙事检查 | "这次不一样"是否成主流；定价逻辑是否变成"X凭什么比Y便宜"（锚定幻觉） |
| 流动性事件 | 巨型IPO/合并是否密集出现在行业利润+估值**双顶**（若出现在周期底部则非泡沫信号） |
| 产业资本 | 减持/增持/回购动向；龙虎榜机构与散户方向是否背离 |
| 反对声音 | 是否存在公开唱空；是否只有退休人士才敢预警 |
| 假反弹鉴别 | 高换手 + 大V密集唱多 + 产业资本卖出 = "倒车接人"陷阱 |

### 双分支顶部模型

顶部有两条路径，阶段判断须先分辨路径再谈时点：

- **流动性事件顶**：标志性巨型IPO/合并抽血（2007中石油、2015中车）
- **饱和顶**：该买的都买了，无标志事件（2021抱团瓦解）

## 十二、回测与校准计划（P1）

| 检验层 | 建议方法 | 通过的含义 |
|---|---|---|
| 案例回放 | 不同类型历史高估、题材扩散、盈利兑现案例 + 配对优质成长股 | 规则具备经济直觉，反方论据写得对 |
| 全样本横截面 | 按季度/月度构建点时股票池，以当时信息计算BRS | 高分组行业调整后收益更差、未来回撤更大、业绩兑现更差 |
| 滚动样本外 | 早期窗口定权重与阈值，后续窗口检验 | 防回看式调参与"只对历史有效" |
| 分组归因 | 控制规模、动量、流动性、质量、行业、上市年限 | 证明BRS不是复述小盘、高换手或近期上涨 |
| 可执行性 | 纳入停牌、涨跌停、交易成本、披露滞后、退市/ST样本 | 防幸存者偏差与不可交易价格 |

**数据窗口声明（诚实条款）**：回测范围以点时数据实际可得窗口为准。若分析师一致预期历史仅覆盖2018年后，则2015杠杆牛不可回测，报告必须写明"回测样本未包含该时期"，不得以案例回放替代样本外证据。回测开始前先盘查数据边界并公开窗口。

**相关性矩阵**：输出 V/E/A 三模块相关性矩阵；任两项 >0.7 → 合并或降权，同步更新权重集版本号。

**校准前后语义**：校准前 = 研究优先级分数；校准后 = 经验风险分位（如"全样本前10%/前5%"），并以此重划档位。

## 十四、红旗规则与结论保护栏

红旗规则不用于给公司贴标签，而是防止简单平均分掩盖严重问题。当核验到重大审计意见异常、反复重大财务更正、关键经营数据与重大承诺持续严重偏离、或短期多重资本供给压力叠加时，报告触发**人工复核**，风险等级至少标示为"待重点核验"；若属关键财务可信度破坏，直接触发**数据有效性闸门**（第六章）。只有原始披露、监管文件与时间线均确认后，才提高最终风险等级。

模型必须强制列出**反方论据**与**去泡沫条件**。公司可以凭持续超预期的收入增长、可验证的份额提升、现金流改善、ROIC上升或合理并购整合消化高估值；这些正向事实持续出现时BRS应下降。框架不允许因历史上"看起来很贵"就固执维持高风险评级。
