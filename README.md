## 🧭 五步分析流程（速览）

```
① 定性  这是什么生意？护城河？管理层？
② 定量  利润是真的吗？现金流健康吗？
③ 估值  值多少钱？安全边际够不够？
④ 排雷  有没有致命风险？
⑤ 执行  买多少？何时买？何时卖？
```

每步之间有 go/no-go 决策点：**看不懂→放弃；数字有假→放弃；不便宜→等待；有雷→放弃**。顺序是灵魂——先看清生意、再验数字、然后才谈估值，最后才轮到买卖点。
