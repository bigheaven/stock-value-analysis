# 段永平投资思维框架

> **来源**：段永平投资问答录（商业逻辑篇 + 大道篇），2006-2025 年雪球/网易博客公开发言
> **定位**：中国最接近巴菲特的投资者。段永平是步步高/OPPO/vivo 幕后老板，2006 年拍下巴菲特午餐，此后持续在雪球以"大道无形我有型"免费分享。用自己做企业的经验反哺投资，用投资验证自己对企业的理解。

---

## 一、底层信仰：三句话

### 1. 买股票就是买公司

> "买股票就是买公司，买公司就是买其未来现金流折现。这里现金流指的是净现金流，未来指的是公司的整个生命周期，不是 3 年，也不是 5 年。"

这不是比喻，不是思维方式——是**定义**。股票是公司的一部分，你买入股票 = 你买入了公司所有权。如果你不愿意持有这家公司十年，就不要持有它的股票十分钟。

### 2. 做对的事情，把事情做对

> "做对的事情"是方向，"把事情做对"是执行。多数人在投资时很习惯去看有没有"把事情做对"这点，从而会很容易掉进短期表现当中。

两者缺一不可，但有先后顺序：**先确认方向正确，再追求执行效率。** 方向错了，跑得越快死得越快。

### 3. 本分 + 平常心

> "本分"就是做自己该做的事情，不做不该做的事情。"平常心"就是回归事物的本源，不受情绪干扰。

这是他从经营企业到投资一以贯之的底层操作系统。"本分"决定你做什么、不做什么，"平常心"决定你能不能在市场疯狂和恐慌时保持冷静。

## 二、投资框架：极简但极难

### 2.1 看公司的顺序

```
第一：商业模式（最重要）
  → 能不能持续赚钱？赚的是不是容易钱？
  → 差异化 = 用户需要但别人没能满足的东西
  → 护城河是商业模式最重要的部分

第二：企业文化
  → 有没有"利润之上的追求"？
  → 管理层正直诚信吗？
  → 是做对的事情的公司，还是不择手段的公司？

第三：价格
  → 合适就好，不需要精确的最低点
  → 用未来现金流折现思维方式，不要套公式
  → 安全边际 = 能力圈，不光是价格
```

**顺序不能乱。** 大部分人是反过来的——先看价格（便宜吗？），再看商业模式（能赚钱吗？），最后看企业文化（管理层靠谱吗？）。段永平说这是本末倒置。

### 2.2 长长的坡，厚厚的雪

> "什么公司是在长长的坡上滚着厚厚的雪呢？苹果是。茅台是。腾讯应该也是。Google 绝对是。"

- **长长的坡**：行业和企业本身能否长期存在并增长——不只是行业赛道好，企业文化也必须能支撑长跑
- **厚厚的雪**：商业模式的盈利能力——高毛利率、强定价权、用户粘性
- **追求"性价比"的公司**：既没有长长的坡也没有厚厚的雪，因为性价比本质上是为低价找借口

### 2.3 看懂一家公司的标准

> "所谓能看懂公司就是能看懂其未来现金流折现。"

- **懂** = 能大致判断这家公司 10 年后还在不在、能不能继续赚钱
- **不懂** = 不能确定 10 年后的现金流状况 → **不碰**
- 能力圈的大小不重要，**知道自己能力圈的边界最重要**
- 他近 20 年真正"看懂"的不到 10 家公司，重手投了 5 家，差不多两年一家

### 2.4 不为清单（Stop Doing List）

> "人们关注我们往往是因为我们做了的那些事情，其实我们之所以成为我们，很大程度上还是因为我们不做的那些事情。"

| 不做的事 | 原因 |
|------|------|
| 不懂不做 | 能力圈之外的东西，涨多少都跟你无关 |
| 不借钱投资 | 杠杆会让你在市场恐慌时被迫卖出 |
| 不做空 | 做空的风险收益极不对称（最多赚 100%，可能亏无限） |
| 不频繁交易 | 每一笔交易都应该是独立的投资决策，不是"调仓" |
| 不投没有利润之上追求的公司 | 只盯着利润的公司迟早会走偏 |
| 不投管理层不诚信的公司 | 正直和诚信是所有伟大企业的共性，也是出问题企业最大的漏斗 |

## 三、商业洞察

### 3.1 利润之上的追求

> "利润之上的追求指的是把消费者需求放在公司短期利益前面。多数公司碰到问题时讨论的都是有没有钱赚的问题，而有利润之上追求的公司碰到问题时可能会先问一句，这是对的事情吗？这是应该赚的钱吗？其实差别很小，但 20 年后差别很大。"

案例：
- 苹果库克说"当我们付出努力让盲人也可以使用时，我不会考虑该死的 ROI"——这就是利润之上的追求
- 茅台坚持做好酒的文化——宁愿牺牲短期产量也不降低品质
- 步步高不做低质低价产品——"本分"就是赚该赚的钱

### 3.2 差异化是好商业模式的前提

> "没有差异化，最后就是价格战。有差异化，就有定价权。"

差异化 = 用户需要、但别人没能满足的东西。不是"我比别人好"，是"别人做不了"。

- 苹果的差异化 = 生态系统 + 用户体验，用户离不开
- 茅台的差异化 = 品牌 + 稀缺性，消费者认
- 腾讯的差异化 = 社交关系链，迁移成本巨大

### 3.3 "敢为天下后，后中争先"

段永平做企业的核心策略：**不追求第一个做，追求做得最好。** 小霸王（学习机）、步步高（VCD/DVD）、OPPO/vivo（手机）——全部是在别人验证了市场之后进入，然后把产品做到极致。

投资同理：不需要在最低点买，需要在确认之后仍然有足够空间的时候买。不追求抄底，追求确定性。

### 3.4 造钟人 vs 报时人

> "乔布斯同时是一个极罕见的报时人，也是一个很好的造钟人。库克就是乔布斯最伟大的发明之一。"

- **报时人**：自己超级厉害，但离开他公司就不行了
- **造钟人**：建立了一套让公司在没有他的情况下仍然伟大的系统（文化 + 人才 + 制度）
- 判断管理层时：相对容易判断他们是否"不对"，不容易判断他们是否"对"——**不对的就不碰**

## 四、与巴菲特/格雷厄姆/杨东的异同

| | 段永平 | 巴菲特 | 格雷厄姆 | 杨东 |
|------|------|------|------|------|
| **核心信仰** | 买股票 = 买公司 | 同 | 同 | 同 |
| **第一标准** | 商业模式 | 护城河 | 安全边际 | 低估值 |
| **出身** | 企业家 | 投资人 | 教授/投资人 | 公募基金经理 |
| **能力圈** | 懂消费电子、互联网 | 懂保险、消费 | 懂财务报表 | 懂中国周期 |
| **投资节奏** | 两年一家 | 类似 | — | — |
| **对待泡沫** | 不参与 | 不参与 | 不参与 | 不参与（写信劝赎回） |
| **最大区别** | 用经营企业的视角看投资 | 用投资的视角看企业 | 用财务报表的角度看企业 | 用周期和价值的角度看市场 |

段永平是四人里唯一一个既经营过百亿企业、又做过投资的人。他说"投资和经营没有本质区别"——这不是比喻，是他真的两边都做过。

## 五、可直接迁移的六条原则

### 1. 买之前问自己：我愿意持有这家公司 10 年吗？

如果答案是犹豫的，就不要买。不需要精确计算，需要的是"大不了持有十年"的心态。

### 2. 先看商业模式，再看价格

你之前买的腾讯/阿里/小米——商业模式怎么样？护城河还在吗？先回答这个问题，再想"是不是跌够了"。

### 3. 不懂不做

昇腾概念股你不敢买——这不是你的问题，这是你的本能保护。段永平在科技泡沫顶峰也不买他不理解的东西。错过了 Cisco 的涨幅，也躲过了 Cisco 的 90% 暴跌。

### 4. 用"不为清单"保护自己

不借钱、不做空、不懂不做、不频繁交易。这些"不做"比"做"什么更重要。

### 5. 关注"利润之上的追求"

阿里有吗？腾讯有吗？小米有吗？一家公司碰到问题时是先问"这对吗"，还是先问"这赚钱吗"——20 年后差别很大。

### 6. "做对的事情"需要时间验证

> "即使是伟大的企业在'做对的事情'的过程当中也是可能会犯错的，因为'把事情做对'往往需要一个过程。所谓长期投资，从某种角度上说，就是要能够相信坚持'做对的事情'的有能力的公司最后会'把事情做对'。"

这句话适用于你现在持有的阿里和腾讯——它们在 AI 上投入巨资，市场在惩罚它们。问题不是"AI 投入对不对"，是"它们在执行上能不能把事情做对"。如果你相信它们在"做对的事情"，那等待就是合理的。
