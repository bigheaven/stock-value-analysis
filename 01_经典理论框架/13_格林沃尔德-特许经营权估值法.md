# 格林沃尔德-特许经营权估值法（Economic Moat / Franchise Valuation）

## 代表人物
**布鲁斯·格林沃尔德**（Bruce Greenwald，1946–），哥伦比亚大学商学院教授，价值投资领域的"另类"大师。他是格雷厄姆-多德学派的正统传承者，代表作《价值投资：从格雷厄姆到巴菲特的头号投资法则》（*Value Investing: From Graham to Buffett and Beyond*）。与巴菲特"买入好企业"的定性路线不同，格林沃尔德强调**以可量化的资产价值与盈利价值作为估值锚**，用"特许经营权"（Franchise）而非玄学般的"护城河"来界定竞争优势。

---

## 核心理念

格林沃尔德的估值框架建立在"**企业价值三要素**"之上，并据此将企业分为三类。核心思想是：**先判断企业属于哪一类，再选择对应的估值方法，绝不套用统一公式。**

| 企业类型 | 判定特征 | 估值方法 | 特许溢价 |
|---------|---------|---------|:-------:|
| **资产型企业** | 盈利价值 < 资产价值 | 按资产重置价值（AV）估值 | 无 |
| （普通商品企业） | 无竞争优势，ROIC≈WACC | 清算价值/重置价值 | 无 |
| **特许经营企业** | 资产价值 < 盈利价值 | 按盈利价值（EPV）估值 | 有（EPV/AV>1） |
| （好企业） | 有持续竞争优势，ROIC>WACC | 永续盈利价值 | 有（EPV/AV>1） |
| **成长型企业** | 盈利价值 < 成长价值 | 盈利价值 + 成长价值 | 有（需验证） |
| （卓越企业） | 优势可复制延伸，再投资回报高 | 三要素加总 | 有（需验证） |

> **核心命题**：当前场价格（V）与内在价值的偏离主要来自市场对"成长性"的过度定价。格林沃尔德主张**先用不依赖成长假设的 EPV 锚定内在价值**，再审视成长是否真实存在、能否被资本化，从而避免为想象买单。

---

## 三要素估值模型

企业内在价值 = **资产重置价值（AV）** + **盈利价值（EPV）** + **成长价值（Growth Value）**

### 1. 资产价值 AV（Asset Value）
资产的真实市场重置成本，而非账面成本。用于衡量"最坏情况下企业值多少钱"。

```
AV = 资产负债表各资产的公允重置成本 − 全部负债
    ± 品牌/渠道等无形资产（若可单独计量）
    − 已减值或无法变现的资产
```

- 作用：提供估值下限（地板），是保守投资者的安全垫
- 局限：忽略无形资产（品牌、客户关系）的创造能力

### 2. 盈利价值 EPV（Earnings Power Value）
企业**不增长**情况下，用当前正常化盈利资本化得到的价值。这是格林沃尔德框架的核心。

```
EPV = 正常化盈利（NOPAT） / WACC
```

**正常化盈利（Normalized NOPAT）校准流程**（去除周期与偶然扰动）：
1. 取一个完整周期（通常5-10年）的营业利润
2. 计算周期平均营业利润率，×当前营收 → 标准化 EBIT
3. 加回折旧摊销（非现金支出）
4. 扣减维持性资本开支（通常以年度折旧为代理）
5. 扣减一次性非经常损益
6. ×（1 − 有效税率）→ 稳态 NOPAT

- 作用：反映企业不增长时的"永续盈利能力"，是价值中枢
- 关键：**不假设增长**，天然规避成长股估值泡沫

### 3. 成长价值 Growth Value
只有满足苛刻条件才计入成长价值：

```
成长价值 = EPV × (ROIC − WACC) / (WACC − g)   （仅当 ROIC > WACC 且增长可持续）
```

**计入成长价值的必要条件**：
1. 企业有真实、可验证的竞争优势（ROIC 长期 > WACC）
2. 管理层资本配置理性，再投资回报率稳定
3. 增长可被企业自己的能力消化，而非依赖行业景气

> 若 ROIC ≤ WACC，**成长是价值毁灭**，成长价值应为负，不应计入。

## 特许经营权（Franchise）判定

格林沃尔德用"**进入壁垒**"而非玄学护城河来界定竞争优势。企业能维持 ROIC > WACC 的原因，是可防范新进入者：

| 竞争优势来源 | 类型 | 识别信号 |
|-------------|------|---------|
| **规模经济** | 成本壁垒 | 固定成本高、单位成本随规模下降 |
| **客户锁定** | 转换壁垒 | 客户更换成本高、习惯性购买 |
| **法规/专利** | 制度壁垒 | 牌照、批文、专利、独占特许 |
| **网络效应** | 连接壁垒 | 用户越多价值越大（少见） |
| **品牌** | 心智壁垒 | 品牌溢价、心智占据（需配合上述之一） |

**判定证据量化审查**（用数据而非打分）：
- 细分市场份额及变化趋势
- 长期盈利稳定性（营业利润率波动幅度）
- ROIC 与 WACC 的差额及走势
- 品牌与渠道的真实转换成本
- 行业新进入者数量与难度
- 技术替代风险、政策监管变化

## 三段式回报率模型（净预期回报 R_net）

格林沃尔德框架的落地执行工具，用于判断企业长期能否覆盖股权资金成本：

```
R_net = R_cash（现金分红回报） + R_organic（内生增长回报）
        + R_active（主动再投资回报） − Fade（盈利衰减）
```

| 分项 | 公式 | 说明 |
|------|------|------|
| **现金回报 R_cash** | 盈利收益率 × 派息率 | = EPS/股价 × 分红比例，即股息率 |
| **内生增长 R_organic** | Σ(各业务有机增速 × 营收权重) | 剔除并购等外延扰动，反映真实内生成长 |
| **主动再投资 R_active** | 再投资比例 × 增量ROIC × q系数 | 留存利润中扣除维持性CAPEX后的自由再投资回报 |
| **盈利衰减 Fade** | 经验估计（0%~2.5%） | 对冲ROIC下行、主业萎缩、竞争加剧 |

**q 系数（资本配置质量等级）**：
| 等级 | 判定 | 处理 |
|:----:|------|------|
| A级 | 投入护城河核心，ROIC 显著>WACC | 全额计入 |
| B级 | 回报贴合行业均值，证据有限 | 折价 0.6 计入 |
| C级 | 低效并购/跨界，回报<资金成本 | 大幅扣减 |
| D级 | 价值毁灭式投资 | 增长收益归零 |

**决策标准**：`R_net > WACC` → 价值创造，可配置；`R_net < WACC` → 价值毁灭，观望/规避。

## EPV 与 AV 交叉验证

**不机械相加**，仅用双维度校验特许溢价的合理性：

```
特许溢价倍数 = EPV / AV
```

- **EPV/AV ≈ 1**：无特许溢价的普通企业，按资产价值估值
- **EPV/AV > 1（如 >2）**：确认存在真实特许经营价值，典型 C 类特许企业
- **EPV/AV < 1**：盈利不可持续，资产价值才是底线，警惕价值陷阱

**归母股权内在价值计算**：

```
归母股权 EPV = NOPAT/WACC + 冗余非经营资产 − 净有息负债 − 少数股东权益
每股内在价值 = 归母股权 EPV / 总股本
```

**市值价值比 V/M**：`V/M = 每股内在价值 / 当前股价`。V/M < 1 说明股价有溢价，无安全边际；V/M > 1 说明有安全垫。

## 操作流程

```
① 定性分类 → ② 正常化盈利校准 → ③ EPV/AV 估值 → ④ 三段式回报测算 → ⑤ 安全边际决策
```

1. **定性分类**：判断是资产型/特许经营型/成长型企业，决定用哪个估值锚
2. **正常化盈利校准**：十年数据 → 标准化营业利润率 → 稳态 NOPAT
3. **估值**：计算 AV、EPV、成长价值，交叉验证特许溢价倍数 EPV/AV
4. **三段式回报**：测算 R_cash + R_organic + R_active − Fade，对比 WACC
5. **安全边际决策**：结合回报缺口、估值偏离、风险等级、数据质量、假设敏感度做四档评级

**投资决策四档矩阵**：
| 档位 | 判定标准 | 操作 |
|:----:|---------|------|
| 强配置 | 净回报大幅>WACC + 高护城河 + 假设稳健 | 积极买入 |
| 合理配置 | 回报小幅达标 + 小幅不确定性 | 可配置 |
| 观望持有 | 回报接近或低于资金成本 | 等待/持有 |
| 风险规避 | 护城河结构性损毁 + 盈利持续恶化 | 规避 |

## 适用场景

- **EPV 尤其适用**：盈利稳定、可预测、有真实竞争优势的企业（消费、OTC药、公用事业、品牌制造）
- **AV 尤其适用**：陷入困境、周期底部、市场怀疑其持续经营能力的价值股
- **成长价值需谨慎**：只有能证明 ROIC>WACC 且再投资回报可持续的卓越企业才配得上成长溢价
- 特别适合**回答"当前价格是否已充分定价特许价值"**（V/M 校验）

---

## 风险提示

- **正常化盈利存在主观性**：周期长度、维持性CAPEX、一次性损益的界定因人而异
- **WACC 假设高度敏感**：WACC 每变动 1%，EPV 结论可能翻转，必须充分论证
- **Fade 衰减系数偏保守**：可能低估优质品牌护城河的韧性（对老牌消费品牌尤甚）
- **成长价值的误用**：把成长当确定性、为想象付高价，是框架最需警惕的陷阱
- **不适用于**：高波动科技股、亏损成长股、重资产周期股（AV/EPV 意义有限）
