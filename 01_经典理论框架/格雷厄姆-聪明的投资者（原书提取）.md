# 聪明的投资者：格雷厄姆价值投资框架

> **来源**：本杰明·格雷厄姆《聪明的投资者》（The Intelligent Investor, 1973年第四版修订版）
>
> **定位**：与 vault 已有的泡沫解剖框架、假概念识别三步法互补——前者告诉你"什么时候是泡沫"，后者告诉你"这个公司到底做什么"，本框架告诉你**什么价格买才安全**。
>
> **触发使用**：每次评估一只新标的，问完"它是周期股还是成长股"、"它是真概念还是概念收割机"之后，第三个问这个框架："有没有安全边际？"

---

## 一、全书一句精华

格雷厄姆把整本书归结为四个字：**安全边际**。

```
安全边际 = 内在价值 − 买入价格

你花 10 块钱买了一个值 15 块钱的东西
→ 那 5 块钱就是你的安全垫
→ 市场跌 30% 你还不亏
→ 这就是投资和投机的区别
```

---

## 二、投资 vs 投机：一堵不能跨的墙

```
格雷厄姆的判据：

投资操作 = 全面分析 + 本金安全 + 满意回报
投机操作 = 不符合以上任何一个条件

关键洞见（映射到你的研究案例）：
"当普通股以极具吸引力的价格出售时，人们认为买股票是投机；
 当股票涨到极危险的水平，买股票反而成了投资。"

利欧股份 半年30次涨停时 → 人人都说"AI龙头，投资它"
利欧股份 3.84元时 → 没人敢买，都说"垃圾股，投机"

市场永远在颠倒这两个词。
格雷厄姆告诉你：别人说"投资"的时候，可能是最大的投机。
```

## 三、市场先生：你每天都要对付的那个疯子

```
格雷厄姆的寓言（全书最经典的概念）：

想象你有一个生意伙伴，叫"市场先生"。
他每天都会敲你的门，报一个价格——
要么买你手里的股份，要么卖给你他手里的股份。

他有时极度乐观 → 报价高得离谱
他有时极度抑郁 → 报价低得荒谬

你可以接受他的报价，可以拒绝，可以不理他。
但他明天还会来。

关键：
→ 你不需要每天和他交易
→ 你应该利用他的躁郁症，而不是被他传染
→ 他躁郁时（报价极低）是最佳买点
→ 他狂躁时（报价极高）是最佳卖点

映射到你的泡沫解剖框架：
阶段4-5 = 市场先生狂躁期 → 巨型IPO、全民炒股、AI信仰
阶段8-9 = 市场先生抑郁期 → 没人敢买、估值冰点、安全边际最大
```

## 四、两类投资者：你选哪个

### 防御型投资者（格雷厄姆最推荐普通人走的路）

```
定义：不想花太多时间、不想担太大风险、追求稳定回报

组合原则：
├── 债券 25-75%（根据市场估值调整）
├── 普通股 25-75%
└── 核心是：不预测、不择时、不追热点

选股标准（映射到今天）：
├── 足够大（市值>100亿）
├── PE不高（<15-20x）
├── 财务稳健（流动比率>2:1，低负债）
├── 连续分红（至少10年）
├── 利润稳定增长（过去10年没有亏损年）
└── PB合理（<1.5x）

映射到你的研究标的：
✅ 中车 PE 12x PB 0.88x 十年分红 → 符合
✅ 工商银行 PB 0.5x 连续N年分红 → 符合
⚠️ 平安 PE 6.9x 但利润受股市波动 → 部分符合
❌ 利欧股份 PE亏损 扣非几千万 → 不符合
```

### 进攻型投资者（需要大量时间研究）

```
定义：愿意花时间、承担一定风险、追求高于平均的回报

四条路径：
├── 买低市盈率的冷门股（不受欢迎的大公司）
├── 买"净流动资产价值"以下的股票（清算价值 > 市值）
├── 买有价证券（可转债、优先股等）
└── 在熊市底部买（利用市场先生的抑郁期）

关键原则：
→ 绝不买没有经过自己研究的东西
→ 绝不依赖别人的预测作决策
→ 安全边际是唯一的护身符
```

## 六、格雷厄姆不会碰的东西（和他会碰的对比）

```
❌ 不碰：
├── 任何 PE > 25x 的股票
├── 任何他算不出内在价值的公司（这就是他不碰科技股的原因）
├── 任何没有至少5年利润记录的公司
├── 任何依赖"预测未来成长"来证明买入价格合理的东西
└── 任何概念股（不管吹得多好听）

✅ 会碰：
├── 破净的稳健大公司（像中车、工行）
├── 连续10年分红的公司（像平安）
├── 熊市底部没人要的好公司（像2022年4元的工行）
└── 债券 + 股票的组合（不预测方向）
```

## 七、和你的已有框架完美互补

```
你的泡沫解剖框架
→ 告诉你：市场现在在哪（阶段1-9）
→ 格雷厄姆说：在阶段8-9买，在阶段4-5卖

你的假概念识别三步法
→ 告诉你：这家公司到底做什么
→ 格雷厄姆说：算不出内在价值的东西别碰

你的周期光谱框架
→ 告诉你：这是周期股还是成长股
→ 格雷厄姆说：周期股我不碰（但你可以在周期底部用安全边际买）

本框架（价值投资）
→ 告诉你：什么价格买才安全
→ 本质：把前面所有框架的结论，变成"买不买、以什么价格买"的最终决策
```

## 八、一句验证法

下次准备买一只股票，先问自己一句话：

**"如果市场明天关门，五年内不再开市，我还愿意以这个价格拥有这家公司吗？"**

如果答案是"不愿意"——你在投机，不是在投资。
