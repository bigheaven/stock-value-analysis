# 彼得·林奇投资框架：六类股票 + PEG + 日常生活选股

> **来源**：彼得·林奇（Peter Lynch, 1944–），富达麦哲伦基金前经理，1977-1990 年复合年化回报 29.2%，《彼得·林奇的成功投资》《战胜华尔街》作者。
>
> **定位**：林奇是连接格雷厄姆（定量安全边际）和费雪（定性成长）的桥梁。他的核心贡献是把"选股"从专业分析师的象牙塔，降维到普通投资者的日常生活。

---

## 一、核心理念：业余投资者有天然优势

林奇反复强调：**普通人比华尔街分析师更早发现好公司**。分析师在办公室看报表，你在商场、医院、停车场——你看到的是真实世界。

```
"你不需要成为火箭科学家。
 投资不是智商测试——智商 160 的人不一定能打败智商 130 的人。
 理性是最重要的。"
```

## 二、六类股票分类法（林奇最核心的方法论）

林奇要求你在买入任何股票之前，先把它归入以下六类之一。**不同类型对应完全不同的预期、持有逻辑和卖出标准。**

| 类型 | 特征 | 预期年化回报 | 核心关注指标 | 代表性案例 |
|------|------|-------------|-------------|-----------|
| **缓慢增长型** | 成熟行业龙头，增速 < GDP | 股息为主 | 股息率、派息率、是否持续 | 电力、水务、银行 |
| **稳健增长型** | 增速 10-12%，大象起舞 | 10-15% | PE 是否合理、多元化成败 | 宝洁、可口可乐 |
| **快速增长型** | 增速 20-25%，小而猛 | 10-40 倍可能 | PEG、增长天花板、复制能力 | 早期的星巴克、沃尔玛 |
| **周期型** | 跟随经济/行业周期波动 | 时机决定一切 | 库存、产能、商品价格 | 钢铁、化工、航运 |
| **困境反转型** | 濒临破产但可能活过来 | 几倍 | 现金储备、债务结构、重组方案 | 克莱斯勒（政府救助） |
| **隐蔽资产型** | 账面有市场未定价的资产 | 几倍 | 资产真实价值、催化剂 | 拥有大量土地/专利/现金的公司 |

## 三、PEG 指标：连接成长与估值的桥梁

林奇最著名的量化工具——将市盈率与增长率挂钩：

```
PEG = PE / 盈利增长率(%)

判断标准：
├── PEG < 0.5  → 极度低估（值得深入研究）
├── PEG < 1.0  → 合理偏低
├── PEG = 1.0  → 估值合理（增长与PE匹配）
├── PEG > 1.5  → 偏贵
└── PEG > 2.0  → 危险区域

示例：
  PE = 20，增长率 = 25% → PEG = 0.8 → 合理偏低
  PE = 40，增长率 = 15% → PEG = 2.7 → 泡沫
```

**关键限制**：
- 只适用于快速增长型和稳健增长型
- 增长率必须用**未来 3-5 年可持续增长率**，不是过去一年的暴增
- PEG 低不一定是买入信号——可能是增长率即将崩塌（价值陷阱）

## 四、日常生活选股法（"买你懂的东西"）

林奇最接地气的选股方法：从你的消费习惯、工作行业、朋友圈中发现牛股。

```
你在哪里发现好公司？
├── 超市/商场   → 哪些货架上的产品卖得最好？
├── 工作行业     → 你的专业领域，你比分析师更懂
├── 医院/药店    → 哪种药患者排队买？
├── 孩子学校     → 孩子们在用什么？在讨论什么？
└── 停车场       → 哪些店门口永远排长队？

林奇经典案例：
- 夫人买了一件 L'eggs 丝袜 → 调研 → 买入 Hanes 公司 → 大赚
- 女儿喜欢去 Body Shop → 调研 → 买入 → 大赚
- 自己开车看到 Dunkin' Donuts 排队 → 调研 → 买入 → 大赚
```

**但注意**：你喜欢一个产品 ≠ 它是一家好公司。你需要进一步验证——财务健康、估值合理、增长可持续。

## 五、理想的买入标的特征

林奇总结了"完美公司"的 13 个特征，以下是核心几个：

```
1. 名字听起来很无聊（甚至可笑）← 机构不关注，定价低
2. 做无聊的事情 ← 不被华尔街追捧
3. 分拆出来的子公司 ← 被迫卖出导致的定价偏差
4. 机构不持股、分析师不覆盖 ← 没有买方压力
5. 处于零增长行业 ← 没有新竞争者进入
6. 拥有某种利基（niche）← 区域性垄断或小众市场
7. 人们需要不断购买它的产品 ← 重复消费，非一次性
8. 公司内部人在买入 ← 管理层最了解公司
```

## 六、避雷清单：六类绝不买入的公司

```
1. 热门行业中最热门的股票   ← 预期已满，估值已高
2. 被吹捧为"下一个XXX"的    ← 从来没有下一个XXX
3. 多元恶化的公司            ← 收购自己不理解的业务，乱花钱
4. 大客户依赖度超过 25-50%   ← 客户一撤，公司崩塌
5. 名字里有"AI""量子""区块链" ← 改名蹭热点的公司
6. 悄悄话股票（whisper stock）← 靠谣言和预期支撑，没有基本面
```

## 七、卖出准则（按类型）

| 类型 | 卖出信号 |
|------|---------|
| 缓慢增长型 | 基本面恶化、涨了 30-50%、股息削减 |
| 稳健增长型 | PE 远超历史均值、新产品失败、管理层变更 |
| 快速增长型 | 增长放缓、PEG > 2.0、核心业务见顶 |
| 周期型 | 库存开始堆积、商品价格开始下跌、产能过剩 |
| 困境反转型 | 债务重组完成、恢复正常盈利、但故事已结束 |
| 隐蔽资产型 | 资产被市场重新定价、机构大量买入（价值已被发现） |
