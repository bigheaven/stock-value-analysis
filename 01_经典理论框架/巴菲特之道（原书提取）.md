# 巴菲特之道：从格雷厄姆到费雪的进化

> **来源**：罗伯特·哈格斯特朗《巴菲特之道》（The Warren Buffett Way, 第3版）
>
> **核心观点**：巴菲特不是格雷厄姆的复制品——他用格雷厄姆的安全边际保住底线，用费雪的成长思维打开天花板。
>
> **与格雷厄姆的关系**：格雷厄姆教巴菲特"买便宜货"，费雪/芒格教他"买好东西"。巴菲特的独特之处在于把两者合一。

---

## 一、巴菲特的进化：从捡烟屁股到买城堡

```
早期巴菲特（格雷厄姆式）：
→ 买股价低于净流动资产的公司
→ 买破净的、没人要的冷门股
→ "烟屁股投资"——在地上找还能吸一口的烟头

后期巴菲特（费雪/芒格式）：
→ 买有"护城河"的伟大公司
→ 以合理的价格买入，不是以便宜的价格
→ "用合理的价格买伟大的公司，远比以便宜的价格买普通的公司好"

关键转折：1972年收购喜诗糖果
→ 买入价2500万美元，远高于净资产
→ 但喜诗有品牌溢价 = 定价权
→ 此后30年，喜诗为伯克希尔赚了超19亿美元
→ 这笔交易让巴菲特从"格雷厄姆信徒"变成了"费雪信徒"
```

## 二、买入企业的12个坚定准则

```
企业准则（生意本身）：
1. 企业简单易懂（能力圈内）
2. 有持续稳定的经营历史
3. 有良好的长期前景
   → 特许经营权（franchise）= 提供必需品的、被需要的、不可替代的

管理准则（谁在掌舵）：
4. 管理层理性（利润再投资还是分红？）
5. 管理层对股东坦诚（不隐瞒坏消息）
6. 管理层抵制"惯性驱使"（不从众、不跟风并购）

财务准则（数字说话）：
7. 注重ROE而非EPS
8. 计算"股东盈余"（= 净利 + 折旧 − 资本支出）
9. 寻找高利润率的公司
10. 每留存1美元，至少创造1美元市值

市场准则（价格）：
11. 确定内在价值
12. 以远低于内在价值的价格买入（安全边际）
```

## 三、集中投资：反常识的真相

```
"分散化是对无知的保护。如果你知道自己在做什么，
 分散化就没有意义。"

巴菲特的集中度：
→ 前5大持仓通常占组合 60-80%
→ 他不认为这是"风险"——他认为持有自己不懂的股票才是风险

概率思维：
→ 把每笔投资看作一个概率事件
→ 当概率对你有利时（安全边际大），下大注
→ 当概率不清晰时（算不出内在价值），一分钱不下

映射到你的实践：
→ 你研究透的标的（中车、工行、紫金）可以重仓
→ 你没研究透的（寒武纪、利欧）一分不碰
→ 格雷厄姆要你分散，巴菲特要你集中——取决于你有多少把握
```

## 四、投资心理学：比分析更难的东西

```
巴菲特认为投资成功 = 智力 × 情绪控制：
├── 智力：能算出内在价值（格雷厄姆教的部分）
└── 情绪控制：能在别人恐慌时不卖、在别人狂热时不追

四大心理陷阱：
1. 过度自信 → 以为自己比市场聪明
2. 过度反应 → 对短期消息反应过度（"小作文"引发的抛售）
3. 损失厌恶 → 亏了不肯割肉、赚了一点点就跑
4. 心理账户 → "这笔钱是赚的，可以冒险"

这四点和你的泡沫解剖框架里的"市场先生"完美对应——
市场先生躁郁时，你也在躁郁。管住自己比管住市场更难。
```

## 五、巴菲特 × 你的系统

```
格雷厄姆框架 → 判断安不安全（安全边际）
巴菲特之道   → 判断好不好（护城河+管理层+ROE）
索罗斯反身性 → 判断现在对不对（市场情绪在哪）
指数基金     → 判断值不值得花时间（如果以上都不适用）

研究单只股票的完整决策链：
1. 巴菲特准则 → 这是好生意吗？（企业+管理+财务）
2. 格雷厄姆 → 价格安全吗？（安全边际）
3. 索罗斯 → 市场情绪对不对？（反身性位置）
4. 假概念识别 → 这个叙事是真的吗？（分部报告验证）
5. 决策 → 买/不买/观望/定投
```
