# 证券分析：格雷厄姆的专业教科书

> **来源**：本杰明·格雷厄姆 & 大卫·多德《证券分析》（Security Analysis, 1934年初版）
>
> **与《聪明的投资者》的关系**：《证券分析》是写给专业分析师的教科书（802页），《聪明的投资者》是给外行的简化版（305页）。前者教你怎么算，后者教你怎么想。
>
> **定位**：当你从"防御型投资者"升级到"进攻型投资者"时，需要这本书的分析技术。

---

## 一、内在价值：投资分析的第一性原理

```
格雷厄姆在证券分析中精确定义了"内在价值"：

内在价值 ≠ 市场价格
内在价值 ≠ 账面价值
内在价值 = 基于事实（资产、收益、股息）的合理估算

四个决定因素：
1. 企业资产（资产负债表）→ 清算价值底线
2. 企业盈利能力（损益表）→ 持续经营价值
3. 股息支付记录 → 管理层对股东的诚意
4. 未来前景 → 最不可靠的因素，只做保守假设
```

## 二、固定价值投资：债券分析的灵魂

```
格雷厄姆用全书最大的篇幅讲债券分析（现代投资者最常跳过的部分）。

核心原则：利息保障倍数 > 收益覆盖

债券的安全边际 = 公司赚的钱能不能轻松覆盖利息

标准：
├── 铁路/公用事业债券：利息保障至少 2.5-3倍
├── 工业债券：利息保障至少 3-4倍
└── 持有至到期：不是为了交易差价

映射到今天：
→ 这个框架解释了为什么中车的分红是安全的（利润覆盖分红2-3倍）
→ 也解释了为什么中铁不安全（利润覆盖弱，应收款威胁）
```

## 三、普通股分析：三张表的重新排列

```
损益表分析（最重要的分析工具）：
├── 剔除一次性/非经常项目（扣非净利润）
├── 7-10年平均收益，而非单年峰值
└── 趋势是危险的："用过去趋势推断未来 = 投机"

资产负债表分析：
├── 净流动资产价值 = 流动资产 − 全部负债
│   → 股价低于这个值 = 白送你还找钱
├── 清算价值 = 卖掉全部资产、还清全部债务后剩多少
│   → 如果市值 < 清算价值 = 最极端的安全边际
└── 商誉 = 超过净资产的部分，永远不值得溢价购买

股息分析：
├── 不分红的公司 → 必须证明留存收益创造了价值
└── 持续分红 >10年的公司 → 管理层值得信任
```

## 四、证券分析 × 你的系统

```
假概念识别三步法 = 证券分析损益表分析的现代版
├── 查分部报告 = 证券分析"剔除一次性项目"
├── 看扣非vs归母 = 证券分析"正常盈利能力"
└── 算应收/营收 = 证券分析"资产负债表测试"

周期分析 = 证券分析"7-10年平均"思路
→ 格雷厄姆不用一年的利润给公司定价
→ 你的周期光谱框架本质上是同一个逻辑
```
