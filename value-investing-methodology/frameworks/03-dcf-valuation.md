# DCF 现金流折现法（Discounted Cash Flow）

## 理论基础
**约翰·伯尔·威廉姆斯**（John Burr Williams）在《投资价值理论》（1938）中首次提出：股票的内在价值等于其未来所有股息的现值。巴菲特将其扩展为自由现金流折现框架。

---

## 核心理念

企业的内在价值等于其未来所有可分配给股东的自由现金流的现值之和。DCF 是理论上最严谨的估值方法，所有估值方法本质上都是 DCF 的简化形式。

---

## 核心公式

```
内在价值 = Σ (FCF_t / (1 + WACC)^t) + 终值 / (1 + WACC)^n
```

**变量说明**：

| 变量 | 说明 | 典型范围 |
|------|------|----------|
| FCF_t | 第 t 年自由现金流 | 基于历史趋势和行业分析 |
| WACC | 加权平均资本成本 | 8-12%（成熟企业） |
| n | 预测期年数 | 5-10 年 |
| 终值 | 预测期后所有现金流的现值 | 通常占估值 60-80% |

---

## 终值计算方法

### 永续增长法（推荐）
```
终值 = FCF_n × (1 + g) / (WACC - g)
```
- g：永续增长率（通常 2-3%，不超过 GDP 增速）

### 退出倍数法
```
终值 = 第 n 年 EBITDA × 行业退出倍数
```

---

## 操作流程

```
预测自由现金流 → 确定 WACC → 折现 → 计算终值 → 得出内在价值 → 对比市价
```

1. **预测 FCF**：基于历史增长率、行业前景、竞争优势
2. **确定 WACC**：CAPM 模型计算股权成本 + 债务成本加权
3. **折现**：逐年折现预测期 FCF
4. **计算终值**：通常使用永续增长法
5. **敏感度分析**：WACC ± 1%、增长率 ± 1% 对估值的影响
6. **对比市价**：内在价值 × 0.6-0.7 = 买入价格

---

## 适用场景

- 现金流稳定、可预测性强的企业（消费品、公用事业、基础设施）
- 成熟期企业（非高速成长期）
- 资本密集型行业

---

## 风险提示

- **对假设极度敏感**：WACC 或增长率微调 1%，估值可能变动 20-30%
- **终值占比过高**：终值通常占估值 60-80%，是一个"基于假设的假设"
- **不适用亏损企业**：没有稳定正现金流的企业无法使用 DCF
- 巴菲特名言："宁要模糊的正确，不要精确的错误"
