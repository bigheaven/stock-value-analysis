# 事件驱动策略（Event-Driven / Special Situations）

## 代表人物
**塞思·卡拉曼**（Seth Klarman, 1957–），Baupost Group 创始人，《安全边际》作者。他以特殊情况投资著称，管理数百亿美元的组合却常年持有大量现金，只在机会出现时出手。

---

## 核心理念

寻找企业事件带来的定价偏差，而非依赖市场整体估值水平。事件驱动策略的优势在于：回报与市场的相关性较低，在任何市场环境中都能找到机会。

---

## 四大事件类型

### 1. 分拆上市（Spin-off）
- 母公司股东被迫卖出（因不符合基金投资范围），导致新公司被低估
- 管理层激励机制通常在分拆后重新设计，利益更一致
- 案例：eBay 分拆 PayPal、百胜分拆百胜中国

### 2. 并购套利（Merger Arbitrage）
- 利用收购价与当前市价之间的价差
- 价差反映市场对交易完成的不确定性
- 年化收益率通常 5-15%
- 风险：交易失败时股价可能大幅下跌

### 3. 破产重组（Distressed Debt）
- 复杂证券（可转债、优先股、破产债权）被市场错误定价
- 需要深入的法律和财务分析能力
- 潜在回报极高，但风险也极高
- 在破产过程中，旧股东通常被清零，债券持有人获得新公司股权

### 4. 资产出售 / 清算
- 企业拥有未被市场充分定价的隐藏资产（房地产、子公司股权、专利组合）
- 清算价值高于市场价值
- 需要仔细分析资产负债表和附注

## 操作流程

```
监控事件 → 分析事件 → 计算预期回报 → 评估风险 → 建仓 → 事件完成 → 退出
```

1. **监控**：持续关注并购公告、分拆公告、破产申请
2. **分析**：深入研究文件、法律条款、时间表
3. **计算回报**：预期收益 × 成功概率 - 潜在损失 × 失败概率
4. **评估风险**：交易失败的最大损失是多少？
5. **建仓**：在价差合理时买入
6. **退出**：事件完成或价差消失

---

## 适用场景

- 并购活动活跃期
- 大型企业分拆非核心业务
- 债务危机后的破产重组机会
- 任何市场环境（策略回报与市场相关性低）

---

## 风险提示

- **并购失败风险**：反垄断审批、股东反对、融资困难都可能导致交易失败
- **时间不确定性**：交易可能比预期延长数月甚至数年
- **专业壁垒高**：需要法律、财务、税务综合知识
- **流动性风险**：某些特殊情况标的市场流动性差
- 不适合没有专业背景的普通投资者
