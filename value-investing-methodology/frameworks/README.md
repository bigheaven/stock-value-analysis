# 价值投资方法论框架

本目录包含六种核心价值投资方法论的独立框架文档，每个文档涵盖该方法的核心理念、关键指标、操作流程和适用场景。

## 五步分析流程速查

> 分析任何标的按五步走：**① 定性 → ② 定量 → ③ 估值 → ④ 排雷 → ⑤ 执行**。每步之间有明确的 go/no-go 决策点。

| 步骤 | 核心问题 | 决策点 |
|------|---------|--------|
| ① 定性 | 这是什么生意？护城河在哪？管理层靠谱吗？ | 不理解 → 放弃 |
| ② 定量 | 利润是真的吗？现金流健康吗？ | 数字不真实 → 放弃 |
| ③ 估值 | 用什么指标？安全边际够不够？ | 不够 → 等待或放弃 |
| ④ 排雷 | 有什么致命风险？ | 有 → 放弃 |
| ⑤ 执行 | 买多少？什么时候买？什么时候卖？ | — |
