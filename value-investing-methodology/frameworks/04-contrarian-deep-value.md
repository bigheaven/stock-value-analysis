# 逆向投资 / 深度价值（Contrarian & Deep Value）

## 代表人物
**霍华德·马克斯**（Howard Marks, 1946–），橡树资本联合创始人，《投资最重要的事》作者。**约翰·邓普顿**（John Templeton, 1912–2008），邓普顿基金创始人，在大萧条底部借入资金买入 104 只股票。

---

## 核心理念

在市场极端悲观时买入，利用市场情绪的错误定价。不关心企业是否"优秀"，而关心市场是否"过度恐慌"。马克斯的名言："我们不能预测未来，但可以判断当前市场处于什么位置。"

---

## 第二层思维

| 第一层思维（普通） | 第二层思维（逆向） |
|---------------------|---------------------|
| "这家公司盈利下滑，危险。" | "盈利下滑已被市场充分定价，股价已跌 60%，市场是否过度悲观？" |
| "这是好公司，买。" | "好公司已被追捧，估值过高，预期已满。" |
| "经济前景黯淡，远离股市。" | "悲观情绪已充分反映，最坏情况可能已被定价。" |
| "这只股票涨了很多，追。" | "价格上涨已反映乐观预期，追高风险大于收益。" |

## 市场情绪周期

```
乐观 → 兴奋 → 狂热 → 否认 → 恐慌 → 投降 → 绝望 → 回归理性
  ↑                                                      ↓
  └──────────────── 逆向投资者入场区间 ──────────────────→
```

---

## 操作流程

```
观察市场情绪 → 识别过度悲观 → 区分暂时性/永久性 → 分批建仓 → 耐心持有 → 情绪恢复后退出
```

1. **观察情绪**：关注 VIX 指数、媒体头条、分析师评级变化
2. **识别过度悲观**：价格是否已反映最坏情况？下跌幅度是否超过基本面恶化？
3. **区分困境性质**：是暂时性困境（周期性、一次性事件）还是永久性恶化（商业模式被颠覆）？
4. **分批建仓**：不一次性买入，在下跌过程中分 3-5 批建仓
5. **持有**：耐心等待市场情绪恢复，可能 6 个月到 3 年
6. **退出**：悲观情绪消散、估值回到合理水平

---

## 适用场景

- 熊市底部、行业危机（如 2008 金融海啸、2020 疫情暴跌）
- 周期性行业底部（能源、矿业、航运）
- 遭遇一次性负面事件的企业（诉讼、事故、监管处罚）

---

## 风险提示

- **心理要求极高**：需要承受"买在左边"的孤独和持续浮亏压力
- **区分暂时性 vs 永久性**是最大挑战——判断错误将导致永久性亏损
- 抄底过早可能面临大幅回撤（"接飞刀"）
- 不适合情绪化的投资者
