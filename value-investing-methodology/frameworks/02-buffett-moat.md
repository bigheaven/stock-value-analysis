# 护城河投资法（Moat Investing）

## 代表人物
**沃伦·巴菲特**（Warren Buffett, 1930–）与 **查理·芒格**（Charlie Munger, 1924–2023），伯克希尔·哈撒韦的掌舵者。受 **菲利普·费雪**（Philip Fisher）成长股定性分析思想影响。

---

## 核心理念

以合理价格买入拥有持久竞争优势的卓越企业，并长期持有。芒格说服巴菲特从"以便宜价格买入平庸企业"转向"以合理价格买入优秀企业"，这一转变是价值投资史上最重大的范式转换。

---

## 护城河五维度

| 维度 | 说明 | 典型案例 |
|------|------|----------|
| 品牌溢价 | 消费者愿意为品牌支付更高价格 | 可口可乐、茅台 |
| 转换成本 | 客户更换供应商的成本极高 | 微软 Office、SAP |
| 网络效应 | 用户越多，产品价值越大 | 微信、Visa、万事达 |
| 规模优势 | 规模带来的成本优势 | 沃尔玛、Costco |
| 专利壁垒 | 技术或法规保护 | 辉瑞、ASML |

---

## 管理层评估清单

- [ ] 诚信记录：是否有不良历史？薪酬是否合理？
- [ ] 能力：历史资本回报率（ROIC）是否持续优秀？
- [ ] 资本配置：回购、分红、并购决策是否理性？
- [ ] 股东导向：是否"像所有者一样思考"？
- [ ] 坦诚度：是否在年报中诚实讨论错误和挑战？

---

## 操作流程

```
理解业务 → 评估护城河 → 评估管理层 → 估值 → 安全边际 → 买入并持有
```

1. **理解业务**：能否用三句话讲清楚这家公司如何赚钱？
2. **评估护城河**：五个维度中至少有一个明确优势
3. **评估管理层**：诚信、能力、资本配置缺一不可
4. **估值**：DCF 或盈利倍数估值，判断内在价值
5. **安全边际**：以内在价值的 60-70% 买入
6. **持有**：只要护城河不被侵蚀，长期持有

---

## 适用场景

- 消费、金融、基础设施等可预测行业
- 具有明显品牌、网络效应或规模优势的企业
- 长期投资（5 年以上）

---

## 风险提示

- 护城河可能被技术变革摧毁（柯达、诺基亚）
- 管理层变更可能改变企业方向
- 合理价格"的判断具有主观性
- 需要极强的耐心和情绪控制能力
