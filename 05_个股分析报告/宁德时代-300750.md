## 三、① 定性：生意本质

### 3.1 一句话生意

**宁德时代是全球动力电池 + 储能的绝对龙头，卖的是"电化学系统的确定性"——安全、一致、大规模、低成本的电池。** 它的客户不是消费者，而是车企（B2B），但它正在把自己做成一个"消费级信任品牌"。

### 3.2 护城河四维评估（20分制）

| 维度 | 评分 | 依据 |
|------|:----:|------|
| **规模效应** | 5/5 | 全球份额39.9%，产能525GWh+在建764GWh，单位成本行业最低 |
| **技术壁垒** | 5/5 | 麒麟/神行/骁遥/钠离子，每瓦时赚0.1元 vs 二线2-3分钱 |
| **客户黏性/转换成本** | 4/5 | 30万+车型66%搭载；但二供报价低10-20%在侵蚀 |
| **品牌心智（B2B2C）** | 4/5 | 尼尔森报告"四成消费者非宁德不选"，信任度81% |

**护城河总分：18/20 —— 极宽，属于A级护城河。**

### 3.3 管理层与治理

- **曾毓群**：技术出身（中科院物理所背景），工程师文化，战略克制，聚焦主业
- 分红+回购意愿强（A股史上最大规模回购托底）
- 治理稳健，无内斗、无多元化冲动

**定性结论：这是一门"强者恒强"的规模+技术生意，护城河极宽，但正从"暴利"走向"合理利润"——GO。**

宁德已从"高成长科技股"切换为"成熟龙头"，估值中枢从40-60x永久下移到15-25x，选 **PE锚**。

## 六、④ 排雷：风险识别（重点：去宁德化）

### 6.1 核心风险：去宁德化的真实影响——**"重构定价"而非"崩塌"**

这是本轮下跌的唯一核心叙事，需要拆穿三件事：

**（1）"去宁化"是真实发生的，但被误读为"订单崩塌"**

时间线（2026年8-9月）：
- 理想26.5亿增资欣旺达动力、获11.17%股份成第二大股东；全新L8全系切欣旺达电芯，i6引入欣旺达+中创新航
- 小米"龙甲电池"：中创新航供三元、欣旺达供磷酸铁锂
- 问界引入中创新航、国轩高科，终结独供
- 宝马新一代平台高配定点亿纬锂能大圆柱，大众/上汽通用引入二供

**（2）但数据与"崩塌"完全相反**

| 指标 | 数据 | 含义 |
|------|:----:|------|
| 2026H1国内乘用车装车份额 | **46.7%（+5.6pct）** | 不降反升 |
| 全球市占率 | **39.9%（+1.7pct）** | 连续9年第一 |
| 2026Q1国内份额 | 50.1% | 时隔五年重夺半壁江山 |
| 30万+车型搭载率 | 66% | 高端难撼动 |

**摩根大通测算**：小米+理想各自仅占宁德国内出货7-8%，而国内市场占总出货不到35%——**单一客户风险敞口极其有限**。摩根大通维持"超配"。

**（3）去宁化的真实杀伤力：不是丢份额，是丢"议价权"→ 毛利率中枢**

传导链条：车企有自研+二供筹码 → 逼宁德降价保份额 → 毛利率承压。这已在2026中报显现：**综合毛利率23.93%（同比-1.1pct）**，动力电池毛利率20.63%被压至低位。

去宁化的本质是**"把宁德从必选项压成重要可选供应商"**，中期（3-5年）让净利率从17%向下走，是"估值逻辑从成长股切向周期制造股"的真正来源。

### 6.2 其他风险识别

| 风险 | 等级 | 说明 |
|------|:----:|------|
| 去宁德化（议价权侵蚀） | 中高 | 中期定价权弱化，非订单崩塌 |
| 价格战/产能过剩 | 中 | 二线厂低10-20%抢单 |
| 固态电池技术代际切换 | 中低(长期高) | 比亚迪2027量产，若宁德掉队才是真"去宁化" |
| 海外政策/关税 | 中 | 境外毛利率29.97%是核心利润，受贸易摩擦影响 |
| 增速中枢下移 | 中 | 从40%+向20-30%收敛 |
| 特斯拉自研4680 | 低 | 仅满足自身<4%需求 |

### 6.3 排雷结论

**无致命风险，但有中期"盈利模型重估"风险。去宁化不致命，但会永久性压低毛利率中枢——这是"逻辑杀"而非"业绩杀"。可以投资，需接受估值中枢下移的现实。**

## 七、⑤ 执行：仓位 + 时机 + 纪律

### 7.1 仓位建议

**4-6%（优质龙头可给较重仓位）**，分散1-2次建仓，避免一次性满仓。

### 7.2 买入信号清单

- [ ] 股价进入 280-300 元区间（PE 14-15x，对应很便宜）
- [ ] 出现"去宁化"情绪宣泄后的缩量企稳（如跌破300后快速收回）
- [ ] 2026Q3财报毛利率守住 23% 以上
- [ ] 储能业务增速持续>50%，对冲动力电池毛利下滑
- [ ] 固态电池/钠离子出现量产里程碑

### 7.3 卖出纪律（触发即减/清）

- [ ] 毛利率 < 20%（降价保份额恶化的确认信号）
- [ ] 国内动力份额 < 40%（护城河真正被动摇）
- [ ] 固态电池代际切换中掉队（技术领先性丧失）
- [ ] 估值修复至 PE 22-25x（合理偏贵，兑现收益）
