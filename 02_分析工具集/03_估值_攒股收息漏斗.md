# 攒股收息漏斗（Dividend Income Funnel）——五层筛选，宁缺毋滥

> **免责声明**：本报告基于公开信息综合分析，不构成任何投资建议。数据为示意性判断，非预测。
>
> **数据截止日期**：2026 年 8 月 3 日
>
> **信息来源**：crypto猫meme《像漏斗一样筛选 A 股5000多只股票》视频文案（2026-07-31）方法借鉴 + vault 个股档案（2026-07/08）+ 对话沉淀（2026-08-02/03）

## 一句话定性

**老王漏斗筛"能涨的成长股"，攒息漏斗筛"能稳定分红的收息资产"——两个漏斗同一形状，过滤网完全不同。攒息漏斗的产出不是"买入名单"，是"收息资格名单"：通过五层者进入攒息池，未通过者即使股息率高也不是攒息标的。核心纪律一句话：宁可错过一百只，不买错一只。**

## 为什么不能直接套用成长股漏斗

老王漏斗（ROE>15%、毛利率>40%、营收增速>10%、PEG<1.5）是成长股筛法，套在收息标的上会把最好的攒息标的全部误杀：

| 标准 | 成长股漏斗 | 攒息漏斗 | 误杀案例 |
|------|-----------|---------|---------|
| ROE | 连续三年 >15% | 与 PB 匹配即可（银行 8-13% 正常） | 工行 ROE 8.83% 会被淘汰，但它是 A 股最接近国债的收息标的 |
| 毛利率 | >40% | 不适用（银行/公用事业无此概念） | 招行/长江电力无毛利率可言 |
| 营收增速 | 持续 >10% | **不要求增长**——收息买的是现金流不是增长 | 格力主业 -16.4% 仍是核心攒息标的 |
| 估值 | PE 分位 <30%、PEG<1.5 | 股息率 ≥4% + 派息率合理 | 神华 PE 96.9% 分位"贵"，但分红承诺 65% 是最制度性的 |

**本质差异**：成长股买的是"未来的利润"，攒息买的是"现在的现金流"——筛子自然不一样。

## 五层漏斗

```
A股 5000+ 只 / vault 50+ 只
   ↓ 第一层 排除（硬伤直接出局）
   ↓ 第二层 门槛（股息率 ≥4%）
   ↓ 第三层 质地（派息率 30-80% + 连续分红）
   ↓ 第四层 匹配（ROE 与 PB、估值与价格）
   ↓ 第五层 属性（中国式攒息 = 垄断补偿）
攒息池（通常个位数）
```

### 第一层：排除（硬伤直接出局）

| 排除项 | 判断 | 案例 |
|--------|------|------|
| 利润恶化/连续亏损 | 分红根基在动摇 | 民生银行（利润恶化中，4.99% 股息率不可攒） |
| FCF 为负还分红 | 分红靠老本，终有挤完的一天 | 大秦铁路（FCF −163 亿，警告级而非出局——看 ROE 能否修复） |
| 股息率伪抬升 | 高息是市场不信任的定价 | 碧桂园服务 9.7%（净现金占市值 90%+ = 资产有水分） |
| 大股东频繁减持 | 老板在跑路 | — |
| 负债率 >70% | 资金链风险（银行/公用事业除外） | — |

**关键**：股息率越高越要先查"为什么高"——9% 的股息率大概率是价格跌出来的，不是现金流好出来的。

### 第二层：门槛（股息率 ≥4%）

- 相对存款 ~1.5% 的**剪刀差**是"攒"的意义（参照系里的搬家引力）
- 口径要注明：TTM / 静态 / 全年平均股价——中车 TTM 5.1% vs 静态 3.6-4.0%，同一只股票口径差 1.5 个点
- **3.5-4% 边缘带**：长江电力 3.68% 差一点到门槛，但水电垄断 + 市场用"股息率-国债息差"定价、稳定性全场最强——边缘带看稳定性补偿
- H 股通常比 A 股高（工行 4.22% A vs 5.99% H）——同标的选哪个市场看股息率与税负

### 第三层：质地（派息率 30-80% + 连续分红）

| 检查项 | 合理区间 | 反面案例 |
|--------|---------|---------|
| 派息率 | **30-80%** | <30%：想分没多少可分（中铁 18%）；>80%：不可持续（建滔 87%，扩产期存疑） |
| 连续分红年数 | 越长越好 | 双汇 26 年 / 中车 18 年 / 平安 14 年连续增长 |
| 承诺分红 | 中国式制度性加分 | 神华承诺 ≥65%（实际 79%）、大秦承诺 ≥55%（实际 75%）、石油年均 51% |

> **承诺分红的双刃剑（2026-08 补充）**：承诺是加分项的前提是**利润配得上承诺**。利润下滑期刚性兑现 = 超派息透支未来——五粮液 2025 利润腰斩（归母 89.54 亿，−71.89%）仍兑现 200 亿分红 → 派息率 223%，靠 1270 亿现金老本撑着，性质从"制度性现金流"变成"股东回报承诺的刚性负担"。判断口诀：**派息率 >100% = 分红在透支未来，永远不是攒息资格**（哪怕承诺再刚、现金再多）。
| 分红频次 | 中期分红 = 意愿增强信号 | 中车 2025 首推中期分红（央企市值管理考核的直接落地） |

### 第四层：匹配（ROE 与 PB、估值与价格）

- **低 ROE 破净 = 公允价不是错杀**：大秦 ROE 3.44% vs PB 0.61——破净是市场对低 ROE 的定价，攒息也救不了基本面
- **银行破净是行业现象**，不看 PB 看 ROE 与资产质量：招行 13.4%/不良 0.94% vs 华夏 1.57%/拨备 146%——同为收息，质地差一个量级
- **高估值攒息要付溢价**：美的 PB 3.25——攒息也要买得合理，好公司贵价格（神华）的应对是等而非追
- 配套：[[deep-value-vs-trap-checklist-深度价值vs价值陷阱]] 八维打分 + 三条一票否决

### 第五层：属性（中国式攒息 = 垄断补偿）

参照系框架：**中国高股息 = 垄断补偿（像日本商社化）而非增长（像美国/印度）**。攒息标的的本质是"制度性现金流"：

| 属性 | 案例 |
|------|------|
| 牌照垄断 | 招行（零售）、平安（保险）、四大行（信用牌照） |
| 自然垄断/一体化 | 长江电力（水电）、神华（煤电路港航）、大秦（西煤东运独木桥） |
| 品牌定价权 | 格力、双汇（26 年分红刚需消费） |
| 制度性分红承诺 | 央企承诺分红（神华/石油/大秦）——市值管理考核加持 |
| **反例：周期股高分红** | 建滔 87% 派息——周期顶部的慷慨分红不是攒息，是周期红利 |

## 攒息 vs 买点分离（重要纪律）

- 攒息漏斗回答"**什么值得持有**"，不回答"什么价格买"——第五层之后还要接老王漏斗的第五层"等信号"：技术面确认（右侧交易/均线）再动手，不追高不抄底
- 配套：[[buy-timing-confirmation-checklist-买入时机确认清单]]（六项信号：估值分位/业绩/资金/叙事/情绪/技术）
- **攒息 ≠ 一直持有**：大秦/中车这类"有资格待验证"的，用档案跟踪信号验证，验证不过就降级

## 总回报视角：股息率之外还有回购（方法论回填 2026-08）

**总股东回报 = 股息率 + 回购收益率**——只看股息率会漏掉"注销式回购"这条隐性的分红通道：

- **回购收益率 = 回购金额 ÷ 市值**：回购注销 = 永久减少股本 = 每股股息/EPS/ROE 自动变厚——是"给所有股东的分红"，只是换了一种发法（格力/美的/五粮液/茅台/腾讯都是注销式）
- **⚠️ 必须区分注销式 vs 激励式**：回购用于股权激励/员工持股 = 股本不减少甚至扩大，回报价值大打折扣（京东方 4.71% 回购收益率是激励式 ⚠️）；**只认注销式**
- **总回报黄金档 ≥6%**（IMA《总回报》2026-07）：宏桥 11.3% / 中远 9.8% / 格力 7.4% / 顺丰 7.0% / 中通 6.7% / 五粮液 6.6% / 新奥 6.5% / 美的 6.4% / 海尔 6.3%；白银档 4.5-6%；青铜档 2-4.5%；观察档 <2%
- **回购收益率排名**（IMA《回购池》）：顺丰 4.60% / 宏桥 4.01% / 中通 3.81% / 中远 3.32% / 友邦 2.85% / 舜宇 2.80% / 小米 2.68%
- **用法**：漏斗第五层后加一道"总回报复核"——股息率卡 3.5% 边缘的标的，若回购注销收益率 ≥1.5%，总回报可补过 4% 门槛（五粮液 6.6% 息 + ~2.5% 回购 ≈ 9%）；但**回购是一次性行为，股息才是制度性现金流**——回购可加分，不能替代派息率与连续分红的验证

## DDM 成长股息：合理买入价的锚（方法论回填 2026-08）

股息率门槛回答"什么值得持有"，DDM 回答"**什么价格买不吃亏**"——给"买点即成本"提供算术锚：

- **公式**：合理买入价 = 每股股息 ÷（目标收益率 T − 股息增速 g）；目标收益率 T 取 7%（跑赢通胀 + 存款剪刀差）
- **口径**：每股股息取 TTM/最新年度；g 取近 5 年股息增速或承诺增速，增速不足 0 按 0 算（保守）
- **安全边际**：现价低于合理价 X% = 股息收益率的缓冲垫（IMA《买入价 V2》2026-07：移动 A 合理 ¥163.07 现价 +39%、平安 ¥141.75 +61%、新奥 ¥51.97 +65%——"低估可买"档；长电/海尔"成长型股息现价合理"档）
- **⚠️ 反直觉警示**：DDM 对"高派息率低增速"标的最苛刻——神华 92% / 双汇 96% / 大秦 101% 派息率的标的，股息增速 g 趋近 0，合理价对 T 极度敏感（T 微调，合理价大动）；**>80% 派息率的标的 DDM 显示"贵"不是算错了，是分红不可持续的信号**
- **用法**：DDM 合理价是"安全边际锚"，不是"现价该买"的信号——合理价 + 六信号（估值/业绩/资金/叙事/情绪/技术）双确认才动手；股价涨 = 安全边际收缩（移动 +39% → +20%，攒息收益变薄）

## 降成本：买出来的，不是摊出来的

攒息者常纠结"要不要摊低成本"——**有必要降成本，但正解是买点管理，不是补仓摊薄**：

- **摊薄 = 锚定陷阱**：摊薄的潜台词是"我的成本是 X，跌到 Y 补一笔摊平"——锚定的是自己的成本价，不是股票的价值。决策依据永远应该是"当前价格值不值得买"（五层资格 + 六信号），不是"补完成本降到多少"
- **摊薄最危险时点 = 资格动摇时**：大秦（ROE 3.44%、FCF −163 亿）越摊越深不是降成本，是接飞刀。补仓前提：五层漏斗没过期 + 六信号满足，缺一不动

| 降成本方式 | 逻辑 | 对应框架 |
|-----------|------|----------|
| **买点即成本**：等股息率安全边际 | 每股分红不变，34 元买入实际收息 5.9%、41 元买入 4.9%——买入价直接决定攒息收益率，省下的每分成本都是永久收益 | 六信号 + "股价涨 = 攒息收益变薄" |
| **分批对应股息率档位** | 底部不可知时，分批本身就是成本平均化——但批次按档位触发（5.0% 建半仓、5.5% 加、6% 再加），不是按月无脑定投 | 参照系：日本式攒息路径 |
| **分红再投资** | 攒息的钱滚成股数，股数增长才是"攒"的本义——复利发生在股数上，不在成本上 | 股息占长期收益 ~70%（全球股息文化） |

**一句话**：攒息的成本是买出来的（在股息率高的位置买），不是摊出来的（为摊薄而补仓）。

## 做 T 增厚股数：把差价利润变成现金流权

攒息的核心指标是**股数**不是成本——**股息 = 股数 × 每股股息 × 持有年限**。对同一只股票频繁低买高卖、让股数增加、平均成本降低，这个动作对攒息者有真实意义：

- **差价利润 → 股数 = 市场发的"股数股息"**：招行每股 2.02 元分红，1 万股 = 每年 2.02 万；做 T 三年股数做到 1.3 万股 = 每年 2.63 万——**股数 +30%，现金流 +30%，且永远有效**（不随股价波动归零）
- **与公司回购同方向**：公司注销 = 每股股息变厚（格力/美的回购注销）；做 T 增厚股数 = 现金流权变大——**给自己做"个人版回购"**
- **反面教训**：清仓 = 复利断掉、攒股清零重来。炒股多年却股息微乎其微的根源通常不是"股息少"，是"股数从没积累起来"——每次"觉得不好就换"都把攒的股数归零，是把交易当目的、攒股当附庸

**做 T 三条纪律（缺一条就是负贡献）**：

1. **底仓永不清**：做 T 是在攒息资格上做增厚；只有五层资格变化才动底仓
2. **信号确认才动手**：六信号（估值/业绩/资金/叙事/情绪/技术）给买卖点，不是日内博弈
3. **成败标准 = 股数净增**：高卖后等不到低点、或跌了不敢接回 → 股数变少 = 这次做 T 是负分。**做 T 可以失败很多次，股数必须永远朝上**

## 更新纪律

- 每年中报 + 年报后各重跑一遍（分红资格随财报变化）
- 股息率口径变化（股价涨跌）触发重估：中车股价两周涨 11%，股息率 5.71%→5.1%，安全边际收缩——**股价涨不是好消息，是攒息收益变薄**
- 用 vault 个股档案的"跟踪信号"承接验证（大秦 8/21、工行半年报、中车 8 月中报）
