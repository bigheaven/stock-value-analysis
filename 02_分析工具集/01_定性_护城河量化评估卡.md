# 护城河量化评估卡：从定性五维度到定量八指标

> **定位**：把巴菲特的护城河五维度（品牌、转换成本、网络效应、规模优势、专利壁垒）从定性描述落地为可打分的量化工具体系。与 `buffett-way-巴菲特之道` 和 `frameworks/02-buffett-moat` 配合使用。
>
> **触发使用**：完成护城河五维度定性分析后，用本卡量化评估，辅助判断"这到底是不是真正的护城河"。

---

## 一、核心逻辑

```
护城河的本质 = 企业能否在 10 年以上持续赚取超额利润

超额利润 = ROIC > WACC（持续）

没有护城河 → 资本涌入 → 竞争加剧 → ROIC 回归平均
有护城河   → 竞争被阻挡 → ROIC 持续高于平均
```

---

## 二、五维度定性评分（每维 0-4 分，满分 20）

### 维度 1：品牌溢价

| 得分 | 标准 | 量化验证 |
|------|------|---------|
| 0 | 无品牌，产品完全同质化 | 价格 = 同行 |
| 1 | 有一定知名度，但无溢价能力 | 市占率 5-10% |
| 2 | 区域/细分品牌，有一定定价权 | 毛利率高于同行 3-5pp |
| 3 | 全国性强势品牌，显著定价权 | 毛利率高于同行 5-10pp，持续 5 年+ |
| 4 | 全球顶级品牌，消费者愿意排队/溢价 | 毛利率高于同行 10pp+，持续 10 年+ |

### 维度 2：转换成本

| 得分 | 标准 | 量化验证 |
|------|------|---------|
| 0 | 无转换成本，随时可换 | 客户流失率 > 30% |
| 1 | 有一定惯性，但转换成本低 | 客户流失率 15-30% |
| 2 | 转换需要投入时间/金钱/培训 | 客户流失率 5-15% |
| 3 | 转换成本极高，嵌入客户业务流程 | 客户流失率 < 5%，续约率 > 90% |
| 4 | 锁定效应，客户几乎不可能离开 | 客户流失率 < 2%，续约率 > 95% |

### 维度 3：网络效应

| 得分 | 标准 | 量化验证 |
|------|------|---------|
| 0 | 无网络效应 | 用户增长不增加产品价值 |
| 1 | 微弱的双边市场 | 有一定匹配价值 |
| 2 | 明显的网络效应，但非垄断 | 市占率 20-40% |
| 3 | 强网络效应，市场份额 > 50% | 胜者通吃格局 |
| 4 | 绝对垄断，网络效应不可逆 | 市占率 > 70%，新进入者无法挑战 |

### 维度 4：规模优势

| 得分 | 标准 | 量化验证 |
|------|------|---------|
| 0 | 无规模优势 | 与同行成本结构无差异 |
| 1 | 有一定规模，但优势不明显 | 成本率略低于同行 |
| 2 | 区域规模优势 | 在核心市场有明显成本优势 |
| 3 | 全国性规模优势 | 成本率低于同行 5pp+ |
| 4 | 全球性规模优势，后来者无法复制 | 成本率绝对领先，规模是第二名的 3 倍+ |

### 维度 5：专利/管制壁垒

| 得分 | 标准 | 量化验证 |
|------|------|---------|
| 0 | 无专利/管制保护 | 任何企业可自由进入 |
| 1 | 有少量专利，但非核心 | 持续有研发投入 |
| 2 | 核心专利保护，但 3-5 年到期 | 专利到期后可能面临仿制 |
| 3 | 强专利组合 + 持续创新 + 监管壁垒 | 专利群 + 监管牌照 |
| 4 | 法定垄断或寡头管制 | 牌照数量有限，新进入者被法律禁止 |

## 三、八项定量指标验证（每项 0-2 分，满分 16）

| # | 指标 | 0 分（弱） | 1 分（合格） | 2 分（强） |
|---|------|-----------|-------------|-----------|
| 1 | **ROIC（5 年平均）** | < 10% | 10-15% | > 15% |
| 2 | **ROIC 稳定性** | 波动 > 10pp | 波动 5-10pp | 波动 < 5pp |
| 3 | **毛利率（5 年平均）** | < 20% | 20-40% | > 40% |
| 4 | **毛利率稳定性** | 波动 > 5pp | 波动 2-5pp | 波动 < 2pp |
| 5 | **市场份额（vs 第二名）** | < 1.5x | 1.5-3x | > 3x |
| 6 | **市场份额趋势** | 近 3 年下降 | 持平 | 近 3 年上升 |
| 7 | **FCF/净利润（5 年平均）** | < 0.5 | 0.5-0.8 | > 0.8 |
| 8 | **研发/营收（科技行业）** | < 3% | 3-8% | > 8%（持续创新） |

## 四、综合判定

```
第一阶段：定性评分（满分 20）
├── < 6 分  → 无护城河，按周期股/普通股处理
├── 6-12 分 → 弱护城河，需持续跟踪
├── 13-17 分 → 强护城河，可以合理价格买入
└── 18-20 分 → 极强护城河，高概率长期持有

第二阶段：定量验证（满分 16）
├── 与定性评分匹配 → 护城河判断可信
├── 定量显著低于定性 → 护城河可能在削弱，重新评估
└── 定量显著高于定性 → 护城河可能被低估，值得深入研究

第三阶段：趋势判断
├── ROIC 趋势 ↑ → 护城河在加深
├── ROIC 趋势 → → 护城河稳定
└── ROIC 趋势 ↓ → 护城河被侵蚀（最危险的情况）
```

---

## 五、护城河侵蚀的五个早期信号

```
1. 毛利率连续 2 年下降，且降幅 > 2pp
2. 市场份额被第二名快速追赶（差距缩小 > 20%）
3. 客户向竞争对手迁移的案例增多
4. 核心专利在未来 3 年内到期，且无替代技术储备
5. 行业出现颠覆性技术，但企业无明确应对策略
```

## 六、行业护城河强度速查

| 行业 | 最强护城河类型 | 典型 ROIC 范围 | 评估重点 |
|------|--------------|---------------|---------|
| 消费品 | 品牌 + 规模 | 15-30% | 品牌力是否持续？毛利率是否稳定？ |
| 科技平台 | 网络效应 + 转换成本 | 20-40% | 用户是否还在增长？竞品是否在侵蚀？ |
| 金融 | 规模 + 管制 | 10-18% | 资产质量、监管政策变化 |
| 基础设施 | 管制 + 规模 | 8-12% | 牌照稳定性、政策风险 |
| 医药 | 专利 + 品牌 | 15-35% | 专利悬崖、管线储备 |
| 矿业 | 资源壁垒 + 规模 | 5-20%（周期） | 资源品位、成本曲线位置 |
