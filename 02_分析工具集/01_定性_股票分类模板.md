# 新股票入库模板 · 先分类，再深挖

> **⚠️ 本模板仅做初判分类，不构成买卖建议。** 目的：帮你在深挖前选对分析框架,避免用成长股框架分析了周期股。
>
> **建议用时**：15 分钟完成初判。做完后如果值得深挖,再开 OpenSpec change。
>
> **分类框架**：[[cycle-growth-spectrum-framework-周期光谱框架]]
>
> **参考案例**：[[existing-portfolio-spectrum-mapping]]

## 第一步：一句话分类（快速判定表）

填下表,约 5 分钟（不知道确切数据就估,标注"C = 估算"）：

### 三问判定

```
1. 渗透率：这个产品/服务,现在多少人已经在用了？
   [ ] < 5%    —— 极早期,九死一生
   [ ] 5-30%   —— 黄金爆发期 ✅ 最安全的成长投资期
   [ ] 30-50%  —— 增速放缓,接近天花板 ⚠️
   [ ] > 50%   —— 存量博弈
   [ ] 不适用    —— 说明:_______________

   渗透率是在加速还是放缓？
   [ ] 加速  [ ] 匀速  [ ] 放缓  [ ] 停滞

2. 资产轻重：公司要赚多一倍的钱,需要投多一倍的厂房机器吗？
   [ ] 轻资产  —— 边际成本递减（软件/品牌/平台）
   [ ] 中资产  —— 需要一定投入但有规模效应（器械/电子制造/医药）
   [ ] 重资产  —— 扩产 = 巨量固定投资（钢铁/化工/航运/采矿）

   在建工程趋势(如果是制造类):
   [ ] 下降  [ ] 平稳  [ ] 上升  [ ] 飙升 🔴

3. 靠什么挡住对手？（选最主要的一种）
   [ ] 网络效应  —— 用的人越多产品越好（微信/淘宝）
   [ ] 技术壁垒  —— 专利/架构/研发积累,对手追不上（ASML/NVIDIA）
   [ ] 品牌壁垒  —— 消费者心智占据（茅台/爱马仕）
   [ ] 规模壁垒  —— 成本最低,量大价格低（宁德时代/海螺水泥）
   [ ] 资本壁垒  —— 我砸钱最多,建了最大工厂
   [ ] 无壁垒     —— 纯靠价格竞争

   这个壁垒现在是在变强还是变弱？
   [ ] 加宽  [ ] 稳定  [ ] 收窄 ⚠️  [ ] 瓦解 🔴
```

### 三问 → 光谱定位

对照 [[cycle-growth-spectrum-framework-周期光谱框架]] 的五段分区：

| 你的三问组合 | 大概率落在 | 打法方向 |
|---|---|---|
| 渗透率 5-30% + 轻/中资产 + 技术/网络壁垒正加宽 | **纯成长** | 第二步→成长股分析路径 |
| 渗透率接近 30% 或趋势放缓,其他绿灯 | **成长偏周期** | 成长路径为主,重点盯渗透率拐点 |
| 至少一个维度开始退化(如渗透率 > 30%+壁垒在收窄) | **灰色地带⚠️** | 拆业务线,退化线用周期框架 |
| 渗透率已过顶点 + 壁垒仍强 + 周期底部回升 | **周期偏成长** | 周期路径为主,盯供给拐点+库存 |
| 渗透率 > 50% 或同质化 + 重资产 + 资本/无壁垒 | **纯周期** | 纯周期股分析路径 |

## 第二步：选择分析框架

### 路径 A：成长股分析（纯成长 / 成长偏周期）

> 核心口诀：择股 > 择时。渗透率 5-30% 黄金期进去,赚的是"蛋糕做大"的钱。

| 分析维度 | 要回答的核心问题 | 关键数据 |
|---|---|---|
| 渗透率验证 | 5-30% 的判断靠谱吗？加速还是放缓？ | 行业报告/出货量/用户数 |
| TAM(总可及市场) | 蛋糕最终多大？剩下多少空间？ | 机构一致预测 |
| 护城河深度 | 为什么对手追不上？壁垒在加宽吗？ | 研发率/专利/用户粘性 |
| 管理层与执行力 | 团队能不能把渗透率从 10% 推到 30%？ | 历史兑现率/战略清晰度 |
| 合理估值 | PEG < 1？PS 相对渗透率合理吗？ | PEG/PS/远期PE |

**注意**：成长股**不要只盯着 PE 看**。50 倍 PE 但利润每年 +100%,一年后就变 25 倍——文案的核心论点。

→ 开 OpenSpec change,命名如 `<ticker>-growth-deepdive`

### 路径 B：周期股分析（纯周期 / 周期偏成长）

> 核心口诀：择时 > 择股。高 PE(亏损)时买,低 PE(暴利)时卖。盯的不是公司,是供给。

| 分析维度 | 要回答的核心问题 | 关键数据 |
|---|---|---|
| 供给格局 | 现在有多少产能？谁在减产/退出？ | 行业产能利用率 |
| 库存周期 | 库存还有多少？去化到什么程度了？ | 行业库存数据 |
| CAPEX 周期 | 在建工程在上升还是下降？ | 在建工程/资本开支 |
| 成本曲线 | 全行业的成本底在哪？谁能熬到春天？ | 成本分位图 |
| 合理估值 | 正常化利润下的 PE 多少？股息够厚吗？ | 正常化PE/EV-EBITDA/股息率 |

**注意**：周期股**看到 3 倍 PE 一定要跑,不是买**。暴利会吸引资本疯狂扩产,1-3 年后产能释放 = 利润雪崩——文案反复强调的陷阱。

→ 开 OpenSpec change,命名如 `<ticker>-cycle-timing`

### 路径 C：灰色地带拆线分析

> 核心问题：**在退化的那条线,退化是可逆的还是不可逆的？**

```
拆线步骤:
1. 把公司的收入/利润按业务线拆开
2. 每条业务线独立跑第一步的"三问判定"
3. 退化中的线 → 按周期股框架分析（路径 B）
   还在成长的线 → 按成长股框架分析（路径 A）
4. 分别估值后,按营收/利润权重合成整体估值
5. 核心判断: 成长线的增量能否在未来 2-3 年内跑赢退化线的缩量？

示例(迈瑞医疗):
  国内IVD —— 灰色(周期化中) → 路径B
  海外IVD —— 纯成长 → 路径A
  生命信息 —— 周期底 → 路径B(择时买入)
  新兴业务 —— 纯成长 → 路径A
  整体 = 路径B主导短期 + 路径A主导长期
```

→ 开 OpenSpec change,命名如 `<ticker>-hybrid-deepdive`

## 第三步：开 OpenSpec 深挖

完成初判后,如果判定值得深挖:

1. 用 `/opsx:propose` 创建新 change（命名基于分析路径,如 `xxx-growth-deepdive` 或 `xxx-cycle-timing`）
2. 在 proposal 的 Capabilities 里引用 [[cycle-growth-spectrum-framework-周期光谱框架]] 的分类结论
3. 按对应路径的分析维度建 spec
4. `/opsx:apply` 执行深挖
