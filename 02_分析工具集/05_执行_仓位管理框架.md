# 仓位管理框架：凯利公式 + 金字塔建仓 + 组合配比

> **定位**：价值投资中"买多少"的系统框架。你的 playbooks 在"买什么"和"什么时候买/卖"上很强，本框架补上"买多少"这一环。
>
> **核心问题**：即使你找到了一个确定性很高的好标的，全仓押注和买 1% 仓位之间的最优解是什么？

---

## 一、仓位管理的三个层次

```
第一层：总仓位配比（股票 vs 现金/债券）
第二层：单标的仓位上限（集中度约束）
第三层：建仓节奏（一次性 vs 分批）
```

---

## 二、第一层：格雷厄姆 25-75 法则

格雷厄姆在《聪明的投资者》中给出了最经典的仓位框架：

```
防御型投资者：
├── 股票仓位：25-75%（永不低于 25%，永不超过 75%）
├── 债券/现金：25-75%
└── 调整规则：当市场估值过高时降低股票比例，反之增加

简单的现代版本：
├── 市场整体 PE < 15 → 股票仓位 75%
├── 市场整体 PE 15-25 → 股票仓位 50%
├── 市场整体 PE > 25 → 股票仓位 25%
└── 极端熊市（如 2008/2020）→ 可临时超配至 80-90%
```

## 三、第二层：单标的仓位约束

### 3.1 凯利公式（最科学的仓位计算）

凯利公式告诉你：在已知胜率和赔率的情况下，最优下注比例是多少。

```
凯利公式：
f* = (p × b - q) / b

其中：
f* = 最优仓位比例（占总资金）
p  = 赢的概率（确定性）
q  = 输的概率 = 1 - p
b  = 赔率 = 预期盈利 / 预期亏损

示例：
  你认为某股票：
  → 60% 概率涨 50%（内在价值回归）
  → 40% 概率跌 20%（判断错误 + 安全边际保护）

  f* = (0.6 × 2.5 - 0.4) / 2.5 = (1.5 - 0.4) / 2.5 = 0.44

  理论最优仓位 = 44%

  保守建议：凯利仓位 × 0.5 = 22%（半凯利，更安全）
```

### 3.2 凯利公式的概率-赔率-仓位速查表

| 胜率 \ 赔率 | 1:1 (涨=跌) | 2:1 (涨=跌×2) | 3:1 (涨=跌×3) | 5:1 (涨=跌×5) |
|-------------|------------|--------------|--------------|--------------|
| 50% | 0% | 25% | 33% | 40% |
| 55% | 10% | 33% | 40% | 46% |
| 60% | 20% | 40% | 47% | 52% |
| 70% | 40% | 55% | 60% | 64% |
| 80% | 60% | 70% | 73% | 76% |

> 实操建议：将凯利仓位 × 0.5 作为实际仓位上限。因为你对胜率和赔率的估计大概率偏乐观。

### 3.3 集中度上限（硬约束）

无论凯利公式算出来多少，以下硬约束不可突破：

```
单只股票仓位上限：
├── 普通标的：≤ 10%（总资金）
├── 高确定性标的：≤ 20%
├── 极高确定性（一生一次的机会）：≤ 30%
└── 绝对红线：任何单一标的 ≤ 40%

行业集中度上限：
├── 单一行业：≤ 40%
└── 单一板块（如科技/金融）：≤ 60%

持有数量建议：
├── 集中投资（巴菲特式）：5-10 只
├── 适度分散：10-20 只
├── 格雷厄姆式分散：30-100 只
└── 最低底线：≥ 5 只（避免单点致命风险）
```

## 四、第三层：金字塔式建仓

一次性满仓是最大的操作风险。金字塔式建仓可以降低择时错误的影响。

### 4.1 标准金字塔（3-4 批）

```
目标仓位：20%

第一批（初始）：40% × 目标 = 8%
  → 当前估值合理，开始建仓

第二批（加仓）：30% × 目标 = 6%
  → 股价下跌 10-15%，或等待 1-2 个月确认判断

第三批（完成）：20% × 目标 = 4%
  → 股价再跌 10-15%，或出现催化剂

第四批（超额）：10% × 目标 = 2%（可选）
  → 极端低估，市场恐慌，安全边际足够大

⚠️ 原则：
- 每批之间有明确的价格区间或时间间隔
- 不因为"涨了"就追加上一批的仓位
- 如果涨了 20%+，不再追加，让利润奔跑
```

### 4.2 倒金字塔卖出

```
卖出同样应该分批，而非一次性清仓：

第一批（减仓）：30% × 仓位
  → 估值进入合理偏高区域

第二批（再减）：40% × 仓位
  → 估值明显高估，或基本面出现恶化信号

第三批（清仓）：30% × 仓位
  → 极度高估，或卖出纪律触发

⚠️ 除非出现以下情况，否则不分批清仓：
  - 财务造假被证实
  - 核心护城河被摧毁
  - 管理层发生重大诚信问题
```

## 五、组合层面的纪律

### 5.1 再平衡规则

```
每季度检查一次：
├── 任何单只股票仓位超过上限 → 减持至上限
├── 任何行业仓位超过上限 → 减持至上限
├── 股票总仓位偏离目标范围 → 调整
└── 至少有 10% 现金储备 → 应对极端机会

⚠️ 再平衡不是机械的——如果一只股票大幅上涨是因为基本面大幅改善
（而非估值膨胀），可以适当放宽上限。但不能无限放宽。
```

### 5.2 现金流管理

```
永远不要满仓。永远留有余地。

现金储备：
├── 正常市场：10-20% 现金
├── 高估值市场：30-50% 现金
├── 熊市底部：5-10% 现金（弹药已打光也合理）
└── 绝对底线：≥ 5% 现金（应对生活/流动性需求）

定期现金流来源：
├── 股息收入 → 再投资
├── 新增储蓄 → 定期定额投入
└── 卖出获利 → 等待下一个机会
```
