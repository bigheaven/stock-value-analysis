# 杠铃策略 · 组合诊断工具

> **⚠️ 本诊断仅做持仓结构分析，不构成买卖建议。** 输出的是"你的组合偏哪一端、缺什么",不是"你应该买XX股票"。
>
> **理论基底**：[[cycle-vs-growth-investing]] — 文案杠铃策略部分；分类标准基于 [[cycle-growth-spectrum-framework-周期光谱框架]]。
>
> **建议频率**：每次新买入一只股票后,跑一次诊断。季度复核。

## 一、杠铃策略的核心逻辑

```
杠铃策略
═══════════════════════════════════════════════════════════════

  进攻端(硅基成长)                          防守端(碳基红利)
  ┌──────────────────┐                  ┌──────────────────┐
  │ 轻资产            │                  │ 重资产            │
  │ 高研发投入         │                  │ 高股息(≥5%)       │
  │ 渗透率 5-30%      │                  │ 供给受限           │
  │ 技术/网络壁垒      │                  │ 不再大规模扩产     │
  │                   │                  │ 现金流稳定         │
  │ 代表: AI/半导体/   │                  │ 代表: 煤炭/电力/   │
  │ 高端软件/创新药/   │                  │ 有色/港口/消费垄断 │
  │ 海外器械成长       │                  │                   │
  └────────┬─────────┘                  └────────┬──────────┘
           │                                      │
           └──────────────┬───────────────────────┘
                          │
                          ▼
              ┌───────────────────────┐
              │      中间资产？        │
              │  渗透率已高+增速个位数  │
              │  +无高股息+无强壁垒     │
              │        ⚠️ 绞肉机       │
              └───────────────────────┘

  文案原文核心理念：
  "他们不会把所有的鸡蛋放在一个篮子里,也不会平庸地去买一堆
   平淡无奇的中间资产。相反,他们会将资产配置在杠铃的两端。"
═══════════════════════════════════════════════════════════════
```

## 二、两端画像

### 进攻端（硅基成长）— 你的组合引擎

| 维度 | 标准 | 检查 |
|---|---|---|
| 渗透率 | 在 5—30% 黄金爆发期,或虽低但技术路径明确 | □ |
| 资产轻重 | 轻或中,边际成本递减 | □ |
| 资本开支/营收 | < 15%（或即使高,但 CAPEX 用于 R&D 而非买机器） | □ |
| 壁垒类型 | 技术/网络效应/品牌,且正在加宽 | □ |
| 增速 | 收入/利润增速 > 15% | □ |
| 示例 | AI芯片、高端半导体、SaaS、创新药(临床后期)、海外器械成长、新能源车(渗透率仍在爬坡的品牌) | |

### 防守端（碳基红利）— 你的组合压舱石

| 维度 | 标准 | 检查 |
|---|---|---|
| 股息率 | ≥ 5%（或 FCF 收益率 ≥ 6%） | □ |
| 供给约束 | 行业有明确的产能天花板(政策/资源/牌照) | □ |
| 资本开支 | 不再大规模扩产,自由现金流充沛 | □ |
| 需求稳定性 | 需求不会消失(能源/基础材料/必需品) | □ |
| 示例 | 动力煤龙头(长协价)、水电/核电、铜/铝矿(品位下降+新矿难批)、港口/高速、高端白酒(消费垄断红利) | |

**防守端自定义扩展**：如果用户认为某消费龙头(如茅台、可口可乐型资产)虽股息不到5%但品牌壁垒极深、波动极低,可酌情归入防守端。关键不是标签,而是"在市场下跌时,这部分能不能让你睡得着觉"。

## 三、自诊三步

### 第一步：估算三端占比

> 不要求列具体股票或金额,给大概百分比即可。

```
我的组合:
  进攻端(硅基成长)    ___%  (如腾讯+迈瑞海外+你的其他成长类)
  防守端(碳基红利)    ___%  (如煤炭/电力/高股息消费)
  中间资产/不确定      ___%  (如迈瑞国内IVD/上汽JV/其他)
  博弈型/特殊          ___%  (如经纬天地/打新/事件驱动)
  ─────────────────────────
  合计              100%
```

### 第二步：对照偏端矩阵

| 进攻端占比 | 防守端占比 | 评级 | 含义 |
|---|---|---|---|
| > 70% | < 20% | 🔴 **极端偏向进攻** | 牛市赚翻,熊市无缓冲;组合波动≈科技指数 |
| 50-70% | 20-40% | 🟡 **偏进攻** | 成长进攻为主,有一定防守但不够厚 |
| 40-60% | 30-50% | 🟢 **基本均衡** | 文案推荐的杠铃结构 |
| < 30% | > 60% | 🟡 **偏防守** | 睡得着觉,但可能踏空科技行情 |
| < 20% | > 70% | 🔴 **极端偏向防守** | 等同买了一只红利ETF,放弃成长弹性 |

### 第三步：中间资产检查

| 中间资产占比 | 评级 | 含义 |
|---|---|---|
| < 20% | 🟢 健康 | 杠铃两端为主,中间极少 |
| 20-40% | 🟡 注意 | 中间层偏厚,检查是否有"伪装成成长的周期股" |
| > 40% | 🔴 **中间资产过多** | 文案的核心警告——"杠铃中间是绞肉机"。其中大概率有退化中的灰色地带股票 |

## 四、你的持仓诊断（基于存量光谱映射）

> 基于 [[existing-portfolio-spectrum-mapping]] 的光谱分析：

```
你的当前组合(按四只已分析股票)
═══════════════════════════════════════════════════════════════

  进攻端         中间资产/灰色      防守端        博弈/特殊
  ─────────      ─────────────      ───────      ─────────
  腾讯           迈瑞国内IVD        (空)          经纬天地
  (成长偏周期)   (灰色⚠️退化中)
                 迈瑞医学影像
  迈瑞海外IVD    (灰色⚠️)
  (纯成长偏)
                 上汽JV
  迈瑞新兴业务   (现金牛瓦解)
  (纯成长)
                 迈瑞生命信息
                 (周期底,但非防守)
  ─────────      ─────────────      ───────      ─────────
  约 40-50%      约 40-50%          ≈ 0%         少量
```

**诊断结论**:

1. 🔴 **防守端完全缺失**——没有煤炭/电力/有色/高股息消费。市场系统性下跌时,你的组合没有任何压舱石,全靠"相信这些公司最终会恢复"的信仰撑。
2. ⚠️ **中间资产占比过大(~40-50%)**——迈瑞国内业务 + 上汽JV 占了半壁江山,全部是处于灰色地带或周期性衰退的资产。它们不是纯防守(低波动+高股息),也不是纯进攻(高成长),正是文案里警告的"中间绞肉机"。
3. 🟢 **进攻端有个不错的基础**——腾讯的护城河 + 迈瑞海外的高增速,构成了组合的增长引擎。但仅靠这两者,组合的进攻弹性也不够（缺一个真正意义上的"渗透率 5-30%" 纯成长股）。
4. 🔴 **博弈型资产虽然没有伤筋动骨,但心智成本高**——经纬天地这种股票,不管仓位多小,你会一直盯着它,消耗本应用在"找到真正成长股"上的精力。

**再平衡方向（非投资建议）**:

1. **优先补防守端**：目标防守端 ≥ 20%。考虑煤炭/电力/有色/高股息消费中任一类。不必一次配齐,从 10% 开始,在市场波动时感受"有防守端和无防守端的差别"。
2. **逐步降低中间层**：迈瑞国内业务和上汽JV 不是不能持有——但要明确它们是"周期择时"仓位,不是"长期成长仓位"。当它们的周期拐点确认后(如专项债发力、以旧换新刺激),才是加仓时机,而不是现在被动扛着。
3. **加一个真正的纯成长**：渗透率在 5-15%、轻资产、技术壁垒正在加宽的股票——把这当作"持续研究的长期任务",不急于买入,但要让组合有一个真正意义上的高弹性进攻标的。
