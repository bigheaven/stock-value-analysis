## 陷阱一：AH溢价陷阱（两地上市价差）

### 现状

恒生AH溢价指数约 **119.08**（2026年5月数据），即A股整体比H股贵约19%。但极端个股差异巨大。

**AH溢价极端案例**（A股比H股贵的幅度）：

| 公司 | A股价格 | H股价格 | A股比H股溢价 |
|------|--------|--------|:----:|
| 东北电气 | 2.25元 | 0.247港元 | **+993%** |
| 浙江世宝 | 15.53元 | 3.95港元 | **+270%** |
| 中石化油服 | 2.29元 | 0.66港元 | **+215%** |
| 中信证券 | ~25元 | ~14港元 | +55% |
| 东方电气 | ~15元 | ~8港元 | +51% |
| 中国太保 | ~28元 | ~15港元 | +48% |

> 也有H股比A股贵的情况，如华虹半导体H股比A股贵约58%（2026年9月数据）。

### 为什么同一家公司，港股更便宜？

**核心原因：两个市场是"同股不同市场"，不是简单的估值错配。**

| 因素 | A股 | H股 |
|------|-----|-----|
| 投资者结构 | 散户为主，情绪驱动 | 机构为主，价值驱动 |
| 资金池 | 境内资金充裕（相对封闭） | 全球资金，但总量小 |
| 流动性 | 极高，小盘也有几千万成交 | 分化极大，小票日均成交不足百万 |
| 打新红利 | 有（新股不败神话） | 无 |
| 退市制度 | 难退市，壳有价值 | 容易退市，壳不值钱 |
| 做空机制 | 难做空 | 容易做空，有裸卖空 |
| 红利税（内地投资者） | 持有超1年免税 | **港股通20%（直接扣除）** |
| 涨跌停板 | ±10%/20% | 无涨跌停限制 |

### 最坑的地方：折价可能长期存在甚至扩大

- AH溢价已存在20多年，从未真正"收敛"
- 溢价率在120-150之间波动是常态，极端时超过200
- **你以为H股会涨上去跟A股看齐，结果可能是A股跌下来跟H股看齐**
- 2021-2022年很多AH股就是A股跌更多把溢价"拉平"的

### 正确认知与操作建议

1. **不要赌"溢价收敛"**——这是长期结构性现象
2. **买H股的理由应该是"公司好+估值便宜"，不是"比A股便宜"**
3. **优先选股息高的H股**——高股息能把"折价"变成现金回报
4. **H股比A股贵的情况要警惕**——通常是流动性溢价或短期炒作，不可持续
5. **同一家公司，如果A股和H股都能买，且H股折价超过30%+股息率更高，优先选H股**

## 陷阱二：高股息陷阱

### 表现形式

- 股息率看起来很高（8%、10%甚至更高）
- 吸引追求稳定收益的投资者买入
- 买入后股息削减，或股价跌幅超过股息收益

### 高股息的三种"假"

| 类型 | 原因 | 识别方法 |
|------|------|---------|
| **跌出来的高股息** | 股价暴跌导致股息率被动升高 | 看股价走势，如果近一年跌了30%+，高股息可能是跌出来的 |
| **一次性高股息** | 卖资产、特别分红导致派息率异常高 | 看派息率，如果超过100%或远超历史平均，可能不可持续 |
| **利润下滑型** | 利润在降，但分红还维持，未来必然砍股息 | 看利润趋势，如果净利连续下滑，高股息保不住 |

### 验证高股息真实性的5个指标

1. **派息率 < 70%**（成熟期公司安全线，超过80%警惕，超过100%高危）
2. **经营现金流 / 分红 > 1.2x**（现金流能覆盖分红且有余量）
3. **连续5年以上稳定分红**（有历史记录可追溯）
4. **利润趋势向上或平稳**（利润在涨，分红才有保障）
5. **不是一次性特别分红**（剔除特别股息后的常态股息率才是真实的）

## 陷阱三：老千股/仙股陷阱

### 什么是老千股？

大股东不靠公司经营赚钱，靠**财技**（合股、供股、配股、拆股等组合拳）收割散户的股票。这是港股独有的最恶劣的陷阱。

### 经典收割流程

```
股价1元 → 砸到0.1元（散户亏90%）
→ 10合1，股价变回1元（股数变为1/10，总市值不变）
→ 继续砸到0.1元（又亏90%，累计亏99%）
→ 大比例供股：1供2，配股价0.05元（折价80%）
   → 不参与：股权被大幅稀释
   → 参与：继续投钱，但投进去继续跌
→ 再合股、再供股…… 无限循环
```

### 老千股识别特征

| 特征 | 说明 |
|------|------|
| 股价极低 | 几毛钱甚至几分钱（"仙股"） |
| 频繁合股/供股 | 历史上多次"10合1""5合1"+大比例供股 |
| 名字经常改 | 换个名字继续骗（蹭热点概念） |
| 市值小 | 通常几十亿港元以下，很多几亿甚至几千万 |
| 常年不分红 | 一毛不拔，只进不出 |
| 大股东持股变动诡异 | 经常减持但又通过供股增回来 |
| 业务看不懂 | 什么热门做什么，但什么都做不好 |

### 数据

- 港股有超过1200只"仙股"（股价低于1港元），占全部股票近一半
- 其中245只股价低于0.1港元
- 港股全市场约2500只股票，真正有投资价值的可能不超过300只

### 避坑方法

**简单粗暴有效：股价低于1港元的港股，直接不碰。** 不管看起来多便宜、故事多好听。

> 更系统的老千股识别操作清单，见 [[04_排雷_港股红旗清单]]（8维度评分系统）。

## 陷阱四：流动性陷阱

### 港股流动性分化有多极端？

| 分层 | 数量占比 | 成交额占比 | 代表股票 |
|------|:----:|:----:|---------|
| 头部50只 | ~2% | 50%+ | 腾讯、友邦、美团、阿里等 |
| 前200只 | ~8% | 80%+ | 大中型蓝筹 |
| 剩下的2300+只 | ~92% | ~20% | 很多日均成交不足百万 |

### 流动性差的后果

1. **冲击成本高**：想买100万，买进去股价就涨了5%甚至更多
2. **卖出困难**：想卖100万，可能挂单几天都成交不了
3. **无量暴跌**：遇到利空，直接跳空大跌，想跑跑不掉
4. **估值失真**：看起来市值不大，但你根本无法以当前价格买入或卖出大量股份

### 对比A股

A股的小票再差，每天也有几千万成交。港股的小票，一天成交几十万甚至几万的都有。**这也是H股比A股便宜的重要原因之一——流动性折价。**

### 避坑方法

- 只买**日均成交额1亿港元以上**的股票
- 市值低于**50亿港元**的小票慎入
- 如果一定要买小票，仓位控制在总仓位的1-2%以内

## 陷阱五：低PE价值陷阱

### 表现

- PE很低（5x、3x甚至更低）
- PB也很低（0.5x、0.3x）
- 看起来"白送钱"，但买入后股价继续跌或长期不涨

### PE低的N种原因（不是每种都叫"便宜"）

| 原因 | 本质 | 举例 |
|------|------|------|
| 盈利是一次性的 | 利润不可持续 | 卖资产、政府补贴、资产重估 |
| 盈利在快速下滑 | 今年PE 5x，明年就变10x | 周期股顶点、行业衰退 |
| 行业在衰退 | 整个赛道在萎缩 | 传统媒体、部分制造业 |
| 公司有隐藏负债 | 表外债务、担保、法律风险 | 部分地产、金融股 |
| 大股东在掏空 | 关联交易、转移资产 | 部分家族企业 |
| 真的被错杀 | 市场情绪过度悲观 | 优质蓝筹大熊市时 |

### 怎么区分"真便宜"和"价值陷阱"？

**3个验证维度**：

1. **盈利稳定性**：过去5-10年，利润是稳步增长/持平，还是大起大落？
2. **现金流质量**：经营现金流是否持续 > 净利润？
3. **ROIC（投入资本回报率）**：是否持续高于资金成本（8-10%）？

> 如果三个答案都是"是"，那可能真便宜；如果有两个以上"否"，大概率是陷阱。

## 陷阱六：供股/配股稀释陷阱

### 什么是供股？

供股就是A股说的"配股"——公司向现有股东按持股比例增发新股，股东要掏钱认购。港股的供股非常自由，公司想融就融。

### 怎么坑你？

- 公司宣布"2供1，配股价折让30%"——看起来捡了便宜
- **不参与 → 股权被稀释**，股价除权后你的持仓直接亏损
- **参与 → 得掏更多钱进去**，但公司拿到钱可能继续亏、继续供
- 老千股甚至会"1供5""1供10"，配股价深折，直接把老股东权益稀释殆尽

### 危险信号

| 信号 | 危险程度 |
|------|:----:|
| 大比例供股（1供2以上） | ⭐⭐⭐⭐⭐ |
| 配股价折让 > 50% | ⭐⭐⭐⭐⭐ |
| 供股用于"补充流动资金"/"还债务" | ⭐⭐⭐⭐ |
| 频繁供股（1-2年内多次） | ⭐⭐⭐⭐⭐ |
| 供股用于扩主业 + 公司盈利正常 | ⭐（相对安全） |

### 操作建议

- 看到大比例供股公告，**先跑再说**（尤其是老千股特征的公司）
- 频繁供股的公司，直接拉黑
- 如果是优质公司的小额供股（用于收购/扩产），可以评估后决定是否参与

## 陷阱七：私有化/退市陷阱

### 怎么坑你？

1. 公司股价跌得很惨，远低于净资产
2. 大股东提出私有化，价格比现价高20-30%（看起来很良心）
3. 你觉得"总算解脱了"，同意了
4. 结果私有化价格远低于公司真实价值，**大股东低价捡走了你的筹码**

### 港股私有化规则

- 需75%以上股东同意（按股数计）
- 反对票不超过10%
- 法院审批
- 小股东基本没有话语权

### 怎么应对？

- 私有化价格低于净资产 → 慎重考虑，可能被贱卖
- 私有化价格高于近1年均价50%以上 → 可以接受
- 如果看好公司长期价值，且大股东私有化价格偏低 → 可以投反对票（虽然大概率没用）

## 陷阱八：汇率风险

### 为什么有汇率风险？

- 通过港股通买港股：用人民币买港币计价的股票
- 卖出后换回人民币
- 港币对人民币的汇率波动会影响你的实际收益

### 联系汇率制度

港币跟美元挂钩（7.75-7.85港元兑1美元），所以本质上**持有港股 = 持有美元资产 + 公司基本面风险**。

| 情景 | 对港股投资者的影响 |
|------|------------------|
| 人民币贬值 | 汇兑收益，相当于额外赚了 |
| 人民币升值 | 汇兑损失，吃掉一部分收益 |
| 港币贬值（联系汇率失守） | 极端风险，但概率极低 |

### 怎么看待汇率风险？

- **不要忽视**：人民币一年升/贬值3-5%很正常，可能吃掉全部股息收益
- **也不用过度担心**：长期来看，汇率是双向波动的
- **可以当工具用**：如果你担心人民币贬值，配置港股相当于对冲
- **计算收益时要用人民币计价**：不要只看港币涨了多少

## 避坑总原则与快速筛查清单

### 总原则

> **港股不是遍地黄金的"估值洼地"，是一半黄金一半坑的"寻宝游戏"。找到黄金的前提是别踩到坑。**

### 港股投资"只买"原则

1. **只买大市值**——市值500亿港元以上优先，最低不低于100亿
2. **只买高成交**——日均成交额1亿港元以上
3. **只买有分红**——连续5年以上分红记录
4. **只买看得懂的生意**——不碰概念炒作、跨界转型
5. **只买行业龙头**——前三以外慎入

### 30秒快速筛查（5个一票否决）

1. ❌ 股价低于1港元？→ 否决（老千股概率高）
2. ❌ 市值低于50亿港元？→ 否决（流动性+老千风险）
3. ❌ 近2年有合股/供股记录？→ 否决（财技公司）
4. ❌ 不分红或分红断断续续？→ 否决（利润真实性存疑）
5. ❌ PE < 3x 或 PB < 0.3x？→ 先打个问号（为什么这么便宜？是不是陷阱？）

### 通过筛查后，再做3件事

1. **看基本面**：营收、利润、ROE、现金流趋势
2. **看估值**：PE/PB/股息率在行业中什么位置
3. **看催化剂**：未来1-2年有什么能让估值修复的因素
