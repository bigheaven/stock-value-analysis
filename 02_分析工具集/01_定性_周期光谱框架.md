# 成长 ⟷ 周期：股票光谱分类框架

> **⚠️ 本框架仅做分类,不构成买卖建议。** 分类为'成长'不等于'值得买',分类为'周期'不等于'应该卖'。后续仍需完整的基本面与估值分析。
>
> **理论基底**：[[cycle-vs-growth-investing]] — 周期股和成长股：最本质区别在哪？
>
> **数据截止日期**：2026-07-18
>
> **适用边界**：适用于制造业、科技、资源、消费等实体产品类股票。不适用于纯金融服务、REITs、SPAC。
>
> **复核周期**：分类有效期建议每半年复核一次；重大行业事件（集采落地、产能集中投放、技术突破）发生后立即复核。

## 一、核心问题

拿到一只股票,第一个要回答的问题不是"值多少钱",而是:

> **这是一只什么类型的股票？它赚钱是靠"把蛋糕做大"(成长)还是靠"重新分蛋糕"(周期)？**

用错了框架,再好的分析也是白做——把周期股当成长股分析,会买在利润最高点;把成长股当周期股交易,会卖在爆发前夜。

本框架提供三个指标,帮你**在 15 分钟内完成这个判断**。

## 二、三指标打分体系

### 指标 1：渗透率 (Penetration Rate)

```
渗透率 S 曲线
═══════════════════════════════════════════════════════════════
  渗透率
   100% ┤                                    ┌─────────────
        │                                   ╱
    80% ┤                                 ╱
        │                                ╱  存量博弈期
    50% ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ╱   (增速 < 10%)
        │                            ╱
    30% ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ╱   增速放缓期
        │                        ╱    (增速从高→中)
        │                      ╱
     5% ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ╱    黄金爆发期
        │                   ╱     (市场空间成倍扩张)
        │                 ╱
        │ 探索期        ╱
     0% └──────────────┴──────────────────────────────────→ 时间
        (高风险高回报)
═══════════════════════════════════════════════════════════════
```

**判定表**：

| 渗透率区间 | 阶段 | 核心特征 | 打分 |
|---|---|---|---|
| < 5% | 探索期 | 产品未成熟,用户极小,九死一生 | 🟡 极早期 |
| 5%—30% | 黄金爆发 | 技术路径明确,市场成倍扩张,**最安全成长投资期** | 🟢 成长 |
| 30%—50% | 增速放缓 | 该买的人都买了,增速断崖式下跌 | 🟡 警惕 |
| > 50% | 存量博弈 | 替换需求为主,增长靠抢份额 | 🔴 周期化 |

**趋势判断（叠加在区间上）**：

| 趋势 | 含义 | 信号 |
|---|---|---|
| 加速渗透 | 还在爬坡,空间充足 | ✅ |
| 匀速渗透 | 正常推进 | ✅ |
| 放缓 | 接近天花板 | ⚠️ |
| 停滞或回退 | 天花板已到 | 🔴 |

**关键警示**：当渗透率 > 30% **且**趋势变为"放缓"时,行业大概率正在从成长股退化为周期股。

### 指标 2：资本开支 (CAPEX) 与资产轻重

> 核心问题：这家公司要赚多一倍的钱,需不需要投多一倍的厂房机器？

**资产轻重判定**：

| 类型 | 特征 | 资本开支/营收比(参考) | 典型行业 |
|---|---|---|---|
| 轻资产 | 服务更多客户不需更多厂房 | < 5% | 软件、品牌消费品、互联网平台 |
| 中资产 | 需要一定投入但边际递减 | 5%—15% | 器械、电子制造、医药 |
| 重资产 | 扩产 = 巨量固定投资 | > 15% | 钢铁、化工、航运、采矿 |

**在建工程趋势**（比绝对值更重要——趋势反转 = 信号）：

| 趋势 | 含义 |
|---|---|
| 下降 | 行业收缩,供给出清中 → 周期见底征兆 ✅ |
| 平稳 | 供需平衡,成熟期 |
| 上升 | 扩产中,未来 1-3 年新产能释放 → 注意拐点 ⚠️ |
| 飙升 | 疯狂扩产,全行业在建工程创新高 → **周期见顶信号** 🔴 |

**重资产 + 在建工程飙升 = 文案里碳酸锂/硅料故事的标准前置信号。**

### 指标 3：壁垒类型 (Moat Type)

> 核心问题：竞争对手能不能靠砸钱就追上你？

**六种壁垒（从最强到最弱）**：

```
┌──────────────────────────────────────────────────────────────────┐
│ 壁垒类型    │ 钱能买到？ │ 特征                    │ 稳定性      │
├──────────────────────────────────────────────────────────────────┤
│ 网络效应    │ ❌ 不能   │ 用的人越多产品越好      │ 极高        │
│ 技术壁垒    │ ⚠️ 很难   │ 专利/架构/研发积累      │ 高(需持续投)│
│ 品牌壁垒    │ ⚠️ 很难   │ 消费者心智占据          │ 高          │
│ 规模壁垒    │ ⚠️ 可以   │ 成本最低,量大价低       │ 中(可被复制)│
│ 资本壁垒    │ ✅ 可以   │ 我有钱建了最大工厂      │ 低(容易被钱破)│
│ 无壁垒      │ —         │ 纯靠价格竞争            │ 零          │
└──────────────────────────────────────────────────────────────────┘
```

**壁垒变化方向**（静态壁垒 × 变化方向 = 真实壁垒）：

| 方向 | 含义 | 信号 |
|---|---|---|
| 加宽 | 护城河越来越深 | ✅ |
| 稳定 | 保持现状 | ✅ |
| 收窄 | 竞争侵蚀 | ⚠️ |
| 瓦解 | 壁垒被突破 | 🔴 |

**文案的核心洞见**：如果一家企业的壁垒只是"我砸的钱多"(资本壁垒),任何有钱的竞争对手都能复制——这就是纯周期股的本质。

## 四、五段分区判定规则

| 光谱段 | 渗透率 | CAPEX | 壁垒 | 组合特征 | 交易策略 |
|---|---|---|---|---|---|
| **纯成长** | 5-30%,趋势加速或匀速 | 轻或中 | 技术/网络/品牌,加宽或稳定 | 三指标全绿 | 择股>择时,渗透率黄金期介入 |
| **成长偏周期** | 接近30%或趋势放缓 | 中 | 稳定但不再加速加宽 | 渗透率亮黄灯,其他灯绿 | 择股为主,注意渗透率拐点 |
| **灰色地带** | 任意 | 任意 | **至少一个维度正在退化** | 有绿灯有红灯 | 按业务线拆开,退化线按周期,成长线按成长 |
| **周期偏成长** | 已过顶点,渗透率回升中 | 中或重 | 技术壁垒强(周期复苏弹性大) | 周期底部回升 | 择时为主,盯供给底+库存拐点 |
| **纯周期** | >50%或同质化 | 重 | 资本壁垒或无壁垒 | 三指标全红或全黄 | 择时>择股,高PE买低PE卖,盯供给出清 |

## 五、分类有效期与复核

- **常规复核**：每半年重打分一次（建议与半年报/年报季同步）
- **事件触发复核**（以下任一发生,立即重打分）：
  - 行业集采/集采范围扩大
  - 主要竞争对手宣布大幅扩产(CAPEX 飙升)
  - 核心技术突破(壁垒可能被打破)
  - 渗透率过关键节点(5%/30%/50%)
  - 在建工程增速突然从下降转上升(周期见顶信号)
